## 数据字段说明

### 基本信息
- **项目类型**: 新建系统 / 储能扩容
- **屋顶理论最大面板数量**: 1-100 块
- **方案**: A / B / C
- **实际面板数量**: 根据容量系数计算的实际安装面板数

### 系统配置
- **光伏容量(kW)**: 实际面板数量 × 0.44kW
- **逆变器功率(kW)**: 根据方案查表或计算得出
- **电池可用容量(kWh)**: 电池的可用容量
- **电池标称容量(kWh)**: 电池的标称容量

### 成本细项（v1.1简化版）
- **面板报价(AUD)**: 光伏容量 × 540 AUD/kW（新建系统）或 0（储能扩容）
- **逆变器报价(AUD)**: 逆变器功率 × 280 AUD/kW（新建系统）或 0（储能扩容）
- **电池报价(AUD)**: 电池标称容量 × 865 AUD/kWh
- **税前整体报价(AUD)**: 面板 + 逆变器 + 电池
- **GST税费(AUD)**: 税前报价 × 10%
- **含税报价(AUD)**: 税前报价 + GST

### 补贴明细
- **STC_PV补贴(AUD)**: 光伏STC补贴（仅新建系统）
- **STC电池补贴(AUD)**: 电池STC补贴
- **VIC州补贴(AUD)**: VIC州补贴（默认0，需手动启用）
- **VIC州无息贷款(AUD)**: VIC州无息贷款（默认0，需手动启用）
- **NSW_VPP补贴(AUD)**: NSW VPP补贴（默认0，需手动启用）
- **补贴总计(AUD)**: 所有补贴之和

### 最终报价
- **最终报价(AUD)**: 含税报价 - 补贴总计
- **展示下限(AUD)**: 最终报价 × (1 - 5%)
- **展示上限(AUD)**: 最终报价 × (1 + 5%)

### 单价分析（新增）
- **系统单价(AUD/W)**: 最终报价 ÷ (光伏容量 × 1000)
  - 反映整个系统的每瓦成本
- **扣除电池后单价(AUD/W)**: (最终报价 - 电池报价 + 电池补贴) ÷ (光伏容量 × 1000)
  - 反映扣除电池投入和电池补贴后的光伏系统每瓦成本
  - 用于评估纯光伏部分的性价比

### 方案差异
- **方案A**: 使用GS功率映射表，电池容量较大
- **方案B**: 使用GD功率映射表，电池容量中等
- **方案C**: 使用公式计算，基于目标自用率50%

## 使用建议

### 1. 数据分析
可以使用Excel或Python进行以下分析：
- 不同面板数量下的成本趋势
- 三个方案的价格对比
- 单价随规模的变化规律
- 补贴占比分析

### 2. 价格查询
根据客户的屋顶面板数量，快速查找对应的报价：
```
例如：37块面板的新建系统
- 方案A: 查找"屋顶理论最大面板数量=37, 方案=A"的行
- 获取最终报价、展示上下限等信息
```

### 3. 方案比较
对于同一面板数量，比较三个方案的：
- 系统配置差异
- 价格差异
- 单价差异

### 4. 扩展计算
如需启用州补贴，可以：
1. 修改 `batch-calculator-v1.1.js` 中的参数
2. 设置 `enable_vic_rebate: true` 或 `enable_nsw_vpp: true`
3. 重新运行脚本生成新数据

## 脚本说明

### 运行方法
```bash
cd Quote
node batch-calculator-v1.1.js
```

### 输出位置
- 输出目录: `Quote/output/`
- 文件命名: `{项目类型}_{时间戳}.csv`
- 时间戳格式: `YYYY-MM-DDTHH-MM-SS`

### 修改参数
编辑 `batch-calculator-v1.1.js` 中的 `DEFAULT_PARAMS` 对象：
```javascript
const DEFAULT_PARAMS = {
    region: 'NSW',  // 修改地区
    panel_price_per_kw: 540,  // 修改面板单价
    // ... 其他参数
};
```

## 注意事项

1. **CSV编码**: 文件使用UTF-8 with BOM编码，确保Excel正确显示中文
2. **数值精度**: 金额保留2位小数，单价保留4位小数
3. **0值情况**: 当面板数量为0或1时，某些方案可能无法计算（显示为0）
4. **补贴限制**: NSW VPP补贴仅在电池容量2-28kWh时适用
