## 项目概述

本项目提供了完整的光伏储能系统批量计算和IRR分析工具，包括：
- Quote v1.1 成本计算
- 批量IRR分析（考虑补贴/不考虑补贴）
- N/A问题分析
- 详细的计算说明文档

## 计算流程

### 第一步：Quote批量计算

**目的**：计算1-100块面板的所有配置的成本和补贴

```bash
cd Quote
node batch-calculator-v1.1.js
```

**输入参数**：
- 面板数量：1-100块
- 项目类型：新建系统、储能扩容
- 方案：A、B、C

**输出文件**：
- `output/jisuan/新建系统_YYYY-MM-DDTHH-MM-SS.csv`
- `output/jisuan/储能扩容_YYYY-MM-DDTHH-MM-SS.csv`

**输出字段**：
- 系统配置（面板数、光伏容量、逆变器功率、电池容量）
- 成本细项（面板、逆变器、电池报价）
- 补贴明细（STC PV、STC Battery、州补贴）
- 最终报价（含税报价、扣除补贴后）
- 单价分析（系统单价、扣除电池后单价）

### 第二步：IRR批量计算（考虑补贴）

**目的**：基于最终报价计算所有州/领地的IRR

```bash
cd Quote
node batch-irr-calculator.js
```

**输入数据**：`output/jisuan/*.csv`

**计算逻辑**：
- 投资成本 = 最终报价AUD（扣除补贴后）
- 使用solar-calculator-static的月度计算逻辑
- 计算240个月的现金流
- 月度计提电池成本（前120个月）

**输出文件**：
- `output/IRR/IRR分析_YYYY-MM-DDTHH-MM-SS.csv`

**输出字段**：
- 基本信息（项目类型、方案、州/领地）
- 系统配置（光伏容量、电池容量）
- 成本信息（总投资成本、电池更换成本）
- 关键指标（自用率、回本周期、贴现回本周期、IRR）

### 第三步：IRR批量计算（不考虑补贴）

**目的**：基于含税报价计算IRR，评估系统真实经济性

```bash
cd Quote
node batch-irr-calculator.js --no-subsidy
```

**输入数据**：`output/jisuan/*.csv`

**计算逻辑**：
- 投资成本 = 含税报价AUD（不扣除补贴）
- 其他逻辑与考虑补贴模式相同

**输出文件**：
- `output/IRR/IRR分析_不考虑补贴_YYYY-MM-DDTHH-MM-SS.csv`

## 使用指南

### 快速开始

```bash
# 1. 进入Quote目录
cd Quote

# 2. 运行Quote批量计算
node batch-calculator-v1.1.js

# 3. 将生成的CSV移动到jisuan目录
mkdir -p output/jisuan
mv output/新建系统_*.csv output/jisuan/
mv output/储能扩容_*.csv output/jisuan/

# 4. 运行IRR计算（考虑补贴）
node batch-irr-calculator.js

# 5. 运行IRR计算（不考虑补贴）
node batch-irr-calculator.js --no-subsidy
```

### 参数修改

#### 修改Quote计算参数

编辑 `batch-calculator-v1.1.js` 中的 `DEFAULT_PARAMS`：

```javascript
const DEFAULT_PARAMS = {
    region: 'NSW',                    // 地区
    panel_price_per_kw: 540,          // 面板单价
    inverter_price_per_kw: 280,       // 逆变器单价
    battery_price_per_kwh: 865,       // 电池单价
    gst_rate: 0.1,                    // GST税率
    display_range_percent: 5,         // 展示浮动百分比
    // ... 其他参数
};
```

#### 修改IRR计算参数

编辑 `batch-irr-calculator.js` 中的 `defaultParams`：

```javascript
const defaultParams = {
    electricityPrice: 0.30,           // 电价
    feedInTariff: 0.05,               // 上网电价
    priceInflation: 0.03,             // 电价通胀率
    degradation: 0.005,               // 系统衰减率
    discountRate: 0.05,               // 贴现率
    // ... 其他参数
};
```

## 问题分析

### N/A问题

**现象**：约27%的记录显示N/A

**原因**：
1. 小系统配置不经济（电池过大）
2. 投资成本远超收益能力
3. 20年内无法回本

**详细分析**：见 `IRR计算N/A问题分析.md`

### 典型N/A案例

#### 2块面板方案A（最差情况）
```
光伏容量: 0.44kW
电池容量: 22.44kWh
投资成本: 16,641.73 AUD
电池成本占比: 117%
年发电量: 671 kWh
年节省: 201 AUD
月度电池计提: 162 AUD
前10年月度净节省: -145 AUD（负数！）
结果: 永远无法回本
```

#### 2块面板方案C（正常情况）
```
光伏容量: 0.44kW
电池容量: 0.43kWh
投资成本: 503.91 AUD
电池成本占比: 74%
年发电量: 671 kWh
年节省: 201 AUD
月度电池计提: 3.1 AUD
前10年月度净节省: +14 AUD
回本周期: 3.04年
IRR: 35.02%
```

### 解决建议

1. **小系统用户**：选择方案C或不装电池
2. **销售人员**：避免推荐N/A配置
3. **系统设计**：优化功率映射表，为小系统配置更小的电池

## 数据分析示例

### 筛选优质投资

```bash
# 筛选IRR > 10%的配置
grep -v "N/A" IRR分析_*.csv | awk -F',' '$17 ~ /[0-9]+\.[0-9]+%/ {
    irr = $17; gsub(/%/, "", irr);
    if (irr > 10) print $0
}'

# 筛选回本周期 < 10年的配置
grep -v "N/A" IRR分析_*.csv | awk -F',' '$14 != "N/A" {
    if ($14 < 10) print $0
}'
```

### 州/领地对比

```bash
# 统计各州平均IRR
for state in NSW VIC QLD SA WA TAS ACT NT; do
    echo -n "$state: "
    grep "\"$state\"" IRR分析_*.csv | grep -v "N/A" | \
        awk -F',' '{irr=$17; gsub(/%/, "", irr); sum+=irr; count++} 
        END {print sum/count "%"}'
done
```

### 方案对比

```bash
# 统计各方案平均IRR
for plan in A B C; do
    echo -n "方案$plan: "

        awk -F',' '{irr=$17; gsub(/%/, "", irr); sum+=irr; count++}

done
```

## 常见问题

### Q1：为什么有些配置显示N/A？
**A**：这些配置在经济上不可行，20年内无法回本。主要是小系统配置了过大的电池。

### Q2：应该使用哪种IRR计算模式？
**A**：
- 短期决策（1-2年）：使用考虑补贴模式
- 长期规划（5-10年）：参考不考虑补贴模式
- 全面评估：同时查看两种模式

### Q3：如何提高IRR？
**A**：
1. 选择合适的方案（方案C通常IRR最高）
2. 避免过大的电池配置
3. 选择用电量高的州/领地
4. 确保系统规模合理（5-15kW最优）

### Q4：补贴政策会变化吗？
**A**：可能会。建议：
- 定期更新补贴参数
- 重新运行计算
- 对比不考虑补贴模式的结果

### Q5：如何验证计算结果？
**A**：
1. 手动计算几个样本验证
2. 对比考虑补贴和不考虑补贴的差异
3. 检查投资成本是否合理
4. 验证IRR是否在合理范围内（0-20%）

## 技术支持

### 依赖环境
- Node.js (v14+)
- 无需额外npm包

### 性能
- Quote批量计算：约10秒（600条记录）
- IRR批量计算：约30秒（4,752条记录）

### 错误处理
- CSV解析错误：检查文件编码（应为UTF-8）
- 计算错误：检查输入参数是否合理
- N/A过多：检查系统配置是否合理
