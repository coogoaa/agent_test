# IRR计算模式说明

## 概述

批量IRR计算脚本支持两种计算模式：
1. **考虑补贴模式**（默认）：使用最终报价AUD（扣除补贴后）作为投资成本
2. **不考虑补贴模式**：使用含税报价AUD作为投资成本

## 使用方法

### 模式1：考虑补贴（默认）
```bash
cd Quote
node batch-irr-calculator.js
```

**投资成本来源**：`最终报价AUD`
- 含税报价 - 所有补贴（STC PV + STC Battery + 州补贴）
- 反映用户实际需要支付的金额

**输出文件**：`IRR分析_YYYY-MM-DDTHH-MM-SS.csv`

### 模式2：不考虑补贴
```bash
cd Quote
node batch-irr-calculator.js --no-subsidy
```

**投资成本来源**：`含税报价AUD`
- 税前报价 + GST
- 不扣除任何补贴
- 反映系统的真实市场价格

**输出文件**：`IRR分析_不考虑补贴_YYYY-MM-DDTHH-MM-SS.csv`

## 两种模式的差异

### 投资成本对比

以50块面板新建系统方案A为例：

| 项目 | 金额(AUD) |
|------|----------|
| 税前报价 | 37,550.60 |
| GST(10%) | 3,755.06 |
| **含税报价** | **41,305.66** ← 不考虑补贴模式使用 |
| STC PV补贴 | -12,077.40 |
| STC Battery补贴 | -3,451.68 |
| 州补贴 | 0.00 |
| **最终报价** | **25,776.58** ← 考虑补贴模式使用 |

**投资成本差异**：41,305.66 - 25,776.58 = **15,529.08 AUD**

### 计算结果对比

#### 案例：50块面板新建系统方案A（NSW）

| 指标 | 考虑补贴 | 不考虑补贴 | 差异 |
|------|---------|-----------|------|
| 投资成本 | 25,776.58 AUD | 41,305.66 AUD | +60% |
| 回本周期 | 12.60年 | 15.83年 | +3.23年 |
| 贴现回本周期 | 16.04年 | N/A | 无法回本 |
| IRR | 7.38% | 3.29% | -4.09% |

**关键发现**：
- 不考虑补贴时，投资成本增加60%
- 回本周期延长约3年
- IRR从7.38%降至3.29%，投资吸引力大幅下降
- 贴现回本周期变为N/A，说明在考虑货币时间价值后无法在20年内回本

## 应用场景

### 考虑补贴模式

**适用于**：
- 客户实际投资决策
- 评估用户真实回报
- 销售报价和推荐

**优势**：
- 反映用户实际支出
- IRR和回本周期更有吸引力
- 符合用户实际体验

**局限**：
- 依赖政府补贴政策
- 补贴可能变化或取消
- 不同州/领地补贴差异大

### 不考虑补贴模式

**适用于**：
- 评估系统真实经济性
- 补贴政策不确定时的保守估计
- 跨国或跨地区对比
- 长期政策分析

**优势**：
- 不依赖补贴政策
- 反映系统本身的经济价值
- 更保守和稳健的评估

**局限**：
- 不符合用户实际支出
- IRR较低，可能影响推广
- 忽略了现有政策优势

## 数据字段说明

两种模式输出的CSV文件格式完全相同，唯一差异是：

### 总投资成本AUD
- **考虑补贴模式**：= 最终报价AUD
- **不考虑补贴模式**：= 含税报价AUD

其他所有字段（自用率、回本周期、IRR等）都是基于相应的投资成本计算得出。

## 补贴金额分析

### 典型补贴占比

| 系统规模 | 含税报价 | 补贴总额 | 补贴占比 |
|---------|---------|---------|---------|
| 小系统(<5kW) | ~5,000 | ~1,500 | 30% |
| 中型系统(5-15kW) | ~25,000 | ~10,000 | 40% |
| 大型系统(>15kW) | ~50,000 | ~20,000 | 40% |

**观察**：
- 补贴占含税报价的30-40%
- 中大型系统补贴占比更高
- 补贴对投资决策影响显著

### 补贴构成

**STC PV补贴**（仅新建系统）：
```
补贴金额 = 光伏容量(kW) × Zone Rating × Deeming Period × STC单价
         = 光伏容量(kW) × 1.382 × 6 × 39
         ≈ 光伏容量(kW) × 323.5 AUD/kW
```

**STC Battery补贴**：
```
补贴金额 = floor(电池可用容量(kWh) × 9.3) × 39
         ≈ 电池可用容量(kWh) × 362.7 AUD/kWh
```

**州补贴**（需手动启用）：
- VIC州补贴：1,400 AUD
- VIC州无息贷款：1,400 AUD
- NSW VPP补贴：根据电池容量计算

## 政策敏感性分析

### 如果STC补贴减半

假设STC单价从39 AUD降至20 AUD：

| 系统 | 当前补贴 | 减半后补贴 | 投资成本增加 |
|------|---------|-----------|-------------|
| 10kW新建+20kWh电池 | ~10,000 | ~5,000 | +5,000 |
| 20kW新建+30kWh电池 | ~20,000 | ~10,000 | +10,000 |

**影响**：
- IRR下降2-3个百分点
- 回本周期延长2-4年
- 部分配置变为不经济

### 如果取消所有补贴

相当于"不考虑补贴模式"的结果：
- 小系统几乎全部不经济
- 中型系统IRR降至3-5%
- 大型系统IRR降至5-7%
- 市场推广难度大幅增加

## 建议

### 对于用户

1. **短期决策**：使用"考虑补贴模式"
   - 反映当前实际成本
   - 补贴政策相对稳定（1-2年内）

2. **长期规划**：参考"不考虑补贴模式"
   - 评估系统本身价值
   - 补贴可能逐步退坡

3. **风险评估**：对比两种模式
   - 了解补贴依赖程度
   - 评估政策变化风险

### 对于销售人员

1. **主推方案**：使用"考虑补贴模式"
   - IRR更有吸引力
   - 回本周期更短
   - 符合用户实际支出

2. **风险说明**：提及补贴政策
   - 说明当前补贴政策
   - 提示政策可能变化
   - 建议尽早安装

3. **保守客户**：展示"不考虑补贴模式"
   - 证明系统本身有价值
   - 即使无补贴也能回本
   - 增强客户信心

### 对于政策制定者

1. **补贴效果评估**：
   - 对比两种模式的IRR差异
   - 评估补贴对市场推广的作用
   - 优化补贴政策设计

2. **退坡策略**：
   - 逐步降低补贴比例
   - 确保系统本身经济性
   - 培育成熟市场

## 技术实现

### 代码逻辑

```javascript

    parseFloat(row['含税报价AUD']) :  // 不考虑补贴

```

```javascript
// 从命令行参数获取模式
const args = process.argv.slice(2);
const noSubsidy = args.includes('--no-subsidy');
```

## 常见问题

### Q1：为什么不考虑补贴模式的N/A更多？
**A**：投资成本更高，更多配置无法在20年内回本。

### Q2：应该用哪种模式做决策？
**A**：短期决策用考虑补贴模式，长期规划参考不考虑补贴模式。

### Q3：两种模式的自用率一样吗？
**A**：是的，自用率只与系统配置和用电模式有关，与投资成本无关。

### Q4：补贴政策会变化吗？
**A**：可能会。建议定期更新补贴参数重新计算。

### Q5：如何修改补贴参数？
**A**：编辑Quote/index-v1.1.html中的补贴参数，重新运行batch-calculator-v1.1.js生成新的CSV，然后运行IRR计算。

## 总结

两种计算模式各有用途：
- **考虑补贴**：反映用户实际成本，适合销售推广
- **不考虑补贴**：反映系统真实价值，适合政策分析

建议同时生成两种模式的数据，全面评估投资价值。
