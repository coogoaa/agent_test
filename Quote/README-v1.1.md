# 系统投入计算器 v1.1 更新说明

## 版本信息
- **版本号**: v1.1
- **更新日期**: 2025-11-12
- **文件**: 
  - `index-v1.1.html` - 主页面
  - `calculator-v1.1.js` - 计算逻辑

## 主要改动

### 1. 成本计算简化（第一个改动）

#### 原有规则
- 分别考虑 Key Products、Balance of System 和 Additional Charges
- 每个部分有独立的成本和利润率计算

#### v1.1 新规则
**不再区分 Key Products、BOS 和 Additional Charges**

直接使用以下单价进行计算：
- **面板单价**: 每kW面板报价（AUD/kW）
- **逆变器单价**: 每kW逆变器报价（AUD/kW）
- **电池单价**: 每kWh电池报价-标称容量（AUD/kWh）

**计算公式**：
```
税前整体报价 = 面板系统容量(kW) × 每kW面板报价 
             + 逆变器功率(kW) × 每kW逆变器报价 
             + 电池标称容量(kWh) × 每kWh电池报价
```

**项目类型差异**：
- **新建系统**: 考虑面板和逆变器的报价
- **储能扩容**: 面板和逆变器的报价为0（只计算电池）

**预设单价和可调整范围**：
| 项目 | 默认值 | 可调整范围 |
|------|--------|-----------|
| 每kW面板报价 | 540 AUD/kW | 300-1200 AUD/kW |
| 每kW逆变器报价 | 280 AUD/kW | 200-800 AUD/kW |
| 每kWh电池报价 | 865 AUD/kWh | 500-1500 AUD/kWh |

### 2. 补贴计算简化（第二个改动）

#### v1.1 新规则
**默认只计算**：
- ✅ STC PV Rebate（仅新建系统）
- ✅ STC Battery Rebate

**州补贴需手动开启**：
- ⬜ VIC州补贴（默认关闭，需勾选"启用VIC州补贴"）
- ⬜ NSW VPP补贴（默认关闭，需勾选"启用NSW VPP补贴"）

这样可以更灵活地控制补贴计算，避免自动计算不适用的州补贴。

### 3. 界面展示范围（第三个改动）

#### 新增功能
在最终报价的基础上，计算上下浮动范围：

**计算公式**：
```
展示下限 = 最终报价 × (1 - 浮动百分比)
展示上限 = 最终报价 × (1 + 浮动百分比)
```

**配置参数**：
- 参数名称：界面展示浮动百分比
- 默认值：5%
- 可在"成本参数"标签页中配置

**示例**：
- 最终报价：10,000 AUD
- 浮动百分比：5%
- 展示下限：9,500 AUD
- 展示上限：10,500 AUD

## 使用方法

### 1. 打开页面
在浏览器中打开 `index-v1.1.html`

### 2. 填写参数
按照标签页顺序填写：
1. **屋顶参数**: 面板数量、项目类型、地区
2. **方案参数**: 各方案的容量系数
3. **设备参数**: 面板功率、容配比等
4. **成本参数**: 
   - ⭐ 新增：每kW面板报价、每kW逆变器报价、每kWh电池报价
   - ⭐ 新增：界面展示浮动百分比
5. **补贴参数**: 
   - STC相关参数（默认启用）
   - ⭐ 新增：州补贴开关（默认关闭）

### 3. 计算结果
点击"💰 计算ABC三套方案"按钮后，会显示：
- 系统配置对比
- 税前报价细项（v1.1简化版）
- 含税报价
- 补贴细项
- 最终报价
- ⭐ **界面展示范围**（新增）

### 4. 查看详细步骤
点击"显示/隐藏详细步骤"按钮可查看每个方案的详细计算过程。

## 技术说明

### 计算流程
1. 根据屋顶面板数量和容量系数计算光伏容量
2. 根据方案类型确定逆变器功率（查表或公式）
3. 根据方案类型确定电池容量（查表或公式）
4. **v1.1**: 使用 kW/kWh 单价计算税前报价
5. 计算GST得到含税报价
6. **v1.1**: 只计算启用的补贴项
7. 计算最终报价
8. **v1.1**: 计算展示上下限

## 注意事项

1. **储能扩容项目**: 面板和逆变器报价自动为0
2. **州补贴**: 默认关闭，需要时请手动勾选启用
3. **单价范围**: 建议在推荐范围内调整，超出范围可能不符合市场实际
4. **展示浮动**: 用于给销售人员提供报价谈判空间
