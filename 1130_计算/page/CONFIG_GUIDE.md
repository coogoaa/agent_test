# ⚙️ 系统配置指南

## 概述

新增的配置管理系统允许用户自定义小时级仿真系统的核心参数，包括电池参数、电网限制、优化目标等。配置保存在浏览器本地存储中，重启后自动加载。

## 功能特性

### 1. 配置页面访问

- **位置**: 顶部导航栏 → ⚙️ 系统配置
- **URL**: `config-editor.html`
- **位置**: 在"新建系统"左侧，"批量处理"右侧

### 2. 配置项分类

#### 🔧 仿真参数配置

**电池参数**:
- **往返效率 (RTE)**: 0.7-1.0，默认 0.90 (90%)
  - 影响电池充放电损耗
  - η_charge = η_discharge = √RTE
  
- **放电深度 (DOD)**: 0.7-1.0，默认 0.90 (90%)
  - 可用容量 = 标称容量 × DOD
  
- **最大充电功率倍率**: 0.3-2.0C，默认 0.5C
  - 充电功率 = 电池容量 × 倍率
  
- **最大放电功率倍率**: 0.3-2.0C，默认 0.6C
  - 放电功率 = 电池容量 × 倍率

**电网参数**:
- **导出限制**: 0-20 kW，默认 5.0 kW
  - 限制向电网导出的最大功率
  
- **进口限制**: 0-50 kW，默认 0 (无限制)
  - 输入0表示无限制

**光伏参数**:
- **单板功率**: 0.3-0.6 kW，默认 0.44 kW (440W)
  
- **季节性调整幅度**: 0-0.5，默认 0.2 (±20%)
  - S_month[m] = 1.0 + amplitude × sin((m-5) × π/6)

**优化参数**:
- **二分法收敛阈值**: 0.1-2.0 kWh，默认 0.5 kWh
  - 电池容量优化的收敛条件
  
- **最大迭代次数**: 5-20次，默认 10次
  - 防止无限循环

#### 🎯 方案优化目标

**方案A - 高端型**:
- 夜间覆盖率目标: 50-100%，默认 90%
- 自给率目标: 50-100%，默认 70%

**方案B - 平衡型**:
- 夜间覆盖率目标: 50-100%，默认 80%
- 自耗率目标: 30-100%，默认 40%

**方案C - 经济型**:
- 夜间覆盖率目标: 30-100%，默认 50%

#### ⚡ 逆变器规格库

**启用/关闭开关**:
- **默认状态**: 关闭 ❌
- **关闭时**: 使用简化的逆变器选型逻辑
- **开启时**: 从规格库中选择最匹配的型号

**单相逆变器** (最大10kW):
```json
[
  "Sungrow SH5.0RS", 5.0,
  "Sungrow SH6.0RS", 6.0,
  "Sungrow SH8.0RS", 8.0,
  "Sungrow SH10RT", 10.0
]
```

**三相逆变器** (10-30kW):
```json
[
  "Sungrow SH10RT", 10.0,
  "Sungrow SH15T", 15.0,
  "Sungrow SH20T", 20.0,
  "Sungrow SH25T", 25.0,
  "Sungrow SH30T", 30.0
]
```

**格式说明**:
- 数组格式: ["型号1", 容量1, "型号2", 容量2, ...]
- 型号: 字符串
- 容量: 数字 (kW)

#### 🔋 电池规格库

**标准电池容量** (kWh):
```json
[5, 6.5, 9.6, 10, 13.5, 16, 20]
```

- 优化后会从这些标准值中选择最接近的
- 可以添加或删除容量选项

## 使用流程

### 1. 修改配置

1. 点击顶部导航 "⚙️ 系统配置"
2. 修改需要调整的参数
3. 点击 "💾 保存配置" 按钮
4. 看到绿色提示 "✅ 配置已保存"

### 2. 应用配置

配置保存后，下次运行仿真时会自动加载：

```
新建系统页面 → 选择房屋 → 开始仿真
                              ↓
                    自动加载保存的配置
                              ↓
                    使用配置参数进行计算
```

### 3. 恢复默认

如果配置出现问题，可以：
1. 点击 "🔄 恢复默认值" 按钮
2. 确认恢复
3. 所有参数恢复到系统默认值

### 4. 导出配置

可以导出配置文件备份：
1. 点击 "📥 导出配置" 按钮
2. 下载 `solarfit_config.json` 文件
3. 可用于分享或备份

## 配置影响

### 电池参数影响

**往返效率 (RTE)**:
- 影响充放电损耗
- RTE越高，能量损失越少
- 影响能量守恒验证结果

**放电深度 (DOD)**:
- 影响可用容量
- DOD越高，可用容量越大
- 但可能影响电池寿命

**充放电倍率**:
- 影响最大充放电功率
- 倍率越高，功率越大
- 影响电池响应速度

### 优化目标影响

**夜间覆盖率**:
- 目标越高，需要的电池容量越大
- 影响方案成本

**自给率/自耗率**:
- 影响PV容量和电池容量的平衡
- 目标越高，系统越复杂

### 逆变器规格库影响

**关闭状态** (默认):
- 使用简化逻辑
- 不依赖具体型号
- 计算更快

**开启状态**:
- 从规格库选择实际型号
- 更符合实际情况
- 可能找不到完全匹配的型号

## 最佳实践

### 1. 参数调整建议

**保守配置** (更可靠):
- RTE: 0.85-0.90
- DOD: 0.85-0.90
- 充放电倍率: 0.4-0.5C

**激进配置** (更高性能):
- RTE: 0.90-0.95
- DOD: 0.90-0.95
- 充放电倍率: 0.6-0.8C

### 2. 优化目标设置

**高端客户**:
- 方案A: 夜间90%+, 自给70%+
- 追求最大自给自足

**普通客户**:
- 方案B: 夜间80%, 自耗40%
- 平衡性能和成本

**预算有限**:
- 方案C: 夜间50%
- 最小化初始投资

### 3. 规格库管理

**建议关闭** (默认):
- 快速原型设计
- 不关心具体型号
- 多种品牌混合

**建议开启**:
- 需要精确报价
- 指定品牌型号
- 库存管理

## 故障排除

### 配置不生效

**问题**: 修改配置后仿真结果没变化

**解决**:
1. 确认点击了"保存配置"
2. 刷新页面重新运行仿真
3. 检查浏览器控制台是否有错误

### 配置格式错误

**问题**: 保存配置时报错

**解决**:
1. 检查JSON格式是否正确
2. 数组必须用方括号 []
3. 字符串必须用双引号 ""
4. 数字不要加引号

### 配置丢失

**问题**: 刷新页面后配置消失

**解决**:
1. 检查浏览器是否禁用localStorage
2. 检查是否在隐私模式
3. 尝试导出配置备份

## 技术细节

### 配置加载流程

```
页面加载
    ↓
loadSystemConfig()
    ↓
读取 localStorage['solarfit_config']
    ↓
存在? → 解析JSON → 返回配置
    ↓
不存在? → 返回默认配置
```

### 配置应用流程

```
startSimulation()
    ↓
config = loadSystemConfig()
    ↓
new DataSynthesizer(config.simulation)
new HourlySimulator(config.simulation)
new PlanGenerator(..., config)
    ↓
使用配置参数进行计算
```

### 开关实现

逆变器规格库开关使用CSS和JavaScript实现：

```javascript
// 开关状态
enabled = checkbox.checked

// 内容可见性
content.style.opacity = enabled ? '1' : '0.5'
content.style.pointerEvents = enabled ? 'auto' : 'none'
```
