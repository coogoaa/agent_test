# 📊 推算逻辑展示功能说明

## 新增功能概述

在 `equipment-recommender.html` 页面中新增了两个主要功能模块：

### 1. 方案推算逻辑详解 🧮

**位置**: 三套方案卡片下方

**功能**: 展示每个方案的完整推算过程，包含6个详细步骤

#### 步骤1: 负荷曲线生成
- 输入参数展示
- 完整计算公式
- 输出结果验证

#### 步骤2: PV发电曲线生成
- 插值查表法详解
- 季节性调整公式
- 容量因子计算

#### 步骤3: 逆变器选型
- 选型约束条件
- DC/AC比例计算
- 规格库选择逻辑

#### 步骤4: 电池容量优化
- 二分法算法详解
- 优化目标说明
- 标准化处理

#### 步骤5: 小时级仿真
- PV溢出优先充电策略
- 白天/夜间场景处理
- 年度汇总数据

#### 步骤6: KPI指标计算
- 5个核心KPI公式
- 实际计算结果
- 百分比展示

### 2. 小时级仿真结果可视化 📈

新增3个Tab页，展示推演过程：

#### Tab 1: 推演过程详解 🔢

**内容**:
- 典型时刻详细计算
- 中午12点白天场景示例
- 晚上8点夜间场景示例

**展示内容**:
```
输入条件 → 计算步骤 → 输出结果

示例 (白天):
- PV_t[12] = 10.5 kW
- Load_t[12] = 0.8 kW
- surplus = 9.7 kW
- 充电 6.75 kW
- 导出 2.95 kW
- SOC: 30% → 82.7%

示例 (夜间):
- PV_t[20] = 0 kW
- Load_t[20] = 1.5 kW
- 放电 1.5 kW
- SOC: 82.7% → 69.7%
```

#### Tab 2: 能量守恒验证 ⚖️

**内容**:
- 能量守恒方程展示
- 输入侧/输出侧详细数据
- 误差计算和验证
- 电池损耗详解

**验证公式**:
```
PV + Import = Load + Export + Clipped + Battery_Loss

输入侧:
- PV发电: xxx kWh
- 电网进口: xxx kWh
- 总输入: xxx kWh

输出侧:
- 负荷消耗: xxx kWh
- 电网导出: xxx kWh
- 裁切损失: xxx kWh
- 电池损耗: xxx kWh
- 总输出: xxx kWh

验证: 误差 < 0.1 kWh ✅
```

#### Tab 3: 电池优化过程 🔋

**内容**:
- 二分法迭代过程示意
- 每次迭代的详细数据
- 收敛性分析
- 三套方案对比表

**迭代示例**:
```
搜索空间: [0, 50] kWh

迭代1: C_mid = 25.0 kWh → 夜间覆盖 95% ✅ → 尝试更小
       新区间: [0, 25]

迭代2: C_mid = 12.5 kWh → 夜间覆盖 85% ✅ → 尝试更小
       新区间: [0, 12.5]

迭代3: C_mid = 6.25 kWh → 夜间覆盖 65% ❌ → 需要更大
       新区间: [6.25, 12.5]

...

收敛: Δ = 0.785 < 0.5 ✅
最优值: 10.16 kWh
标准化: 10 kWh
```

## 使用方法

### 查看方案推算逻辑

1. 完成仿真计算后，页面会自动显示"方案推算逻辑详解"模块
2. 默认显示方案A的推算过程
3. 点击上方的按钮可切换查看方案B或方案C
4. 每个步骤都有详细的公式和计算过程

### 查看推演过程

1. 滚动到"小时级仿真结果可视化"区域
2. 点击不同的Tab切换查看:
   - 📅 典型日能量流向 (原有功能)
   - 📊 方案KPI对比 (原有功能)
   - 🔢 推演过程详解 (新增)
   - ⚖️ 能量守恒验证 (新增)
   - 🔋 电池优化过程 (新增)

## 技术实现

### 新增函数

1. **renderCalculationLogic(results, planKey)**
   - 渲染方案推算逻辑
   - 支持方案切换
   - 动态生成HTML内容

2. **renderCalculationProcess(results)**
   - 渲染推演过程详解
   - 展示典型时刻计算
   - 白天/夜间场景示例

3. **renderEnergyBalance(results)**
   - 渲染能量守恒验证
   - 输入输出对比
   - 误差计算

4. **renderBatteryOptimization(results)**
   - 渲染电池优化过程
   - 二分法迭代展示
   - 三套方案对比

### 数据流

```
startSimulation()
    ↓
generateAllPlans()
    ↓
displayResults()
    ├─ renderCharts() (原有)
    ├─ renderCalculationLogic() (新增)
    ├─ renderCalculationProcess() (新增)
    ├─ renderEnergyBalance() (新增)
    └─ renderBatteryOptimization() (新增)
```

## 样式设计

### 颜色方案

- **方案推算逻辑**: 蓝色系 (border-blue-500)
- **推演过程**: 靛蓝/紫色系 (border-indigo-500)
- **能量守恒**: 绿色系 (border-green-500)
- **电池优化**: 紫色/粉色系 (border-purple-500)

- 使用卡片式设计
- 渐变色背景
- 左侧彩色边框
- 步骤编号圆形徽章
- 代码块使用等宽字体

## 公式展示

所有公式都使用 `font-mono` 字体，并带有适当的缩进和颜色：

```html
<p class="ml-4 text-gray-700">E_month[m] = E_annual × W_month[m]</p>
<p class="ml-4 text-gray-600">其中 W_month[m] 为第m月的用电比例权重</p>
```

## 交互功能

### 方案切换

- 点击方案按钮切换查看不同方案的推算逻辑
- 按钮状态会高亮显示当前选中的方案
- 内容会动态更新

### Tab切换

- 点击Tab按钮切换不同的可视化内容
- Tab状态会高亮显示
- 内容区域平滑切换
