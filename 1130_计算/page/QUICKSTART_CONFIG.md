# 🚀 配置功能快速开始

## 30秒快速体验

### 1. 访问配置页面
```
打开浏览器 → equipment-recommender.html
    ↓
点击顶部 "⚙️ 系统配置"
    ↓
进入配置页面
```

### 2. 修改一个参数
```
找到 "电池参数" → "往返效率 (RTE)"
    ↓
修改值: 0.90 → 0.95
    ↓
点击 "💾 保存配置"
    ↓
看到绿色提示 ✅
```

### 3. 验证配置生效
```
返回 "📊 新建系统"
    ↓
选择房屋 → 开始仿真
    ↓
查看结果 (使用新的RTE值)
```

## 常见使用场景

### 场景1: 我想提高电池效率

**目标**: 模拟更高效的电池系统

**步骤**:
1. 进入配置页面
2. 修改电池参数:
   - RTE: 0.90 → 0.95
   - DOD: 0.90 → 0.95
3. 保存配置
4. 重新运行仿真

**效果**:
- 电池损耗减少
- 自给率提高
- 能量守恒验证误差更小

---

### 场景2: 我想降低优化目标

**目标**: 生成更经济的方案

**步骤**:
1. 进入配置页面
2. 修改方案目标:
   - 方案A夜间覆盖: 90% → 80%
   - 方案B夜间覆盖: 80% → 70%
   - 方案C夜间覆盖: 50% → 40%
3. 保存配置
4. 重新运行仿真

**效果**:
- 电池容量减小
- 系统成本降低
- 夜间覆盖率降低

---

### 场景3: 我想使用具体的逆变器型号

**目标**: 从规格库选择实际型号

**步骤**:
1. 进入配置页面
2. 找到 "逆变器规格库"
3. 打开 "启用规格库" 开关
4. (可选) 修改规格库内容
5. 保存配置
6. 重新运行仿真

**效果**:
- 显示具体逆变器型号
- 更符合实际报价
- 可用于库存管理

---

### 场景4: 我想限制电网导出

**目标**: 模拟电网导出限制

**步骤**:
1. 进入配置页面
2. 修改电网参数:
   - 导出限制: 5.0 → 3.0 kW
3. 保存配置
4. 重新运行仿真

**效果**:
- 更多PV溢出被裁切
- 裁切率提高
- 需要更大的电池容量

---

### 场景5: 我想恢复默认设置

**目标**: 重置所有配置

**步骤**:
1. 进入配置页面
2. 点击 "🔄 恢复默认值"
3. 确认恢复
4. 看到提示 "已恢复默认配置"

**效果**:
- 所有参数恢复默认值
- 清除localStorage
- 下次运行使用默认配置

## 故障排除速查

### 问题: 配置不生效

**症状**: 修改配置后结果没变化

**解决**:
- ✅ 确认点击了 "保存配置"
- ✅ 刷新页面
- ✅ 重新运行仿真
- ✅ 检查浏览器控制台

---

### 问题: 保存失败

**症状**: 点击保存后报错

**解决**:
- ✅ 检查JSON格式
- ✅ 数组用 []
- ✅ 字符串用 ""
- ✅ 数字不加引号

---

### 问题: 配置丢失

**症状**: 刷新后配置消失

**解决**:
- ✅ 检查localStorage是否启用
- ✅ 退出隐私模式
- ✅ 导出配置备份
- ✅ 重新保存

## 快捷操作

### 导出配置
```
配置页面 → "📥 导出配置" → 下载JSON文件
```

### 备份配置
```
导出配置 → 保存到云盘/U盘 → 需要时手动复制粘贴
```

### 分享配置
```
导出配置 → 发送JSON文件 → 对方手动复制粘贴到配置页面
```
