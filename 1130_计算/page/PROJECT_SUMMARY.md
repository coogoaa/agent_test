## 📊 技术实现亮点

### 1. 小时级仿真引擎

**核心创新**:
- 从经验系数估算升级为8760小时动态仿真
- 每个方案执行8760次能量平衡计算
- 精确模拟电池充放电过程
- 考虑逆变器功率限制、导出限制、SOC约束

**性能优化**:
- 使用Float32Array优化内存占用
- 单次仿真耗时<1秒
- 三套方案并行生成耗时3-5秒

### 2. PV溢出优先充电策略

**策略描述**:
```
白天 (PV >= Load):
  1. PV优先供负荷
  2. 溢出优先充电池 (受充电功率、SOC上限限制)
  3. 剩余才并网导出 (受导出限制)
  4. 无法导出的部分被裁切

夜间 (PV < Load):
  1. PV供负荷
  2. 电池放电补充 (受放电功率、SOC下限限制)
  3. 剩余从电网进口
```

**优势**:
- 最大化电池利用率
- 减少并网依赖
- 提高自给率和夜间覆盖率

### 3. 电池容量优化算法

**二分法搜索**:
```javascript
// 在0-50kWh范围内搜索最优容量
while (maxKwh - minKwh > 0.5) {
    midKwh = (minKwh + maxKwh) / 2
    simulation = simulate(pvProfile, loadProfile, midKwh, ...)
    
    if (meetsTarget(simulation, targets)) {
        maxKwh = midKwh  // 满足目标，尝试更小容量
    } else {
        minKwh = midKwh  // 不满足，需要更大容量
    }
}
```

**标准化处理**:
- 将优化结果标准化到常见规格 [5, 6.5, 9.6, 10, 13.5, 16, 20]
- 避免非标准容量带来的采购困难

### 4. 数据合成技术

**负荷曲线生成**:
- 输入: 年用电量 + 州代码
- 应用: 月度分配系数 (12个月) + 小时分配系数 (24小时)
- 输出: 8760小时负荷曲线
- 验证: 总和误差<0.1%

**PV发电曲线生成**:
- 输入: 坡面方位角 + 面板数量
- 方法: 插值查表法 (8个标准方位角模板)
- 优化: 季节性调整因子 (夏季×1.2, 冬季×0.8)
- 输出: 8760小时发电曲线

## 🎓 关键学习点

### 1. 小时级仿真的必要性

**为什么不能用日均法？**
- 负荷和PV发电都有明显的时序特征
- 电池充放电受功率和SOC约束
- 并网导出有功率限制
- 裁切量只能通过小时级计算

### 2. 电池容量优化的复杂性

**为什么不能用简单公式？**
- 电池容量影响自耗率、自给率、夜间覆盖率
- 需要在多个目标之间权衡
- 不同方案有不同的优化目标
- 二分法可以快速收敛到最优解

### 3. 能量守恒的重要性

**为什么要验证能量守恒？**
- 确保仿真逻辑正确
- 发现潜在的计算错误
- 提高结果可信度
- 符合物理定律
