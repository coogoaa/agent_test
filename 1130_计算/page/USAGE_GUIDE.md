## 🚀 快速上手

### 第一步：打开系统

在浏览器中打开 `equipment-recommender.html` 文件。推荐使用现代浏览器（Chrome、Firefox、Edge）。

### 第二步：选择房屋

从"选择房屋样本"下拉列表中选择一个GIS房屋ID。系统会自动显示该房屋的基本信息：
- 坡面数量
- 总面板容量
- 总装机容量 (kW)

### 第三步：配置参数

1. **用户所在州** - 选择用户所在的澳洲州/领地
   - 影响年用电量默认值
   - 影响负荷曲线生成
   - 影响补贴计算 (Zone Rating)

2. **电网相位** - 选择单相或三相
   - 单相: 逆变器≤10kW, 导出限制≤5kW
   - 三相: 逆变器≤30kW, 导出限制≤15kW

### 第四步：开始仿真

点击"🚀 开始仿真计算"按钮，系统将：
1. 生成8760小时负荷曲线
2. 生成8760小时PV发电曲线
3. 执行三套方案的小时级仿真
4. 计算精确的KPI指标
5. 渲染可视化图表

**预计耗时**: 3-5秒

### 第五步：查看结果

系统会自动滚动到结果区域，展示：
- 三套方案的详细配置
- 仿真KPI指标
- 典型日能量流向图
- 方案KPI对比图

## 🔍 功能详解

### 1. 屋顶坡面详情

点击"查看该房屋屋顶坡面详细数据"可展开表格，显示：

| 列名 | 说明 |
|------|------|
| Slope ID | 坡面编号 |
| 方位角 | 坡面朝向角度 (0°=北, 90°=东, 180°=南, 270°=西) |
| 朝向 | 方位角的文字描述 |
| 最大面板数 | 该坡面可安装的最大面板数量 |
| 发电潜力评分 | 0-100分，综合考虑方位角、倾角、遮挡 |
| 评分可视化 | 绿色进度条直观显示评分 |

**评分规则**:
- 北向 (0°) 最佳，得分最高
- 南向 (180°) 最差，得分最低
- 东西向 (90°/270°) 居中

### 2. 三套方案对比

#### 方案A - 高端型 (Maximum)

**特点**:
- 🎯 **目标**: 最大化能源独立性
- ☀️ **PV策略**: 满铺所有可用坡面
- ⚡ **逆变器**: 选择最大规格 (满足DC/AC≤2.0)
- 🔋 **电池**: 大容量配置
- 📊 **KPI目标**: 夜间覆盖≥90%, 自给率≥70%

**适用场景**:
- 追求能源独立的用户
- 屋顶空间充足
- 预算较为宽裕
- 希望最大化利用屋顶资源

#### 方案B - 平衡型 (Balanced)

**特点**:
- 🎯 **目标**: 性价比最优
- ☀️ **PV策略**: 选择高效坡面，目标10-13kW
- ⚡ **逆变器**: 常用档位 (5/8/10kW)
- 🔋 **电池**: 适中容量
- 📊 **KPI目标**: 夜间覆盖≥80%, 自耗率≥40%

**适用场景**:
- 追求性价比的用户
- 主流配置需求
- 预算适中
- 希望平衡投资与收益

#### 方案C - 经济型 (Economy)

**特点**:
- 🎯 **目标**: 最小化初期投资
- ☀️ **PV策略**: 固定6.6kW配置
- ⚡ **逆变器**: 单相5kW
- 🔋 **电池**: 基础配置 (5-6.5kWh)
- 📊 **KPI目标**: 夜间覆盖≥50%

**适用场景**:
- 预算有限的用户
- 入门级配置
- 希望快速回本
- 对能源独立性要求不高

### 3. 仿真KPI指标

每个方案卡片都会显示以下KPI:

#### 自耗率 (Self-consumption Rate)
- **定义**: PV发电中被自己消耗的比例
- **计算**: (PV发电 - 并网导出 - 裁切) / PV发电
- **意义**: 越高表示PV发电被更充分利用
- **理想值**: >40%

#### 自给率 (Autarky Rate)
- **定义**: 负荷中由PV+电池满足的比例
- **计算**: 1 - (电网进口 / 总负荷)
- **意义**: 越高表示对电网依赖越小
- **理想值**: >60%

#### 夜间覆盖率 (Night Coverage Rate)
- **定义**: 夜间负荷被电池覆盖的比例
- **时段**: 18:00-6:00
- **计算**: 夜间电池放电 / 夜间总负荷
- **意义**: 越高表示夜间备电能力越强
- **理想值**: >70%

#### 裁切率 (Clipping Rate)
- **定义**: PV发电被裁切的比例
- **原因**: 电池已满 + 并网导出受限
- **计算**: 裁切量 / PV发电
- **意义**: 越低越好，表示PV利用更充分
- **理想值**: <5%

### 4. 可视化图表

#### 典型日能量流向图

**功能**: 展示24小时的能量流动情况

**包含曲线**:
- 🟡 **PV发电** - 黄色曲线，显示光伏发电功率
- 🔴 **负荷** - 红色曲线，显示用电负荷
- 🟢 **电池充电** - 绿色区域 (未来版本)
- 🔵 **电池放电** - 蓝色区域 (未来版本)

**如何解读**:
1. 白天PV曲线高于负荷 → 有盈余，可充电或导出
2. 夜间负荷曲线高于PV → 需要电池放电或电网进口
3. 观察两条曲线的交叉点，了解能量转换时刻

**切换方案**: 点击上方的"方案A/B/C"按钮可切换查看不同方案

#### 方案KPI对比图

**功能**: 柱状图对比三套方案的KPI

**包含指标**:
- 自耗率
- 自给率
- 夜间覆盖率
- 溢出吸收率

**如何解读**:
- 柱子越高表示该指标表现越好
- 紫色=方案A, 蓝色=方案B, 绿色=方案C
- 一目了然地对比三套方案的性能差异

## 📊 结果解读

### 如何选择合适的方案？

#### 优先考虑方案A，如果:
- ✅ 屋顶空间充足
- ✅ 预算宽裕 (>$25,000)
- ✅ 追求能源独立
- ✅ 希望最大化利用屋顶
- ✅ 夜间用电量大

#### 优先考虑方案B，如果:
- ✅ 追求性价比
- ✅ 预算适中 ($15,000-$25,000)
- ✅ 主流配置需求
- ✅ 希望平衡投资与收益
- ✅ 大多数用户的选择

#### 优先考虑方案C，如果:
- ✅ 预算有限 (<$15,000)
- ✅ 入门级需求
- ✅ 希望快速回本
- ✅ 对能源独立性要求不高
- ✅ 用电量较小

### KPI指标参考值

| 指标 | 优秀 | 良好 | 一般 | 需改进 |
|------|------|------|------|--------|
| 自耗率 | >50% | 40-50% | 30-40% | <30% |
| 自给率 | >70% | 60-70% | 50-60% | <50% |
| 夜间覆盖率 | >80% | 70-80% | 60-70% | <60% |
| 裁切率 | <3% | 3-5% | 5-8% | >8% |

## ❓ 常见问题

### Q1: 为什么仿真需要3-5秒？

**A**: 系统需要执行8760小时 (365天×24小时) 的逐小时能量平衡计算，包括:
- 生成8760小时负荷曲线
- 生成8760小时PV发电曲线
- 执行三套方案的仿真 (每套8760次循环)
- 计算多个KPI指标
- 优化电池容量 (二分法迭代)

### Q2: 为什么方案A的裁切率较高？

**A**: 方案A采用满铺策略，PV装机容量大，在以下情况会产生裁切:
- 电池已充满 (SOC=100%)
- 并网导出达到上限 (单相5kW/三相15kW)
- 剩余的PV发电无处可去，被裁切

**解决方案**:
- 增加电池容量 (但会增加成本)
- 升级到三相电网 (提高导出限制)
- 接受一定的裁切率 (3-5%是可接受的)

### Q3: 夜间覆盖率是如何计算的？

**A**: 
1. 定义夜间时段: 18:00-6:00 (共12小时)
2. 统计夜间总负荷: 这12小时的用电量总和
3. 统计夜间电池放电: 这12小时的电池放电总和
4. 计算比例: 夜间电池放电 / 夜间总负荷

**注意**: 夜间覆盖率<100%是正常的，因为:
- 电池容量有限
- 需要保留一定的SOC避免过放
- 部分负荷仍需从电网进口

### Q4: 为什么不同州的结果差异很大？

**A**: 主要因素:
1. **年用电量不同** - TAS最高(10148kWh), WA最低(5617kWh)
2. **负荷曲线不同** - 各州的24小时用电模式不同
3. **月度分布不同** - 夏季/冬季用电比例不同
4. **补贴系数不同** - Zone Rating影响补贴金额

### Q5: 如何理解DC/AC容配比？

**A**: 
- **定义**: PV额定功率(DC) / 逆变器功率(AC)
- **澳洲规范**: Hybrid系统通常≤200% (2.0)
- **意义**: 允许一定的超配，因为PV很少达到额定功率
- **示例**: 13.2kW PV + 8kW逆变器 = 165%容配比 ✅

**为什么允许超配？**
- PV实际输出受天气、温度、角度影响
- 很少同时达到100%额定功率
- 超配可提高系统经济性

## 🔧 高级用法

### 1. 查看控制台日志

打开浏览器开发者工具 (F12)，查看Console标签页，可以看到:
- 负荷曲线生成日志
- PV发电曲线生成日志
- 仿真过程日志
- 能量守恒验证结果
- 电池容量优化过程

### 2. 自定义房屋数据

如果要添加自定义房屋，可以修改 `equipment-recommender.html` 中的 `HOUSE_DATA_RAW` 变量:

```javascript
const HOUSE_DATA_RAW = `id_0	slope	aspect	nums
999	slope 1	0	20
999	slope 2	180	15`;
```

格式说明:
- `id_0`: 房屋ID
- `slope`: 坡面编号
- `aspect`: 方位角 (度)
- `nums`: 最大面板数

### 3. 调整仿真参数

在核心算法模块中可以调整:

**DataSynthesizer.js**:
- 修改月度/小时用电比例
- 调整PV发电模板
- 修改季节性调整因子

**HourlySimulator.js**:
- 修改电池效率 (RTE)
- 调整SOC上下限
- 修改夜间时段定义

**PlanGenerator.js**:
- 调整方案目标KPI
- 修改电池容量标准规格
- 调整逆变器选型逻辑

### 4. 导出仿真数据

在浏览器控制台中执行:

```javascript
// 导出完整仿真结果
console.log(JSON.stringify(AppData.simulationResults, null, 2));

// 导出方案A的时序数据
const planA = AppData.simulationResults.planA;
console.log('方案A时序数据:', planA.simulation.time_series);
```

### 5. 性能优化建议

如果仿真速度较慢:
1. 使用现代浏览器 (Chrome/Edge最快)
2. 关闭其他占用资源的标签页
3. 考虑使用Web Worker (未来版本)
4. 减少仿真天数 (修改HourlySimulator构造函数)
