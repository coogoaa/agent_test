## 澳洲家庭光伏组件推断

流程拆解为 **5 个核心步骤**。这套流程是**“以终为始”**的：先算用户晚上缺多少电，再配电池，再配逆变器，最后反推需要多少光伏板，最后看屋顶装不装得下。

### 第一步：负荷分析 (Load Analysis)

**目标**：算出用户“晚上”到底用多少电（决定电池大小），以及“瞬间”最大功率（决定逆变器下限）。

**计算逻辑**：
1.  **日均用电** = 年用电 / 365。
2.  **夜间用电 (Nightly Consumption)** = 日均用电 × (18:00 到 次日 06:00 的用电比例之和)。
    *   *注：为了简化，我们可以直接预设一个“夜间比例系数”，比如 45%。*
3.  **峰值功率 (Peak Demand)** = 日均用电 × 某小时最大比例 × 1.5 (波动系数)。

**代码实现**：

```python
def step1_analyze_load(user_input, hourly_ratios):
    """
    计算夜间用电量和峰值功率
    """
    annual_kwh = user_input["annual_usage_kwh"]
    daily_avg_kwh = annual_kwh / 365.0
    
    # 1. 计算夜间用电量 (假设夜间定义为 18:00 - 06:00)
    # 我们需要从 hourly_ratios 中提取对应时段的比例之和
    # 假设 hourly_ratios 是一个长度 24 的数组，索引 0 代表 00:00-01:00
    night_hours_indices = [18, 19, 20, 21, 22, 23, 0, 1, 2, 3, 4, 5]
    night_ratio_sum = sum([hourly_ratios[i] for i in night_hours_indices])
    
    nightly_consumption_kwh = daily_avg_kwh * night_ratio_sum
    
    # 2. 估算峰值功率 (Peak Power)
    # 找出一天中用电比例最高的小时
    max_hourly_ratio = max(hourly_ratios)
    max_hourly_kwh = daily_avg_kwh * max_hourly_ratio
    
    # 乘以 1.5 系数估算瞬时峰值 (经验值)
    peak_power_kw = max_hourly_kwh * 1.5
    
    return {
        "daily_avg_kwh": daily_avg_kwh,
        "nightly_consumption_kwh": nightly_consumption_kwh,
        "peak_power_kw": peak_power_kw
    }
```

### 第二步：电池定容 (Battery Sizing)

**目标**：根据不同的策略（A/B/C），给用户配多大的电池。

**计算逻辑**：
1.  **目标容量** = 夜间用电量 × 策略系数 (0.4 / 1.0 / 1.5)。
2.  **档位匹配**：将计算出的目标容量，靠拢到标准电池规格（如 5, 10, 13.5, 20 kWh）。

**代码实现**：

```python
def step2_size_battery(load_analysis, strategy_type):
    """
    根据策略计算推荐电池容量
    """
    nightly_load = load_analysis["nightly_consumption_kwh"]
    ratio = STRATEGY_CONFIG[strategy_type]["battery_ratio"]
    
    # 1. 计算理论目标容量
    target_capacity = nightly_load * ratio
    
    # 2. 标准电池库匹配 (这里模拟几个常见规格)
    # 逻辑：找最接近且稍大的规格
    standard_batteries = [5.0, 9.6, 13.5, 19.2] # kWh
    
    selected_battery_kwh = 5.0 # 默认最小
    for bat in standard_batteries:
        if bat >= target_capacity * 0.9: # 允许 10% 的误差向下兼容
            selected_battery_kwh = bat
            break
    
    # 如果需求超大，就选最大的
    if target_capacity > standard_batteries[-1]:
        selected_battery_kwh = standard_batteries[-1]
        
    return selected_battery_kwh
```

### 第三步：逆变器选型 (Inverter Selection)

**目标**：选一个能带得动电池，又符合澳洲单相电规定的逆变器。

**计算逻辑**：
1.  **下限**：逆变器功率至少要能支持电池的充放电（通常电池功率是容量的 0.5倍，例如 10kWh 电池对应 5kW 功率）。
2.  **上限**：澳洲单相电，逆变器不能超过 10kW。
3.  **选择**：在下限和上限之间，选一个标准档位 (5, 6, 8, 10 kW)。

**代码实现**：

```python
def step3_select_inverter(battery_kwh, peak_load_kw):
    """
    选择单相混合逆变器
    """
    # 1. 确定最小需求
    # 电池充放电功率通常为容量的 0.5C (例如 10kWh -> 5kW)
    min_inverter_kw_by_battery = battery_kwh * 0.5
    
    # 2. 确定标准档位
    standard_inverters = [5.0, 6.0, 8.0, 10.0]
    
    selected_inverter_kw = 5.0
    
    # 3. 匹配逻辑
    # 优先满足电池功率，其次考虑覆盖一部分家庭峰值负载
    target_inverter_kw = max(min_inverter_kw_by_battery, peak_load_kw * 0.7)
    
    for inv in standard_inverters:
        if inv >= target_inverter_kw:
            selected_inverter_kw = inv
            break
            
    # 4. 强制兜底：单相不能超过 10kW
    if selected_inverter_kw > 10.0:
        selected_inverter_kw = 10.0
        
    return selected_inverter_kw
```

### 第四步：光伏反推 (Target PV Sizing)

**目标**：根据逆变器大小和电池大小，算出**“理想状态下”**应该铺多少板子（高容配比）。

**计算逻辑**：
1.  **确定容配比 (DC/AC Ratio)**：
    *   电池小 (<7kWh) -> 容配比 1.5
    *   电池大 (>=7kWh) -> 容配比 1.8 (澳洲黄金配置)
2.  **目标光伏功率** = 逆变器功率 × 容配比。
3.  **目标板子数量** = 目标光伏功率 / 单块板功率。

**代码实现**：

```python
import math

def step4_calculate_target_pv(inverter_kw, battery_kwh, panel_watts):
    """
    反推需要多少块光伏板
    """
    # 1. 动态确定容配比
    if battery_kwh < 7.0:
        dc_ac_ratio = 1.5
    else:
        dc_ac_ratio = 1.8 # 有大电池，可以多铺板子
        
    # 2. 计算目标直流容量 (kW)
    target_dc_kw = inverter_kw * dc_ac_ratio
    
    # 3. 换算成板子数量 (向上取整，多发点电总是好的)
    target_panel_count = math.ceil((target_dc_kw * 1000) / panel_watts)
    
    return {
        "target_dc_kw": target_dc_kw,
        "target_panel_count": target_panel_count,
        "applied_ratio": dc_ac_ratio
    }
```

### 第五步：物理校验与排布 (Physical Roof Check)

**目标**：拿着“理想板子数量”，去屋顶上试着铺。如果铺不下，就砍掉；如果某面铺太少（启动电压不够），就舍弃该面。

**计算逻辑**：
1.  **排序**：把屋顶坡面按效率（Efficiency）从高到低排序（先铺北面，再铺东西，最后南面）。
2.  **填充**：一个面一个面地填，直到填满“目标数量”或者屋顶没地儿了。
3.  **电压校验**：检查每个面铺的数量。如果某面数量 < 4 块（启动电压不足），则该面的板子数量归零。
4.  **汇总**：得出最终实际能装的数量。

**代码实现**：

```python
def step5_physical_layout(target_panel_count, roof_planes, panel_specs, inverter_specs):
    """
    在屋顶上实际排布，并进行电气校验
    """
    # 1. 按效率排序屋顶 (优先铺好的面)
    sorted_planes = sorted(roof_planes, key=lambda x: x['efficiency'], reverse=True)
    
    remaining_panels_to_install = target_panel_count
    installed_panels_per_plane = {} # 记录结果
    
    # 2. 贪心算法填充
    for plane in sorted_planes:
        plane_id = plane['plane_id']
        max_capacity = plane['max_panels']
        
        if remaining_panels_to_install > 0:
            # 这个面能装多少？取 剩余需求 和 物理上限 的较小值
            install_on_this_plane = min(remaining_panels_to_install, max_capacity)
            installed_panels_per_plane[plane_id] = install_on_this_plane
            remaining_panels_to_install -= install_on_this_plane
        else:
            installed_panels_per_plane[plane_id] = 0
            
    # 3. 启动电压校验 (Min String Check)
    # 最小板数 = 启动电压 / 面板工作电压 (向上取整)
    min_panels_per_string = math.ceil(inverter_specs['v_start'] / panel_specs['v_mp'])
    # 通常是 100/32 = 3.125 -> 4块
    
    final_total_panels = 0
    final_layout = {}
    
    for plane_id, count in installed_panels_per_plane.items():
        if count > 0 and count < min_panels_per_string:
            # 如果这个面铺了，但少于4块，逆变器起不来，必须舍弃 (或者逻辑复杂点：挪到其他面，这里先简化为舍弃)
            final_layout[plane_id] = 0
            # print(f"警告: 坡面 {plane_id} 数量 {count} 不足启动电压，已移除")
        else:
            final_layout[plane_id] = count
            final_total_panels += count
            
    # 4. 计算最终系统容量
    final_system_kw = (final_total_panels * panel_specs['watts']) / 1000.0
    
    return {
        "final_panel_count": final_total_panels,
        "final_system_kw": final_system_kw,
        "layout_detail": final_layout
    }
```

### 总结：主程序调用流

把上面 5 步串起来，就是你的核心业务逻辑：

```python
def generate_solar_proposal(user_input, roof_data, strategy="B"):
    # 1. 负荷分析
    load_data = step1_analyze_load(user_input, STATE_HOURLY_RATIOS[user_input['state']])
    
    # 2. 选电池
    battery_kwh = step2_size_battery(load_data, strategy)
    
    # 3. 选逆变器
    inverter_kw = step3_select_inverter(battery_kwh, load_data['peak_power_kw'])
    
    # 4. 算理想光伏
    target_pv_data = step4_calculate_target_pv(inverter_kw, battery_kwh, PANEL_SPECS['watts'])
    
    # 5. 屋顶实际排布
    final_system = step5_physical_layout(
        target_pv_data['target_panel_count'], 
        roof_data, 
        PANEL_SPECS, 
        INVERTER_SPECS
    )
    
    return {
        "strategy": STRATEGY_CONFIG[strategy]['name'],
        "battery_size_kwh": battery_kwh,
        "inverter_size_kw": inverter_kw,
        "pv_system_kw": final_system['final_system_kw'],
        "panel_count": final_system['final_panel_count'],
        "layout": final_system['layout_detail']
    }
```
