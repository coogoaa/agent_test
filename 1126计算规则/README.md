# 澳洲家庭光伏组件推断计算器

## 📋 项目说明

这是一个基于"以终为始"理念的澳洲家庭光伏系统配置计算器，通过5步推断流程，从用户用电需求反推最优的光伏、电池和逆变器配置方案。

## 🎯 核心特点

- **5步推断流程**：负荷分析 → 电池定容 → 逆变器选型 → 光伏反推 → 物理校验
- **详细计算步骤**：每一步都展示完整的计算公式和中间结果
- **三种策略方案**：经济型(A)、平衡型(B)、高端型(C)
- **真实数据支持**：基于澳洲各州实际用电曲线数据
- **物理约束校验**：考虑屋顶实际情况和电气启动要求

## 📊 计算流程详解

### 第1步：负荷分析 (Load Analysis)
- 计算日均用电量
- 分析夜间用电量（18:00-06:00）
- 估算峰值功率需求

### 第2步：电池定容 (Battery Sizing)
- 根据策略系数计算目标容量
  - 经济型：夜间用电 × 0.4
  - 平衡型：夜间用电 × 1.0
  - 高端型：夜间用电 × 1.5
- 匹配标准电池规格：5.0, 9.6, 13.5, 19.2 kWh

### 第3步：逆变器选型 (Inverter Selection)
- 满足电池充放电功率需求（容量×0.5C）
- 覆盖家庭峰值负载（峰值×0.7）
- 符合澳洲单相电上限（≤10kW）

### 第4步：光伏反推 (Target PV Sizing)
- 根据电池大小确定容配比
  - 小电池(<7kWh)：1.5
  - 大电池(≥7kWh)：1.8（澳洲黄金配置）
- 计算理想面板数量

### 第5步：物理校验与排布 (Physical Roof Check)
- 按效率排序屋顶坡面
- 贪心算法分配面板
- 电压启动校验（最少4块/串）
- 输出最终可行方案

## 📝 输入参数说明

### 用户基础信息
- **年用电量**：用户全年总用电量（kWh）
- **所在州**：NSW/VIC/QLD/SA/WA/TAS/NT/ACT
- **邮编**：用于未来扩展（如区域补贴）

### 屋顶信息
- **坡面ID**：标识符（A, B, C...）
- **方位角**：0=北, 90=东, 180=南, 270=西
- **倾角**：屋顶倾斜角度
- **最大面板数**：该坡面物理上限
- **效率评分**：0-1，考虑朝向和遮挡

### 硬件参数
- **单块面板功率**：默认440W
- **面板工作电压**：默认32V
- **逆变器启动电压**：默认100V
- **单相最大功率**：默认10kW

## ⚙️ 参数配置功能

新增的参数配置页面支持：

### 1️⃣ 用户基础信息
- 选择州自动更新对应的年用电量和邮编
- 支持8个州/领地的数据

### 2️⃣ 各州用电曲线模型
- 展示和编辑各州全年用电量
- 展示和编辑12个月的用电比例
- 展示和编辑24小时的用电比例
- 预留曲线图可视化位置

### 3️⃣ GIS 屋顶识别结果
- 紧凑的表单布局
- 支持添加/删除多个屋顶坡面
- 配置方位角、倾角、最大面板数、效率评分

### 4️⃣ 硬件参数配置
- **面板参数**：功率、工作电压、开路电压、工作电流
- **逆变器参数**：启动电压、最大电压、单相/三相功率
- **电池参数**：标准容量、DoD、RTE、C-Rate（预留）

### 5️⃣ 策略配置
- 支持修改三种策略的名称
- 支持修改电池容量系数（battery_ratio）
- 实时显示计算公式

### 💾 配置管理
- **导出配置**：保存为JSON文件
- **导入配置**：从JSON文件加载
- **应用到计算器**：保存到浏览器localStorage
- **恢复默认值**：一键重置

## 💡 使用示例

1. 打开 `solar-calculator.html`
2. 输入用户年用电量（如：8000 kWh）
3. 选择所在州（如：NSW）
4. 配置屋顶信息（可添加多个坡面）
5. 点击"开始计算"
6. 查看A/B/C三种方案的详细计算过程
7. 选择最适合的方案
