# 计算差异说明

## 🔍 问题发现

主页面 `solar-calculator.html` 和测试页面 `test-panel-iteration.html` 使用了**不同的成本参数**，导致计算结果不一致。

---

## 📊 参数差异对比

### 成本参数

| 参数 | 主页面 (solar-calculator.html) | 测试页面 (test-panel-iteration.html) | 差异 |
|------|-------------------------------|-------------------------------------|------|
| **面板单价** | **540 AUD/kW** | **1200 AUD/kW** | **2.22倍** ❌ |
| 逆变器单价 | 280 AUD/kW | 280 AUD/kW | ✅ 相同 |
| 电池单价 | 865 AUD/kWh | 865 AUD/kWh | ✅ 相同 |

### 代码位置

**主页面 (solar-calculator.js:609):**
```javascript
const costConfig = {
    panel_price_per_kw: parseFloat(document.getElementById('config_panel_price_per_kw')?.value || 540),
    inverter_price_per_kw: parseFloat(document.getElementById('config_inverter_price_per_kw')?.value || 280),
    battery_price_per_kwh: parseFloat(document.getElementById('config_battery_price_per_kwh')?.value || 865),
    // ...
};
```

**测试页面 (test-panel-iteration.html:154-156):**
```javascript
function calculateSimpleCost(systemResult) {
    const panelPricePerKw = 1200; // AUD/kW  ← 硬编码！
    const inverterPricePerKw = 280; // AUD/kW
    const batteryPricePerKwh = 865; // AUD/kWh
    // ...
}
```

---

## 💡 为什么会有这个差异？

### 主页面的540 AUD/kW

这是**面板的批发价或成本价**，可能包含：
- 面板本身的成本
- 基础安装费用
- 不含高额利润

### 测试页面的1200 AUD/kW

这是**面板的零售价或含安装价**，可能包含：
- 面板成本
- 完整安装费用
- 人工成本
- 利润空间

---

## 📋 15块面板成本对比示例

### 平衡型 (B) - 光伏6.60kW

#### 主页面计算（540 AUD/kW）
```
面板成本 = 6.60 × 540 = $3,564
逆变器成本 = 8.0 × 280 = $2,240
电池成本 = 13.5 × 865 = $11,678

总成本 = $17,482
不含电池成本 = $5,804
kW单价 = $5,804 / 6.60 = $879/kW
```

#### 测试页面计算（1200 AUD/kW）
```
面板成本 = 6.60 × 1200 = $7,920
逆变器成本 = 8.0 × 280 = $2,240
电池成本 = 13.5 × 865 = $11,678

总成本 = $21,838
不含电池成本 = $10,160
kW单价 = $10,160 / 6.60 = $1,539/kW
```

#### 差异
```
面板成本差异: $7,920 - $3,564 = $4,356 (122%增加)
总成本差异: $21,838 - $17,482 = $4,356
kW单价差异: $1,539 - $879 = $660/kW (75%增加)
```

## ⚠️ 其他差异

### 1. 税费和补贴

**主页面：**
- ✅ 包含GST税费（10%）
- ✅ 包含STC补贴（光伏+电池）
- ✅ 包含州补贴（VIC/NSW）
- ✅ 计算最终报价

**测试页面：**
- ❌ 不含税费
- ❌ 不含补贴
- ❌ 只显示税前成本

### 2. 成本计算公式

**主页面（完整版）：**
```javascript
税前成本 = 面板成本 + 逆变器成本 + 电池成本
含税报价 = 税前成本 × 1.1
STC补贴 = (光伏STC + 电池STC) × 单价
州补贴 = VIC补贴 或 NSW PRC补贴
最终报价 = 含税报价 - 总补贴
```

**测试页面（简化版）：**
```javascript
总成本 = 面板成本 + 逆变器成本 + 电池成本
// 没有税费和补贴
```

2. **次要差异：** 测试页面不含税费和补贴
3. **建议：** 统一使用主页面的参数配置系统
