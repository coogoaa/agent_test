# 用户输入处理

本文档详细说明用户输入如何被处理并转换为计算所需的变量。

---

## 1. 输入数据流

```
用户输入
    ↓
┌─────────────────────────────────────────────────────────────┐
│                      输入项目                                │
├─────────────────────────────────────────────────────────────┤
│ • 邮编 → 经纬度、州、配电商                                   │
│ • 系统容量、朝向、倾角                                        │
│ • 电池容量、效率、保留比例                                    │
│ • 年电费、每度电价、日供电费、上网电价                         │
└─────────────────────────────────────────────────────────────┘
    ↓
后端处理 + 前端变量初始化
    ↓
variables 对象
```

## 2. 邮编处理

### 2.1 API 调用

```javascript
// 文件: shared_calc.js
sCalc.getPostcodeInfo = function(elem, updateStateDefaults, options = {}) {
    $.ajax({
        url: '/solar-calculator/postcodeInformation/',
        data: {
            postcode: elem.val()  // 用户输入的邮编
        },
        success: function(result) {
            // 处理返回数据
        }
    });

```

### 2.2 API 返回数据结构

```javascript
result.response = {
    lat: -37.8136,                    // 纬度
```

### 2.3 处理流程

```javascript
// Step 1: 设置经纬度

$('#postcode-lon').val(result.response.lon);

// Step 2: 设置州
$('#postcode-state').val(result.response.state);

// Step 3: 加载州默认值
updateStateDefaults(result.response.isEnergex ? 'Energex' : result.response.state);

// Step 4: 设置配电商和出口限制
const distributors = result.response.solarDistributors;
const isThreePhase = $('#three_phase').is(':checked');
const phaseKey = isThreePhase ? 'three' : 'single';
const exportLimit = exportLimitRates[distributorName][phaseKey];
$('#export-limit').val(exportLimit);
```

### 2.4 州默认值加载

```javascript
// 文件: custom.js
Calcs.stateDefaults = function(state) {
    var defaults = state_defaults[state];
    
    // 设置 FiT
    $('#FiT').val(defaults['FiT'] + 'c');
    
    // 设置 kWhCost
    $('#kWhCost').val(defaults['kWhCost'] + 'c');
    
    // 设置年度电费
    $('#annual-bill').val(defaults['annual_bill']);
    
    // 计算日供电费
    var dailyCharge = 0;
    Object.values(defaults['charge']).forEach(function(seasonCharge) {
        dailyCharge += seasonCharge;
    });
    dailyCharge = dailyCharge / 365 * 100;  // 转换为分/天
    $('#daily-charge').val(dailyCharge.toFixed(2));
}
```

```html
        Generic 10kWh Lithium Battery
    </option>
    <option value="custom-battery">My battery isn't on this list</option>
</select>
```

### 4.2 电池成本计算

```javascript
// 文件: custom.js - Calcs.battery()

var installation_cost = 3000;  // 固定安装费
var total_cost = 0;

$('select.battery-selection').each(function(idx, val) {
    var option = $(val).find('option:selected');
    var price = parseFloat(option.attr('data-price'));
    
    // SA州特殊价格
    if ($('#postcode-state').val() == 'SA' && option.attr('data-SA-price') !== undefined) {
        price = parseFloat(option.attr('data-SA-price'));
    }
    
    // 自定义电池：按容量估算
    if (isNaN(price) || price == 0) {
        const capacity = $(val).closest('.battery-item').find('[name*=capacity]').val();
        if (capacity != '' && parseFloat(capacity) > 0) {
            price = parseFloat(capacity) * 750;  // $750/kWh
        }
    }
    
    var cost = installation_cost + price;
    total_cost += cost;
});

return total_cost;
```

## 6. 系统成本计算

### 6.1 成本计算公式

```javascript
// 文件: custom.js - Calcs.cost()

var battery_cost = parseFloat($('#battery-cost').val().replace(',',''));
var total_cost;

if (isNaN(battery_cost) || battery_cost === 0) {
    // 无电池：每kW $900
    total_cost = system_size_new * 900;
} else if (battery_cost > 0) {
    // 有电池：电池成本 + 每kW $700
    total_cost = battery_cost + system_size_new * 700;
}

$('#total-cost').val(total_cost.toLocaleString('en-AU'));
```

### 6.2 成本计算示例

```
示例1：6.6kW 无电池
total_cost = 6.6 × $900 = $5,940

示例2：6.6kW + 10kWh电池
battery_cost = $7,500 + $3,000 = $10,500
total_cost = $10,500 + 6.6 × $700 = $15,120
```

## 7. FiT 限制检查

### 7.1 检查逻辑

```javascript
// 文件: custom.js - Calcs.checkFiTRestrictions()

const state = $('#postcode-state').val();
var totalSystemSize = 0;

// 计算总系统容量
$("[name^='solararray'].sa-system-capacity").each(function(i, item) {
    const systemSize = parseInt(item.value.replace(" kW", ""));
    totalSystemSize += systemSize;
});

// WA州限制
if (state == 'WA' && totalSystemSize > 6.6) {
    $('#FiT').val("0c");
    // 显示警告弹窗
    jQuery('a[data-popup="fit0PopupWA"]').click();
}

// VIC州限制
if (state == 'VIC' && totalSystemSize >= 100) {
    $('#FiT').val("0c");
    // 显示警告弹窗
    jQuery('a[data-popup="fit0PopupVIC"]').click();
}
```

## 8. 表单提交验证

### 8.1 验证流程

```javascript
// 文件: custom.js - Default.utils.onSubmitForm()

// 1. 验证邮编
if (hasInvalidPostcode) {
    e.preventDefault();
    sCalc.highlightError('postcode');
    return;
}

// 2. 验证年度电费
if (hasInvalidAnnualBill) {
    e.preventDefault();
    sCalc.highlightError('annual-bill');
    return;
}

// 3. 验证电价已加载
if (!kWhCost) {
    e.preventDefault();
    sCalc.getPostcodeInfo($('#postcode'), sCalc.stateDefaultsFunction, {
        onFinished: () => $(e.target).submit()
    });
    return;
}

// 4. 高级模式：验证NEM12文件
if (!isSimpleMode && !nem12token) {
    e.preventDefault();
    sCalc.highlightError('uploadNem12');
    return;
}

// 5. 验证配电商选择
if (dnspSelect.val() == '' && dnspSelect.find('option').length > 2) {
    e.preventDefault();
    sCalc.highlightError('dnsp-selection');
    return;
}
```

## 9. 输入到 variables 对象的映射

### 9.1 映射关系

| 用户输入 | variables 属性 | 说明 |
|----------|----------------|------|
| 邮编 | state | 通过API获取州 |
| 系统容量 | total_capacity | 后端计算 |
| 朝向 | (PVWatts参数) | 传递给API |
| 倾角 | (PVWatts参数) | 传递给API |
| 电池容量 | battery['data-capacity'] | 从选项提取 |
| 电池效率 | battery['data-efficiency'] | 从选项提取 |
| 电池保留 | battery['data-reserve'] | 从选项提取 |
| 年电费 | annual_bill | 直接使用 |
| 每度电价 | kWh_cost | 去除单位后使用 |
| 日供电费 | dailyCharge | 直接使用 |
| 上网电价 | FiT | 去除单位后使用 |

### 9.2 后端生成的变量

| 变量 | 来源 | 说明 |
|------|------|------|
| generated_season | PVWatts API | 各季节发电量 |
| generated_year | PVWatts API | 年发电量 |
| total_cost | 前端计算 | 系统总成本 |
| charge | 后端计算 | 各季节日供电费 |

## 10. 完整输入处理流程图

```
用户输入邮编
    ↓
getPostcodeInfo() API调用
    ↓
获取: lat, lon, state, distributors
    ↓
stateDefaults() 加载州默认值
    ↓
用户调整: kWhCost, FiT, annual_bill, daily_charge
    ↓
用户选择: system_capacity, azimuth, tilt
    ↓
用户选择: battery (capacity, efficiency, reserve)
    ↓
Calcs.battery() 计算电池成本
    ↓
Calcs.cost() 计算系统总成本
    ↓
checkFiTRestrictions() 检查FiT限制
    ↓
表单验证
    ↓
提交到后端
    ↓
后端调用 PVWatts API
    ↓
生成 variables 对象
    ↓
返回结果页面
```
