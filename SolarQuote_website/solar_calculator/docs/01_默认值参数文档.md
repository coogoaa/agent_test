## 2. 系统成本默认值

### 2.1 太阳能系统成本

```javascript
// 无电池系统
system_cost = system_capacity_kW × $900

// 有电池系统
system_cost = battery_cost + system_capacity_kW × $700
```

| 场景 | 每kW成本 | 说明 |
|------|----------|------|
| 无电池 | $900/kW | 包含安装、逆变器等 |
| 有电池 | $700/kW | 电池成本单独计算 |

### 2.2 电池成本

```javascript
// 标准电池
battery_cost = battery_price + $3000 (安装费)

// 自定义电池
battery_cost = capacity_kWh × $750 + $3000 (安装费)
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 安装费 | $3000 | 固定安装费用 |
| 自定义电池估算 | $750/kWh | 按容量估算价格 |
| SA州特殊价格 | 使用 `data-SA-price` | 南澳有特殊电池价格 |

### 2.3 逆变器更换成本

```javascript
// 第12年更换逆变器
inverter_size = Math.ceil(system_capacity / dc_ac_ratio)
inverter_cost = inverter_size × 1000 × inverter_cost_per_watt × (1 + inflation)^12
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| inverter_cost_per_watt | $0.20 | 每瓦更换成本 |
| dc_ac_ratio | 1.32 | 直流/交流比 |
| 更换年份 | 第12年 | 固定在第12年更换 |

### 3.3 SA州特殊价格说明

**重要发现：** 从电池列表分析，`data-SA-price` (南澳特殊价格) 与 `data-price` (标准价格) **完全相同**。

```javascript
// 示例：Tesla Powerwall 3
data-price="8650" data-SA-price="8650"

// 示例：BYD Battery Box Premium HVM 11.0
data-price="5857" data-SA-price="5857"
```

**结论：** 当前数据中南澳没有特殊的电池价格优惠，`data-SA-price` 属性存在但值与标准价格相同。

### 3.4 电池成本计算公式

```javascript
// 文件: custom.js - Calcs.battery()

var installation_cost = 3000;  // 固定安装费

// 标准电池
battery_cost = data-price + installation_cost

// SA州电池 (如果有特殊价格)
if (state == 'SA' && option.attr('data-SA-price') !== undefined) {
    battery_cost = data-SA-price + installation_cost
}

// 自定义电池
if (isNaN(price) || price == 0) {
    battery_cost = capacity_kWh × 750 + installation_cost
}
```

### 3.5 电池选择后的联动计算

当用户选择电池后，系统会自动计算并填充以下字段：

#### 触发事件
```javascript
// 文件: custom.js
$('body').on('change keyup', 'select.battery-selection, #battery-cost', function(){
    var battery_cost = Calcs.battery();  // 计算电池成本
    $('#battery-cost').val(parseFloat(battery_cost).toLocaleString('en-AU'));  // 填充到输入框
    Calcs.cost();  // 重新计算总成本
});
```

#### 计算示例：Enphase IQ Battery 5P

**Step 1: 电池成本计算 (Calcs.battery)**
```
电池价格 (data-price) = $6,750
安装费 (installation_cost) = $3,000
---------------------------------
Battery cost after rebates = $6,750 + $3,000 = $9,750
```

**Step 2: 系统总成本计算 (Calcs.cost)**
```
系统容量 = 10 kW (默认)
有电池时每kW成本 = $700
系统成本 = 10 × $700 = $7,000

电池成本 = $9,750
---------------------------------
Cost of entire system = $7,000 + $9,750 = $16,750
```

#### 成本计算公式汇总

| 场景 | 公式 | 示例 |
|------|------|------|
| **无电池** | `system_size × $900` | 10kW × $900 = $9,000 |
| **有电池** | `battery_cost + system_size × $700` | $9,750 + 10kW × $700 = $16,750 |

#### 电池成本公式

| 电池类型 | 公式 | 示例 |
|----------|------|------|
| **预设电池** | `data-price + $3,000` | $6,750 + $3,000 = $9,750 |
| **SA州电池** | `data-SA-price + $3,000` | 同上 (当前无差异) |
| **自定义电池** | `capacity × $750 + $3,000` | 10kWh × $750 + $3,000 = $10,500 |

### 3.6 NSW政府补贴标识

电池列表中包含 `data-nsw-govt-rebate-yes` 属性，标识该电池是否符合NSW政府补贴资格。

**注意：** 补贴计算逻辑在当前提供的代码中**未找到具体实现**。`Battery cost after rebates` 字段显示的是 `data-price + 安装费`，用户可以手动修改为补贴后的实际价格。

### 5.2 出口限制的使用场景

出口限制 (`export_limit`) 在以下场景中使用：

```javascript
// 文件: shared_calc.js

// 1. 根据邮编自动获取配电商
const distributors = result.response.solarDistributors;

// 2. 根据配电商和相位类型设置出口限制
const isThreePhase = $('#three_phase').is(':checked');
const phaseKey = isThreePhase ? 'three' : 'single';
const exportLimit = exportLimitRates[distributorName][phaseKey];
$('#export-limit').val(exportLimit);

// 3. 默认出口限制
const exportLimit = distributorLimits ? distributorLimits[phaseKey] : 5 * (isThreePhase ? 3 : 1);
// 单相默认: 5 kW
// 三相默认: 15 kW
```

**注意：** 当前简单模式计算器**不使用出口限制**进行计算。页面显示提示："This calculator does not model export limits yet."

### 5.3 邮编与配电商的匹配关系

邮编到配电商的匹配通过后端 API 实现：

```javascript
// API 调用
$.ajax({
    url: '/solar-calculator/postcodeInformation/',
    data: { postcode: elem.val() },
    success: function(result) {
        // result.response.solarDistributors 返回配电商列表
        const distributors = result.response.solarDistributors;
        // 可能返回多个配电商供用户选择
    }
});
```

**重要：** 邮编到配电商的具体映射数据存储在**后端数据库**中，前端代码中**没有**这个映射表。需要从后端获取或提供额外的邮编-配电商映射数据。

## 9. 结果页面滑块默认值

### 9.1 自用率滑块 (Self Consumption)

```javascript
// 文件: result_debug.js
let maxAvgScr = sCalc.solarCalc.calculateMaxSelfC(v, highestSelfC, highestBatSelfC);
jQuery('#self-consumption-slider .slider').slider({max: maxAvgScr});
```

|------|----------|------|
| 最大值 | `min(100, (年用电量/年发电量)*100)` | 不能超过100% |
| 默认值 | `最大值 / 2` | 最大自用率的一半 |
| 最小值 | 0 | 固定为0 |

### 9.2 通胀率滑块 (Inflation)

| 参数 | 默认值 | 范围 | 说明 |

## 12. 注意事项

   - 返回州信息后加载对应的 `state_defaults`

   - WA州大于6.6kW系统无FiT
   - VIC州大于100kW系统无FiT

## 13. 各州年用电量默认值

各州的默认年用电量可以通过以下公式从 `annual_bill` 反推：

```javascript
年用电量 = (annual_bill - 年日供电费) / (kWh_cost / 100)
年日供电费 = daily × 365 / 100
```
