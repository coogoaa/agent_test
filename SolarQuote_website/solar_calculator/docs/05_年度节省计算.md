# 年度节省计算 (calculateYearlyValues)

本文档详细说明 `calculateYearlyValues` 函数的完整计算逻辑。

---

## 1. 数据流概览

```
┌─────────────────────────────────────────────────────────────┐
│                calculateYearlyValues (循环20年)              │
├─────────────────────────────────────────────────────────────┤
│ For year = 0 to 19:                                         │
│   For season in [summer, autumn, winter, spring]:           │
│     1. 计算通胀后电价                                        │
│     2. 计算太阳能前电费                                      │
│     3. 计算自用电量和节省                                    │
│     4. 计算出口电量和收入                                    │
│     5. 如有电池，计算电池节省                                 │
│     6. 累计季节节省                                          │
│   累计年度节省                                               │
│   第12年扣除逆变器更换成本                                    │
└─────────────────────────────────────────────────────────────┘
```

## 4. 计算步骤详解

### 4.1 Step 1: 自用率季节加权

```javascript
// 根据州默认自用率和用户调整计算各季节自用率
var seasonSC = {
    summer: selfC * state_defaults.self_consumption_ratio['summer'] / variables.selfC,
    autumn: selfC * state_defaults.self_consumption_ratio['autumn'] / variables.selfC,
    winter: selfC * state_defaults.self_consumption_ratio['winter'] / variables.selfC,
    spring: selfC * state_defaults.self_consumption_ratio['spring'] / variables.selfC
};
```

**示例计算 (VIC州, selfC=1.0):**
```
seasonSC.summer = 1.0 × 38 / 37 = 1.027 (102.7%)
seasonSC.autumn = 1.0 × 38 / 37 = 1.027 (102.7%)
seasonSC.winter = 1.0 × 39 / 37 = 1.054 (105.4%)
seasonSC.spring = 1.0 × 32 / 37 = 0.865 (86.5%)
```

### 4.2 Step 2: 通胀调整电价

```javascript
// 第N年的电价 = 基础电价 × (1 + 通胀率)^N
var kWhCost_year = kWh_cost * Math.pow(1 + inflation, year);
var dailyCharge_year = dailyCharge * Math.pow(1 + inflation, year);
```

**示例计算 (第5年, 通胀3%):**
```
kWhCost_year5 = 27 × (1.03)^5 = 27 × 1.159 = 31.30分
dailyCharge_year5 = 135.89 × (1.03)^5 = 157.53分
```

### 4.3 Step 3: FiT递减处理

```javascript
// 如果启用FiT递减
if (reduce_fit) {
    var FiT_year = FiT - year;  // 每年减少1分
    
    // 最低限制
    if (FiT_year < 6) {
        FiT_year = FiT > 6 ? 6 : FiT;
    }
}
```

**示例计算 (初始FiT=7分):**
```
Year 0: FiT = 7分
Year 1: FiT = 6分
Year 2+: FiT = 6分 (最低限制)
```

### 4.4 Step 4: 季节循环计算

```javascript
var seasons = ['summer', 'autumn', 'winter', 'spring'];
var yearSavings = 0;

seasons.forEach(function(season) {
    // 4.4.1 计算太阳能前电费
    var preSolarBill = usage[season] * (kWhCost_year / 100) 
                     + charge[season] * Math.pow(1 + inflation, year);
    
    // 4.4.2 计算自用电量
    var selfConsumption = Math.min(
        generated_season[season] * seasonSC[season],
        usage[season]
    );
    
    // 4.4.3 计算自用节省
    var selfConsumptionSavings = selfConsumption * (kWhCost_year / 100);
    
    // 4.4.4 计算出口电量
    var exportEnergy = generated_season[season] - selfConsumption;
    
    // 4.4.5 计算FiT收入
    var FiTIncome = exportEnergy * (FiT_year / 100);
    
    // 4.4.6 计算电网用电
    var gridUsage = usage[season] - selfConsumption;
    
    // 4.4.7 计算太阳能后电费
    var postSolarBill = gridUsage * (kWhCost_year / 100) 
                      + charge[season] * Math.pow(1 + inflation, year)
                      - FiTIncome;
    
    // 4.4.8 计算季节节省
    var seasonSavings = preSolarBill - postSolarBill;
    
    yearSavings += seasonSavings;
});
```

## 5. 电池节省计算

### 5.1 电池参数

```javascript
var battery = {
    capacity: 10,           // kWh
    efficiency: 0.9,        // 往返效率
    reserve: 0.2            // 保留比例
};

// 可用容量
var usableCapacity = capacity * (1 - reserve);  // 10 × 0.8 = 8 kWh

// 充放电效率
var chargeEff = Math.sqrt(efficiency);    // √0.9 ≈ 0.949
var dischargeEff = Math.sqrt(efficiency); // √0.9 ≈ 0.949
```

### 5.2 电池节省逻辑

```javascript
// 每日可存储的多余电量
var dailyExcess = exportEnergy / days_in_season[season];

// 电池可存储量 (考虑充电效率)
var batteryCharge = Math.min(dailyExcess * chargeEff, usableCapacity);

// 电池可放电量 (考虑放电效率)
var batteryDischarge = batteryCharge * dischargeEff;

// 电池节省 = 放电量 × 电价 - 减少的FiT收入
var batterySavings = batteryDischarge * (kWhCost_year / 100) 
                   - batteryCharge * (FiT_year / 100);

// 只有当节省为正时才计入
if (batterySavings > 0) {
    seasonSavings += batterySavings * days_in_season[season];
}
```

### 5.3 电池节省示例

```
假设:
- 日多余电量: 20 kWh
- 电池容量: 8 kWh (可用)
- 充电效率: 94.9%
- 放电效率: 94.9%
- 电价: 27分
- FiT: 7分

计算:
- 电池充电: min(20 × 0.949, 8) = 8 kWh
- 电池放电: 8 × 0.949 = 7.59 kWh
- 电池节省: 7.59 × 0.27 - 8 × 0.07 = 2.05 - 0.56 = $1.49/天
- 季节节省: 1.49 × 90 = $134.10 (夏季)
```

## 6. 逆变器更换成本

### 6.1 计算公式

```javascript
// 第12年更换逆变器
if (year == 12) {
    // 逆变器大小 = 系统容量 ÷ DC/AC比
    var inverterSize = Math.ceil(systemCapacity / dc_ac_ratio);
    
    // 逆变器成本 = 大小(kW) × 1000 × 每瓦成本 × 通胀调整
    var inverterCost = inverterSize * 1000 * inverter_cost_per_watt 
                     * Math.pow(1 + inflation, 12);
    
    yearSavings -= inverterCost;
}
```

### 6.2 示例计算

```
系统容量: 6.6 kW
DC/AC比: 1.32
每瓦成本: $0.20
通胀率: 3%

逆变器大小 = ceil(6.6 / 1.32) = ceil(5) = 5 kW
逆变器成本 = 5 × 1000 × 0.20 × (1.03)^12
           = 5000 × 0.20 × 1.426
           = $1,426
```

## 10. 代码实现

### 10.1 简化版 JavaScript

```javascript
function calculateYearlyValues(v, year, options = {}) {
    const inflation = options.inflation || 0.03;
    const selfC = options.selfC || 1.0;
    const reduceFit = options.reduce_fit !== false;
    
    // 通胀调整
    const kWhCost = v.kWh_cost * Math.pow(1 + inflation, year) / 100;
    let FiT = v.FiT;
    if (reduceFit) {
        FiT = Math.max(FiT - year, FiT > 6 ? 6 : FiT);
    }
    FiT = FiT / 100;
    
    // 季节自用率
    const seasonSC = {};
    ['summer', 'autumn', 'winter', 'spring'].forEach(s => {
        seasonSC[s] = selfC * v.state_defaults.self_consumption_ratio[s] / v.selfC;
    });
    
    // 季节计算
    let yearSavings = 0;
    ['summer', 'autumn', 'winter', 'spring'].forEach(season => {
        const gen = v.generated_season[season];
        const use = v.usage[season];
        
        // 自用电量
        const selfConsumption = Math.min(gen * seasonSC[season], use);
        
        // 出口电量
        const exportEnergy = gen - selfConsumption;
        
        // 节省 = 自用节省 + FiT收入
        const savings = selfConsumption * kWhCost + exportEnergy * FiT;
        
        yearSavings += savings;
    });
    
    // 第12年逆变器更换
    if (year === 12) {
        const inverterSize = Math.ceil(v.systemCapacity / v.dc_ac_ratio);
        const inverterCost = inverterSize * 1000 * v.inverter_cost_per_watt 
                           * Math.pow(1 + inflation, 12);
        yearSavings -= inverterCost;
    }
    
    return { year, savings: yearSavings };
}
```

### 10.2 Python 实现

```python
def calculate_yearly_values(v, year, options=None):
    """
    计算指定年份的节省金额
    
    参数:
        v: 变量对象
        year: 年份 (0-19)
        options: 可选参数
    
    返回:
        包含年度节省等信息的字典
    """
    options = options or {}
    inflation = options.get('inflation', 0.03)
    self_c = options.get('selfC', 1.0)
    reduce_fit = options.get('reduce_fit', True)
    
    # 通胀调整电价
    kwh_cost = v['kWh_cost'] * ((1 + inflation) ** year) / 100
    
    # FiT递减
    fit = v['FiT']
    if reduce_fit:
        fit = max(fit - year, 6 if fit > 6 else fit)
    fit = fit / 100
    
    # 季节自用率
    season_sc = {}
    for season in ['summer', 'autumn', 'winter', 'spring']:
        season_sc[season] = (self_c * 
            v['state_defaults']['self_consumption_ratio'][season] / v['selfC'])
    
    # 季节计算
    year_savings = 0
    for season in ['summer', 'autumn', 'winter', 'spring']:
        gen = v['generated_season'][season]
        use = v['usage'][season]
        
        # 自用电量
        self_consumption = min(gen * season_sc[season], use)
        
        # 出口电量
        export_energy = gen - self_consumption
        
        # 节省
        savings = self_consumption * kwh_cost + export_energy * fit
        year_savings += savings
    
    # 第12年逆变器更换
    if year == 12:
        inverter_size = math.ceil(v['system_capacity'] / v['dc_ac_ratio'])
        inverter_cost = (inverter_size * 1000 * v['inverter_cost_per_watt'] 
                        * ((1 + inflation) ** 12))
        year_savings -= inverter_cost
    
    return {'year': year, 'savings': year_savings}
```

## 11. 注意事项

1. **自用率上限**
   - 自用电量不能超过用电量
   - 使用 `Math.min()` 限制

2. **FiT递减规则**
   - 每年减少1分
   - 最低不低于6分 (如果初始FiT > 6)
   - 如果初始FiT ≤ 6，则保持不变

3. **通胀复利**
   - 使用复利公式 `(1 + r)^n`
   - 同时应用于电价和日供电费

4. **逆变器更换**
   - 固定在第12年
   - 成本也需要通胀调整

5. **电池计算**
   - 需要考虑充放电效率损失
   - 只有当节省为正时才计入
