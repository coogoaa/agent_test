# 完整计算流程汇总

本文档汇总整个太阳能计算器的完整计算流程。

---

```

│                   PVWatts API 计算                           │
├─────────────────────────────────────────────────────────────┤

                              ↓
┌─────────────────────────────────────────────────────────────┐
│               calculateUsageValuesPerSeason                  │

```

## 2. 核心公式汇总

### 2.1 用电量计算

```
季节用电量 = (季节电费比例 × 年度电费 - 季节日供电费) ÷ 电价

usage[season] = (bill_factor[season] × annual_bill - charge[season]) / (kWh_cost / 100)
```

### 2.2 自用电量计算

```
季节自用率 = 用户自用率 × 州默认季节自用率 ÷ 州默认平均自用率

seasonSC[season] = selfC × state_defaults.self_consumption_ratio[season] / variables.selfC

自用电量 = min(发电量 × 季节自用率, 用电量)

selfConsumption = min(generation × seasonSC, usage)
```

### 2.3 节省计算

```
自用节省 = 自用电量 × 电价
selfConsumptionSavings = selfConsumption × (kWhCost / 100)

出口电量 = 发电量 - 自用电量
exportEnergy = generation - selfConsumption

FiT收入 = 出口电量 × FiT
FiTIncome = exportEnergy × (FiT / 100)

总节省 = 自用节省 + FiT收入 + 电池节省
totalSavings = selfConsumptionSavings + FiTIncome + batterySavings
```

### 2.4 通胀调整

```
第N年电价 = 基础电价 × (1 + 通胀率)^N
kWhCost_yearN = kWhCost × (1 + inflation)^N

第N年FiT = 初始FiT - N (最低6分)
FiT_yearN = max(FiT - N, 6)
```

### 2.5 电池节省

```
可用容量 = 电池容量 × (1 - 保留比例)
usableCapacity = capacity × (1 - reserve)

充电效率 = √往返效率
chargeEff = √roundTripEff

放电效率 = √往返效率
dischargeEff = √roundTripEff

电池充电量 = min(日多余电量 × 充电效率, 可用容量)
batteryCharge = min(dailyExcess × chargeEff, usableCapacity)

电池放电量 = 电池充电量 × 放电效率
batteryDischarge = batteryCharge × dischargeEff

电池节省 = 放电量 × 电价 - 充电量 × FiT
batterySavings = batteryDischarge × kWhCost - batteryCharge × FiT
```

### 2.6 逆变器更换

```
逆变器大小 = ceil(系统容量 ÷ DC/AC比)
inverterSize = ceil(systemCapacity / dc_ac_ratio)

逆变器成本 = 逆变器大小 × 1000 × 每瓦成本 × (1 + 通胀率)^12
inverterCost = inverterSize × 1000 × inverter_cost_per_watt × (1 + inflation)^12
```

### 2.7 回收期

```
回收期 = 累计节省首次超过系统成本的年份 + 剩余月份

paybackYears = year when cumulativeSavings >= totalCost
paybackMonths = (totalCost - previousCumulative) / (yearlySavings / 12)
```

## 4. 计算示例

### 4.1 输入参数

```
位置: 墨尔本 (VIC)
系统容量: 6.6 kW
电池: 10 kWh (效率90%, 保留20%)
年电费: $1,824
电价: 27分
FiT: 7分
日供电费: 135.89分
通胀率: 3%
```

### 4.2 Step 1: 发电量计算 (PVWatts)

```
年发电量: 9,449 kWh

季节发电量:
- Summer: 3,062 kWh
- Autumn: 2,145 kWh
- Winter: 1,587 kWh
- Spring: 2,655 kWh
```

### 4.3 Step 2: 用电量计算

```
季节用电量 = (比例 × 年电费 - 日供电费) ÷ 电价

Summer: (0.2314 × 1824 - 122.30) / 0.27 = 1,110 kWh
Autumn: (0.2354 × 1824 - 125.02) / 0.27 = 1,127 kWh
Winter: (0.2938 × 1824 - 125.02) / 0.27 = 1,522 kWh
Spring: (0.2394 × 1824 - 123.66) / 0.27 = 1,160 kWh

年用电量: 4,919 kWh
```

## 7. 注意事项

1. **单位转换**
   - 电价输入为"分"，计算时需除以100转换为"元"
   - FiT输入为"分"，计算时需除以100转换为"元"

2. **自用率限制**
   - 自用电量不能超过用电量
   - 使用 `Math.min()` 进行限制

3. **FiT递减**
   - 每年减少1分
   - 最低不低于6分（如果初始FiT > 6）

4. **逆变器更换**
   - 固定在第12年
   - 成本需要通胀调整

5. **电池效率**
   - 往返效率拆分为充电和放电效率
   - 各取平方根

6. **州特殊规则**
   - WA: 系统 > 6.6kW 时 FiT = 0
   - VIC: 系统 ≥ 100kW 时 FiT = 0
   - SA: 电池有特殊价格
