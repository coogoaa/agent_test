# 季节用电量计算 (calculateUsageValuesPerSeason)

本文档详细说明 `calculateUsageValuesPerSeason` 函数的计算逻辑。

---

## 1. 数据流概览

```
┌─────────────────────────────────────────────────────────────┐
│               calculateUsageValuesPerSeason                  │
├─────────────────────────────────────────────────────────────┤
│ 根据年电费和季节比例，计算每季度用电量                         │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 函数定义

```javascript
// 文件: shared_calc.js

sCalc.solarCalc.calculateUsageValuesPerSeason = function(v) {
    // calculate usage values for each season
    Object.keys(v.charge).forEach(function(season) {
        v.usage[season] = ((v.state_defaults.bill_factor[season] * v.annual_bill) 
                          - v.charge[season]) / (v.kWh_cost / 100);
    });
}
```

---

## 3. 核心公式

### 3.1 基本公式

```
季节用电量 = (季节电费比例 × 年度电费 - 季节日供电费总额) ÷ 每度电价
```

### 3.2 数学表达式

```
usage[season] = (bill_factor[season] × annual_bill - charge[season]) / (kWh_cost / 100)
```

### 3.3 公式分解

| 组成部分 | 公式 | 说明 |
|----------|------|------|
| 季节电费 | `bill_factor[season] × annual_bill` | 该季节的总电费 |
| 季节日供电费 | `charge[season]` | 该季节的固定费用 |
| 季节用电费 | 季节电费 - 季节日供电费 | 纯用电部分费用 |
| 季节用电量 | 季节用电费 ÷ 电价 | 转换为kWh |

---

## 4. 输入参数

### 4.1 参数说明

| 参数 | 类型 | 来源 | 说明 |
|------|------|------|------|
| v.state_defaults.bill_factor | object | 州默认值 | 各季节电费占比 |
| v.annual_bill | number | 用户输入 | 年度电费 ($) |
| v.charge | object | 计算得出 | 各季节日供电费总额 (分) |
| v.kWh_cost | number | 用户输入 | 每度电价 (分) |

### 4.2 示例输入 (VIC州)

```javascript
var v = {
    state_defaults: {
        bill_factor: {
            summer: 0.23138833,
            autumn: 0.235412475,
            winter: 0.293762575,
            spring: 0.23943662
        }
    },
    annual_bill: 1824,
    charge: {
        summer: 122.30,   // 90天 × 135.89分/天 ÷ 100
        autumn: 125.02,   // 92天 × 135.89分/天 ÷ 100
        winter: 125.02,   // 92天 × 135.89分/天 ÷ 100
        spring: 123.66    // 91天 × 135.89分/天 ÷ 100
    },
    kWh_cost: 27
};
```

## 5. 计算步骤

### 5.1 Step 1: 计算季节电费

```javascript
// 各季节电费 = 年度电费 × 季节比例
var seasonBill = {
    summer: 1824 × 0.23138833 = 422.05,
    autumn: 1824 × 0.235412475 = 429.39,
    winter: 1824 × 0.293762575 = 535.83,
    spring: 1824 × 0.23943662 = 436.73
};

// 验证: 422.05 + 429.39 + 535.83 + 436.73 = 1824 ✓
```

### 5.2 Step 2: 扣除日供电费

```javascript
// 季节用电费 = 季节电费 - 季节日供电费
var seasonUsageCost = {
    summer: 422.05 - 122.30 = 299.75,
    autumn: 429.39 - 125.02 = 304.37,
    winter: 535.83 - 125.02 = 410.81,
    spring: 436.73 - 123.66 = 313.07
};
```

### 5.3 Step 3: 转换为用电量

```javascript
// 季节用电量 = 季节用电费 ÷ (电价/100)
// 电价 = 27分 = $0.27

var usage = {
    summer: 299.75 / 0.27 = 1110.19 kWh,
    autumn: 304.37 / 0.27 = 1127.30 kWh,
    winter: 410.81 / 0.27 = 1521.52 kWh,
    spring: 313.07 / 0.27 = 1159.52 kWh
};

// 年用电量 = 1110.19 + 1127.30 + 1521.52 + 1159.52 = 4918.53 kWh
```

## 10. 用电量在后续计算中的应用

### 10.1 自用电量计算

```javascript
// 自用电量 = 发电量 × 自用率 (受用电量限制)
var selfConsumption = Math.min(
    generation × selfConsumptionRatio,
    usage  // 不能超过用电量
);
```

### 10.2 电网用电量计算

```javascript
// 电网用电量 = 总用电量 - 自用电量

```

### 10.3 出口电量计算

```javascript
// 出口电量 = 发电量 - 自用电量
var exportEnergy = generation - selfConsumption;
```

## 11. 代码实现

### 11.1 JavaScript 实现

```javascript
function calculateUsageValuesPerSeason(v) {
    const seasons = ['summer', 'autumn', 'winter', 'spring'];
    
    seasons.forEach(function(season) {
        // 季节电费
        const seasonBill = v.state_defaults.bill_factor[season] * v.annual_bill;
        
        // 季节日供电费
        const seasonCharge = v.charge[season];
        
        // 季节用电费
        const seasonUsageCost = seasonBill - seasonCharge;
        
        // 季节用电量 (kWh)
        v.usage[season] = seasonUsageCost / (v.kWh_cost / 100);
    });
}
```

### 11.2 Python 实现

```python
def calculate_usage_values_per_season(v):
    """
    根据年电费和季节比例计算每季度用电量
    
    参数:
        v: 包含以下属性的对象
            - state_defaults.bill_factor: 各季节电费比例
            - annual_bill: 年度电费 ($)
            - charge: 各季节日供电费总额 ($)
            - kWh_cost: 每度电价 (分)
    
    返回:
        v.usage: 各季节用电量 (kWh)
    """
    seasons = ['summer', 'autumn', 'winter', 'spring']
    v['usage'] = {}
    
    for season in seasons:
        # 季节电费 = 年度电费 × 季节比例
        season_bill = v['state_defaults']['bill_factor'][season] * v['annual_bill']
        
        # 季节用电费 = 季节电费 - 季节日供电费
        season_usage_cost = season_bill - v['charge'][season]
        
        # 季节用电量 = 季节用电费 ÷ 电价
        v['usage'][season] = season_usage_cost / (v['kWh_cost'] / 100)
    
    return v
```

## 12. 注意事项

1. **电价单位转换**
   - 输入电价单位为"分" (cents)
   - 计算时需除以100转换为"元" (dollars)

2. **日供电费处理**
   - 日供电费已按季节天数预先计算
   - 存储在 `v.charge` 对象中

3. **负值处理**
   - 如果日供电费高于季节电费，用电量可能为负
   - 实际应用中应设置最小值为0

4. **精度问题**
   - 建议保留2位小数
   - 最终显示时可四舍五入
