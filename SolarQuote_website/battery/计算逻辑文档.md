# SolarQuotes Battery Calculator 计算逻辑文档

## 概述

SolarQuotes Battery Calculator 是一个用于计算在现有太阳能系统上添加电池后的节省和回收期的计算器。该计算器通过上传用户的智能电表数据（NEM12 CSV文件），结合电价计划，计算出添加电池后的实际节省金额。

## 核心计算逻辑

### 1. 电池成本计算 (`calc-battery_calc.js`)

```javascript
Calcs.battery = function() {
    var installation_cost = 3000;  // 固定安装费用 $3000
    var total_cost = 0;

    var option = $('.sqDropdown.battery-selection .checked');
    var price = parseFloat(option.attr('data-price'));
    
    // 如果没有预设价格，按容量计算
    if(isNaN(price) || price == 0) {
        const capacity = $('select.battery-selection')
            .closest('.battery-item')
            .find('[name*=capacity]').val();
        if (capacity != '' && parseFloat(capacity) > 0) {
            price = parseFloat(capacity) * 750;  // $750/kWh
        }
    }

    var cost = parseFloat(installation_cost) + price;
    total_cost += cost;
    return total_cost;
}
```

**计算公式：**
- **电池总成本** = 安装费用（$3000） + 电池价格
- **电池价格**（如无预设）= 电池容量(kWh) × $750

### 2. 年度节省计算 (`calc-shared_calc.js`)

#### 2.1 季节性自用率权重

```javascript
var seasonSC = {
    summer: selfC * variables.state_defaults.self_consumption_ratio['summer'] / variables.selfC,
    autumn: selfC * variables.state_defaults.self_consumption_ratio['autumn'] / variables.selfC,
    winter: selfC * variables.state_defaults.self_consumption_ratio['winter'] / variables.selfC,
    spring: selfC * variables.state_defaults.self_consumption_ratio['spring'] / variables.selfC
};
```

#### 2.2 季节账单计算

对于每个季节（夏、秋、冬、春），计算以下指标：

```javascript
// 太阳能前账单
st.pre_solar_bill = seasonCharge[season] + (st.usage * state_cost);

// 自用电量（取发电量×自用率 和 用电量的较小值）
st.selfc = Math.min(v.generated_season[season] * selfC, st.usage);

// 自用节省
st.savings_selfc = st.selfc * state_cost;

// 电网用电
st.grid_use = st.usage - st.selfc;
st.grid_cost = st.grid_use * state_cost;

// 出口电量
st.exported = v.generated_season[season] - st.selfc;

// 上网电价收入
st.FiT = st.exported * FiT_value;

// 总节省
st.savings = st.FiT + st.savings_selfc;
```

#### 2.3 电池计算逻辑

```javascript
if(has_battery) {
    // 电池效率计算（往返效率的平方根）
    var roundTripEff = variables.battery['data-efficiency'] ?? 0.9;
    var chargeEff = Math.sqrt(roundTripEff);    // 充电效率
    var dischargeEff = Math.sqrt(roundTripEff); // 放电效率

    // 电池可用容量
    bat.capacity = st.days_in_season * 
        (variables.battery['data-capacity'] * (1 - variables.battery['data-reserve']));
    
    // 可存储能量（考虑充电损耗）
    var storable_energy = st.exported * chargeEff;
    bat.available = Math.min(bat.capacity, storable_energy);
    
    // 可用能量（考虑放电损耗）
    var usable_energy = bat.available * dischargeEff;
    bat.selfc = Math.min(usable_energy, st.grid_use);

    // 电池使用后的电网用电
    bat.grid_use = st.grid_use - bat.selfc;
    bat.grid_cost = bat.selfc * state_cost;
    
    // 电池使用后的出口电量
    bat.exported = st.exported - (bat.available / chargeEff);
    
    // 电池相关费用和收入
    bat.imports = bat.grid_use * state_cost;
    bat.export_earnings = bat.exported * FiT_value;
    bat.savings_selfc = bat.selfc * state_cost;
    
    // 电池账单
    bat.bill = (st.days_in_season * (variables.dailyCharge / 100)) + 
               bat.imports - bat.export_earnings;
    
    // 总自用电量
    bat.self_kwh = bat.selfc + st.selfc;
    
    // 电池节省
    bat.savings = bat.savings_selfc + st.savings_selfc + bat.export_earnings;
}
```

### 7. 回收期计算

```javascript
sCalc.detailedPayback = function(year, aggSavings, currentYearSavings, total) {
    var monthlyAvg = currentYearSavings / 12;
    var months = Math.ceil((total - aggSavings) / monthlyAvg);
    
    if (months == 0) {
        return {
            string: year + (year > 1 ? " yrs" : " yr"),
            years: year,
            months: months,
            monthsNumber: year * 12
        };
    } else if (months >= 12) {
        return {
            string: (year + 1) + (year > 0 ? " yrs" : " yr"),
            years: year + 1,
            months: 0,
            monthsNumber: (year + 1) * 12
        };
    }
    
    return {
        string: year + (year > 1 ? " yrs, " : " yr, ") + months + " mth" + (months > 1 ? "s" : ""),
        years: year,
        months: months,
        monthsNumber: (year * 12) + months
    };
}
```

### 8. 用电量按季节计算

```javascript
sCalc.solarCalc.calculateUsageValuesPerSeason = function(v) {
    v.usage = {};
    
    Object.keys(variables.charge).forEach(function(season) {
        // 用电量 = (季节账单因子 × 年度账单 - 固定费用) / 电价
        v.usage[season] = ((v.state_defaults.bill_factor[season] * v.annual_bill) - 
                           v.charge[season]) / (v.kWh_cost / 100);
    });
}
```

## 数据流程

```
用户输入
    ↓
┌─────────────────────────────────────────────────────────┐
│  1. 邮编 → 获取州信息、配电商、默认电价                    │
│  2. 电价计划 → 选择零售商、费率类型、具体费率              │
│  3. 电池选择 → 容量、效率、预留比例                        │
│  4. NEM12数据上传 → 12个月用电和出口数据                   │
└─────────────────────────────────────────────────────────┘
    ↓
计算引擎
    ↓
┌─────────────────────────────────────────────────────────┐
│  1. 解析NEM12数据 → 每30分钟用电/出口数据                  │
│  2. 按季节汇总 → 夏/秋/冬/春用电量和发电量                 │
│  3. 计算无电池账单 → 基于实际用电和电价                    │
│  4. 计算有电池账单 → 考虑电池充放电效率                    │
│  5. 计算节省金额 → 无电池账单 - 有电池账单                 │
│  6. 计算回收期 → 电池成本 / 年节省金额                     │
└─────────────────────────────────────────────────────────┘
    ↓
输出结果
    ↓
┌─────────────────────────────────────────────────────────┐
│  • 年度节省金额                                          │
│  • 回收期（年/月）                                        │
│  • 季节性账单对比                                         │
│  • 自用率变化                                            │
└─────────────────────────────────────────────────────────┘
```

## 关键参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `installation_cost` | 电池安装费用 | $3,000 |
| `price_per_kwh` | 电池单价（无预设时） | $750/kWh |
| `roundTripEff` | 电池往返效率 | 90% |
| `data-reserve` | 电池预留容量 | 根据电池型号 |
| `inverter_cost_per_watt` | 逆变器更换单价 | 变量配置 |
| `dc_ac_ratio` | 直流/交流比 | 变量配置 |

## 电价计划创建流程

1. **选择零售商** → 从邮编对应的零售商列表中选择
2. **选择计划类型** → 单一费率 / 分时电价
3. **设置季节性费率**（可选）→ 不同季节不同费率
4. **设置工作日/周末费率**（可选）→ 分时电价时可用
5. **设置用电费率** → 阶梯或固定费率
6. **设置上网电价** → 固定/分时/阶梯
7. **设置供电费** → 每日供电费用
8. **设置需量费**（可选）→ 每kW每日费用
9. **设置折扣**（可选）→ 总折扣百分比

## 注意事项

1. **数据要求**: 需要至少12个月的智能电表数据（NEM12格式）
2. **出口限制**: 计算器目前不完全模拟出口限制
3. **政府补贴**: 计算包含联邦政府的电池补贴（Cheaper Home Batteries Program）
4. **GST处理**: 所有费率输入需包含GST（10%）
5. **通胀考虑**: 长期计算会考虑电价通胀因素
