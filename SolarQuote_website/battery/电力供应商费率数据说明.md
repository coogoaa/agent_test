# 电力供应商费率数据说明

## 概述

本文档说明 SolarQuotes Battery Calculator 中各电力供应商费率数据的获取机制、提示逻辑以及如何获取完整的费率数据。

---

## 一、数据来源说明

### 1.1 数据获取方式

**重要：各电力供应商的具体费率数据（如 19.2 c/kWh）是通过后端 API 动态获取的，不是硬编码在前端代码中。**

```
用户选择邮编 + 零售商 + 计划类型
           ↓
    前端发送 API 请求
           ↓
POST /battery-storage/calculator/ajaxSearchDefaultPlan/
           ↓
    后端查询数据库
           ↓
    返回匹配的费率数据
           ↓
    前端显示费率信息
```

### 1.2 API 请求参数

```javascript
fetch('/battery-storage/calculator/ajaxSearchDefaultPlan/', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        planType: 'Time of Use',        // 计划类型
        multipleTariffPeriods: false,   // 是否多季节费率
        controlledLoad: false,          // 是否有控制负载
        retailer: 'AGL',                // 零售商名称
        postcode: '3000',               // 邮编
        state: 'VIC'                    // 州
    }),
});
```

## 二、提示信息处理逻辑

### 2.1 提示显示条件

截图中的提示信息由 `foundDefaultPlan` 状态控制：

```javascript
function editTariffsNote() {
    return html`
        <div class="edit-tariffs-note">
            ${foundDefaultPlan.value && html`
                <span> <p class="adjust"> We have loaded an energy plan that matches your postcode, retailer, and plan type </p> </span>
                <span> <p class="adjust"> Please adjust the tariffs to match your plan's </p> </span>

            ${!foundDefaultPlan.value && html`

                <span> <p class="adjust"> Please add your plan's tariffs below </p> </span>
            `}
        </div>
    `;
}
```

### 2.2 状态判断逻辑

```javascript
const loadedDefaultPlan = (data) => {
    loadingDefaultPlan.value = false;
    
    // 如果 API 返回空数据

    foundDefaultPlan.value = true;  // 找到匹配计划

```

### 2.3 两种提示状态

| 状态 | 提示信息 | 触发条件 |
|------|---------|---------|
| `foundDefaultPlan = true` | "We have loaded an energy plan..." | API 返回了匹配的计划数据 |
| `foundDefaultPlan = false` | "We couldn't find an energy plan..." | API 返回空数据或无匹配 |

## 三、如何获取完整费率数据

### 3.1 方法一：通过浏览器开发者工具

1. 打开 SolarQuotes 计算器页面
2. 按 F12 打开开发者工具
3. 切换到 "Network" 标签
4. 选择邮编、零售商、计划类型
5. 查看 `ajaxSearchDefaultPlan` 请求的响应数据

### 3.2 方法二：直接调用 API

```bash
curl -X POST 'https://www.solarquotes.com.au/battery-storage/calculator/ajaxSearchDefaultPlan/' \
  -H 'Content-Type: application/json' \
  -d '{
    "planType": "Time of Use",
    "multipleTariffPeriods": false,
    "controlledLoad": false,
    "retailer": "AGL",
    "postcode": "3000",
    "state": "VIC"
  }'
```

### 3.3 方法三：获取零售商列表

```bash
curl -X POST 'https://www.solarquotes.com.au/battery-storage/calculator/ajaxSearchRetailers/' \
  -d 'postcode=3000'
```

## 五、数据库来源推测

根据代码分析，费率数据可能来自以下来源：

### 5.1 Energy Made Easy API

```javascript
// 代码中有引用
energyPlan.offerId != 'custom' && !['VIC', 'WA', 'NT'].includes(energyPlan.state) && html`
    <a target="_blank" href="https://www.energymadeeasy.gov.au/plan?id=${energyPlan.offerId}&postcode=${energyPlan.postcode}"> See more </a>
`
```

**Energy Made Easy** 是澳洲政府的能源比价网站，提供各零售商的费率数据。

### 5.2 数据更新频率

- 费率数据由后端定期从官方来源更新
- 前端不缓存费率数据，每次选择都会重新请求
- 用户可以手动调整加载的费率

## 九、总结

| 数据类型 | 存储位置 | 获取方式 |
|---------|---------|---------|
| 各州默认电价 | 前端代码 (state_defaults) | 直接读取 |
| 默认时段结构 | 前端代码 | 直接读取 |
| 零售商列表 | 后端数据库 | API: ajaxSearchRetailers |
| **具体费率数据** | **后端数据库** | **API: ajaxSearchDefaultPlan** |
| 用户自定义计划 | URL参数/localStorage | 前端存储 |

**要获取完整的各供应商费率数据，需要通过 API 调用或直接访问后端数据库。**
