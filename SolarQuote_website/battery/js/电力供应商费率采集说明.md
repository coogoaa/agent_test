## 四、Energy Made Easy API

### 4.1 官方API信息

**Energy Made Easy** 是澳洲能源监管机构 (AER) 运营的官方能源比价网站。

| 项目 | 信息 |
|------|------|
| 网站 | https://www.energymadeeasy.gov.au |
| API文档 | https://www.energymadeeasy.gov.au/api |
| 数据格式 | JSON |
| 认证 | 需要申请API Key |

### 4.2 API 端点

```
# 获取计划列表
GET https://api.energymadeeasy.gov.au/plans?postcode={postcode}

# 获取计划详情
GET https://api.energymadeeasy.gov.au/plans/{planId}
```

### 4.3 申请API访问

1. 访问 https://www.energymadeeasy.gov.au/api
2. 填写申请表格
3. 说明使用目的
4. 等待审批（通常1-2周）

### 4.4 注意事项

- Energy Made Easy **不覆盖 VIC、WA、NT** 州
- 这些州有独立的能源监管机构
- VIC: Essential Services Commission (ESC)
- WA: Economic Regulation Authority (ERA)
