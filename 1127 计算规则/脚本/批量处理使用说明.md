# 批量处理脚本使用说明

## 功能概述

`batch_processor.py` 脚本用于批量处理光伏系统计算，支持两种模式：
1. **新建系统** - 完整的光伏+储能系统设计
2. **储能扩容** - 基于现有屋顶，应用容量系数（默认70%）的扩容方案

## 快速开始

### 基本用法

```bash
cd "1127 计算规则/脚本"

# 处理新建系统和储能扩容（默认NSW，单相）
python3 batch_processor.py -i "../验证数据/agent_sample_data - 坡面信息.csv"

# 仅处理新建系统
python3 batch_processor.py -i "../验证数据/agent_sample_data - 坡面信息.csv" -m new

# 仅处理储能扩容
python3 batch_processor.py -i "../验证数据/agent_sample_data - 坡面信息.csv" -m expansion
```

### 完整参数

```bash
python3 batch_processor.py \
  -i "../验证数据/agent_sample_data - 坡面信息.csv" \  # 输入CSV文件
  -s NSW \                                              # 州代码
  -p single \                                           # 电网类型
  -m both \                                             # 处理模式
  -l 100                                                # 限制处理数量（可选）
```

## 参数说明

### 必需参数

- `-i, --input`: 输入CSV文件路径
  - 格式：包含 `id_0`, `slope`, `aspect`, `nums` 列
  - 示例：`../验证数据/agent_sample_data - 坡面信息.csv`

### 可选参数

- `-s, --state`: 州代码（默认：NSW）
  - 可选值：NSW, VIC, QLD, SA, WA, TAS, ACT, NT
  - 影响：用电量、补贴计算

- `-p, --phase`: 电网类型（默认：single）
  - `single` - 单相电网（逆变器≤10kW）
  - `three` - 三相电网（逆变器≤30kW）

- `-m, --mode`: 处理模式（默认：both）
  - `new` - 仅新建系统
  - `expansion` - 仅储能扩容
  - `both` - 两者都处理

- `-l, --limit`: 限制处理数量（用于测试）
  - 示例：`-l 10` 仅处理前10个房屋

- `-c, --config`: 配置文件路径（默认：config.json）

## 输出文件

所有输出保存在 `../out/` 目录，文件名带时间戳：

### 1. 新建系统CSV (`新建系统_YYYYMMDD_HHMMSS.csv`)

**列说明：**
```
房屋ID                    - 房屋唯一标识
州                        - 用户所在州
电网类型                  - single/three
屋顶总容量(kW)           - GIS分析的最大容量

方案A-PV(kW)             - 光伏装机容量
方案A-面板数             - 面板数量
方案A-逆变器(kW)         - 逆变器功率
方案A-容配比(%)          - PV/逆变器比例
方案A-储能(kWh)          - 储能容量
方案A-成本($)            - 含税总成本
方案A-补贴($)            - STC补贴金额
方案A-最终报价($)        - 成本-补贴

方案B、方案C 同上
```

### 2. 储能扩容CSV (`储能扩容_YYYYMMDD_HHMMSS.csv`)

**额外列：**
```
容量系数                  - 屋顶容量系数（默认70%）
扩容可用容量(kW)         - 总容量 × 系数
```

### 3. 汇总报告 (`汇总报告_YYYYMMDD_HHMMSS.txt`)

包含：
- 处理数量统计
- 各方案平均报价
- 新建系统和储能扩容对比

## 处理流程

### 新建系统流程

1. 读取CSV文件，按房屋ID分组
2. 对每个房屋：
   - 评估屋顶坡面（方位角评分）
   - 生成方案A（高端型）：满铺
   - 生成方案B（平衡型）：10-13kW
   - 生成方案C（经济型）：6.6kW
   - 计算储能容量（三种方法取最大值）
   - 计算成本和补贴
3. 导出CSV汇总

### 储能扩容流程

1. 读取CSV文件，按房屋ID分组
2. 应用容量系数（默认0.7）到每个坡面
3. 使用相同的计算逻辑生成三套方案
4. 导出CSV汇总（包含容量系数信息）

## 配置说明

### 修改容量系数

编辑 `config.json`：

```json
{
  "expansion": {
    "roofCapacityFactor": 0.7,  // 修改为其他值，如0.6或0.8
    "replaceInverter": true
  }
}
```

### 修改其他参数

参考 `config.json` 中的其他配置项：
- `pv` - PV组件参数
- `battery` - 储能系数
- `inverter` - 逆变器规格
- `cost` - 成本参数
- `subsidy` - 补贴参数

## 常见问题

### Q1: 处理全部数据需要多久？

A: 约50秒（4937个房屋）。可以先用 `-l 10` 测试。

### Q2: 如何修改容量系数？

A: 编辑 `config.json` 中的 `expansion.roofCapacityFactor`。

### Q3: CSV文件乱码怎么办？

A: 使用Excel打开时选择UTF-8编码，或用Numbers/WPS等软件。

### Q4: 如何只处理特定房屋？

A: 可以先筛选CSV文件，或修改脚本添加房屋ID过滤功能。

### Q5: 输出文件在哪里？

A: `1127 计算规则/out/` 目录，文件名带时间戳。

### Q6: 如何对比不同州的报价？

A: 多次运行脚本，每次指定不同的 `-s` 参数，然后对比生成的CSV。

## 高级用法

### 批量处理多个州

创建shell脚本 `batch_all_states.sh`：

```bash
#!/bin/bash

STATES=("NSW" "VIC" "QLD" "SA" "WA" "TAS" "ACT" "NT")

for state in "${STATES[@]}"; do
    echo "处理 $state..."
    python3 batch_processor.py \
        -i "../验证数据/agent_sample_data - 坡面信息.csv" \
        -s $state \
        -p single \
        -l 100
done

echo "全部完成！"
```
