## 🚀 快速开始（3步）

### 方法1：使用启动脚本（推荐）

#### Mac/Linux:
```bash
cd "1127 计算规则/脚本"
./run.sh
```

#### Windows:
```cmd
cd "1127 计算规则\脚本"
run.bat
```

然后选择：
- `1` - 运行内置测试案例（3个）
- `2` - 运行批量测试（6个案例，从test_data.json加载）
- `3` - 清理输出目录

### 方法2：直接运行Python脚本

```bash
# 运行内置测试（3个案例）
python3 solar_calculator.py

# 运行批量测试（6个案例）
python3 run_batch_test.py

# 使用自定义测试数据
python3 run_batch_test.py -t my_test_data.json
```

## ⚙️ 修改配置

### 1. 修改计算参数

编辑 `config.json`:

```json
{
  "pv": {
    "pmax": 440  // 修改组件功率
  },
  "battery": {
    "premium": {
      "daily": 0.5,    // 高端型：日用电系数
      "evening": 2.0,  // 傍晚峰值系数
      "pv": 1.5        // PV容量系数
    }
  },
  "cost": {
    "pvPerKw": 540,        // 光伏成本 $/kW
    "batteryPerKwh": 865   // 储能成本 $/kWh
  }
}
```

### 2. 添加测试案例

编辑 `test_data.json`:

```json
{
  "test_cases": [
    {
      "name": "我的测试案例",
      "description": "描述信息",
      "house_data": [
        {"id": "slope 1", "aspect": 0, "max": 20},
        {"id": "slope 2", "aspect": 90, "max": 10}
      ],
      "state": "NSW",
      "phase_type": "single"
    }
  ]
}
```

**参数说明：**
- `aspect`: 方位角（0=正北，90=正东，180=正南，270=正西）
- `max`: 该坡面最大可安装面板数
- `state`: NSW/VIC/QLD/SA/WA/TAS/ACT/NT
- `phase_type`: single（单相）或 three（三相）

## 📈 输出文件说明

### 1. 文本报告 (result_*.txt)

包含完整的计算过程和结果：
- 屋顶分析（坡面评分、容量）
- 三套方案详情（A高端/B平衡/C经济）
- 成本明细
- 补贴计算
- 最终报价

### 2. JSON数据 (result_*.json)

机器可读格式，包含所有计算数据，可用于：
- 进一步数据分析
- 导入其他系统
- API集成

### 3. 汇总报告 (summary_*.txt)

所有测试案例的简要对比，快速查看关键指标。

### 4. 对比表格 (comparison_*.csv)

Excel格式，方便进行横向对比和数据分析。

## 🔍 常见使用场景

### 场景1：验证单个房屋配置

```python
# 编辑 solar_calculator.py 中的 test_cases
test_cases = [
    {
        'name': '客户A的房屋',
        'house_data': [
            {'id': 'slope 1', 'aspect': 5, 'max': 25}
        ],
        'state': 'NSW',
        'phase_type': 'single'
    }
]
```

运行：`python3 solar_calculator.py`

### 场景2：批量验证多个房屋

编辑 `test_data.json`，添加所有房屋数据，然后运行：
```bash
python3 run_batch_test.py
```

### 场景3：测试不同配置参数

1. 备份原配置：`cp config.json config_backup.json`
2. 修改 `config.json` 中的参数
3. 运行测试：`python3 run_batch_test.py`
4. 对比结果
5. 恢复配置：`cp config_backup.json config.json`

### 场景4：对比不同州的报价

在 `test_data.json` 中创建相同房屋但不同州的测试案例：

```json
{
  "test_cases": [
    {
      "name": "同一房屋 - NSW",
      "house_data": [...],
      "state": "NSW",
      "phase_type": "single"
    },
    {
      "name": "同一房屋 - VIC",
      "house_data": [...],
      "state": "VIC",
      "phase_type": "single"
    }
  ]
}
```

## 🐛 故障排除

### 问题1：找不到Python

**解决方案：**
```bash
# Mac
brew install python3

# Ubuntu/Debian
sudo apt-get install python3

# Windows
从 python.org 下载安装
```

### 问题2：权限错误

**解决方案：**
```bash
# Mac/Linux
chmod +x run.sh
chmod +x solar_calculator.py
```

### 问题3：输出目录不存在

脚本会自动创建，但如果有问题：
```bash
mkdir -p ../out
```

### 问题4：JSON格式错误

使用在线工具验证JSON格式：
- https://jsonlint.com/

### 问题5：中文显示乱码

确保终端支持UTF-8编码：
```bash
# Mac/Linux
export LANG=zh_CN.UTF-8

# Windows
chcp 65001
```
