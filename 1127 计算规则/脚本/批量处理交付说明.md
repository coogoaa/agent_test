## 📊 输出说明

### 输出位置
所有结果保存在 `1127 计算规则/out/` 目录

### 输出文件

#### 1. 新建系统CSV
**文件名**: `新建系统_YYYYMMDD_HHMMSS.csv`

**包含列**:
- 房屋ID、州、电网类型、屋顶总容量
- 方案A/B/C的：PV容量、面板数、逆变器、容配比、储能、成本、补贴、最终报价

**示例数据**:
```csv

1,NSW,single,0.88,0.88,2,5,17.6,13.5,14907.97,4641.00,10266.97,...
```

#### 2. 储能扩容CSV
**文件名**: `储能扩容_YYYYMMDD_HHMMSS.csv`

**额外列**:
- 容量系数（默认70%）
- 扩容可用容量

**示例数据**:
```csv
房屋ID,州,电网类型,屋顶总容量(kW),容量系数,扩容可用容量(kW),...
1,NSW,single,0.88,70.0%,0.62,0.88,2,5,17.6,13.5,...
```

#### 3. 汇总报告
**文件名**: `汇总报告_YYYYMMDD_HHMMSS.txt`

**包含内容**:
- 处理数量统计
- 各方案平均报价
- 新建系统和储能扩容对比

## 🔧 配置说明

### 容量系数调整

编辑 `config.json`:
```json
{
  "expansion": {
    "roofCapacityFactor": 0.7,  // 修改为0.6、0.8等
    "replaceInverter": true
  }
}
```

### 其他参数

可修改的配置项：
- `pv.pmax` - PV组件功率（默认440W）
- `battery` - 储能系数（三套方案不同）
- `inverter` - 逆变器规格
- `cost` - 成本参数
- `subsidy` - 补贴参数

## 📋 命令行参数

```bash
python3 batch_processor.py [选项]

必需参数:
  -i, --input FILE      输入CSV文件路径

可选参数:
  -s, --state STATE     州代码 (默认: NSW)
                        可选: NSW/VIC/QLD/SA/WA/TAS/ACT/NT
  
  -p, --phase TYPE      电网类型 (默认: single)
                        可选: single/three
  
  -m, --mode MODE       处理模式 (默认: both)
                        可选: new/expansion/both
  
  -l, --limit NUM       限制处理数量（用于测试）
  
  -c, --config FILE     配置文件路径 (默认: config.json)
```
