# 容配比自动调整说明

## 解决方案

### 完整的调整逻辑

```javascript
// 检查容配比是否超标
if (parseInt(ratioC) > 200) {
    // 1. 显示警告
    derivationLog[stepCIndex].details.push({ 
        text: `⚠️ 容配比 ${ratioC}% 超过 200%，违反澳洲Hybrid系统规则！`,
        warning: true
    });
    
    // 2. 尝试增大逆变器
    const minInvForCompliance = Math.ceil(resultC.totalKw / 2.0);
    const threeOptions = phaseType === 'single' ? INVERTER_CONFIG.single.c : INVERTER_CONFIG.three.c;
    const compliantInv = threeOptions.find(s => s >= minInvForCompliance);
    
    if (compliantInv && compliantInv > invC) {
        // 方案1: 增大逆变器解决
        invC = compliantInv;
        const newRatio = (resultC.totalKw / invC * 100).toFixed(0);
        derivationLog[stepCIndex].details.push({ 
            text: `✓ 调整为 ${invC}kW 逆变器 → 容配比 ${newRatio}% (符合规则)`,
            highlight: true
        });
    } else {
        // 方案2: 减少面板
        const maxInv = threeOptions[threeOptions.length - 1];
        const maxAllowedKw = maxInv * 2.0;
        const excessKw = resultC.totalKw - maxAllowedKw;
        const panelsToRemove = Math.ceil((excessKw * 1000) / PV_WATT);
        
        // 从低分坡面开始减板子
        let removedCount = 0;
        const sortedByScore = [...roofPlanes].sort((a, b) => a.score - b.score);
        
        for (let plane of sortedByScore) {
            if (removedCount >= panelsToRemove) break;
            if (plane.max === 0) continue;
            
            const canRemove = Math.min(plane.max, panelsToRemove - removedCount);
            plane.max -= canRemove;
            removedCount += canRemove;
        }
        
        // 重新计算
        resultC.count -= removedCount;
        resultC.totalKw = (resultC.count * PV_WATT / 1000);
        invC = maxInv;
    }
}
```

## 调整策略

### 策略1: 增大逆变器（优先）

**条件**: 配置中有更大的逆变器规格

**示例**:
```

初始: 6.6kW / 3kW = 220% ❌

计算最小需求: ceil(6.6 / 2.0) = 4kW
查找符合规格: 5kW ✓

调整为: 6.6kW / 5kW = 132% ✓
```

**推导日志**:
```

✓ 调整为 5kW 逆变器 → 容配比 132% (符合规则)
```

### 策略2: 减少面板（备选）

**条件**: 逆变器已达配置上限

**示例**:
```

初始: 6.6kW / 3kW = 220% ❌

最大允许: 3kW × 200% = 6.0kW

需减少: ceil(0.6 × 1000 / 440) = 2片
```

**推导日志**:

## 澳洲Hybrid系统规则

### 容配比限制

**规则**: DC/AC比率不得超过200%

**原因**:
1. 逆变器过载保护
2. 电网安全要求
3. 设备寿命保障

**合理范围**: 150% - 200%
- < 150%: 逆变器利用率低
- 150-200%: 最佳范围
- > 200%: 违反规则

### 调整优先级

1. **优先增大逆变器**
   - 保持PV容量不变
   - 提高系统输出能力
   - 更好的投资回报

2. **备选减少面板**
   - 降低系统成本
   - 符合规则要求
   - 保持合理容配比
