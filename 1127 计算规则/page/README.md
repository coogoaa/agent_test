# 光伏设备智能推荐系统 - 完整动态推导版

## 功能概述

这是一个基于 GIS 数据、用户用电模式和澳洲 CEC 标准的智能光伏系统设计工具。系统能够：

1. **动态推导光伏组件配置**：基于屋顶物理限制和坡面朝向评分
2. **智能匹配逆变器**：根据容配比规则自动选择合适的逆变器规格
3. **动态计算储能容量**：基于用户所在州的用电数据和光伏系统规模

## 核心特性

### 1. 输入参数
- **房屋 GIS 数据**：屋顶坡面方位角、最大可布局面板数量
- **用户位置**：澳洲各州（NSW/VIC/QLD/SA/WA/TAS/ACT/NT）
- **PV 组件参数**：JA Solar 440W 组件规格
- **电网相位**：单相/三相（影响逆变器选型）

### 2. 智能推导过程

#### Step 1: 屋顶坡面评分
- 基于方位角计算发电潜力（南半球规则：正北最优）
- 评分范围 0-100，自动排序优先级

#### Step 2: 物理限制分析
- 统计屋顶总容量和可用坡面数量

#### Step 2.5: 用电数据分析（新增）
- 基于州典型用电模式
- 计算日均用电量和傍晚高峰用电量
- 为储能容量计算提供依据

#### Step 3-5: 三套方案推导

**方案 A (经济型)**
- 目标：6.6kW 光伏系统
- 逆变器：5kW 组串式
- 容配比：≤133% (CEC 规则)
- 储能：不配置

**方案 B (平衡型)**
- 目标：10-13kW 光伏系统
- 逆变器：5-10kW 混合式
- 容配比：150%-200% (允许超配)
- 储能：**动态计算**
  - 公式：`max(日用电×30%, 傍晚峰×1.5, PV容量×1.0)`
  - 标准化到常见规格：5/6.5/9.6/10/13.5 kWh

**方案 C (高端型)**
- 目标：物理极限满铺
- 逆变器：动态匹配大功率逆变器
- 容配比：自动计算
- 储能：**动态计算**
  - 公式：`max(日用电×50%, 傍晚峰×2.0, PV容量×1.5)`
  - 提供离网级备电能力

### 3. 储能容量计算逻辑（基于 cankao.md 5.2 节）

#### 方法 1：基于日用电量
```
推荐容量 = 日均用电量 × 系数
- 平衡型：30%
- 高端型：50%
```

#### 方法 2：基于傍晚高峰用电
```
傍晚高峰时段：17:00-21:00
傍晚高峰用电 = 日均用电 × 各州时段比例之和
推荐容量 = 傍晚高峰用电 × 系数
- 平衡型：1.5倍
- 高端型：2.0倍
```

#### 方法 3：基于光伏系统规模
```
推荐容量 = 光伏装机容量 (kW) × 系数
- 平衡型：1.0 kWh/kW
- 高端型：1.5 kWh/kW
```

**最终推荐**：取三种方法计算结果的最大值，并标准化到常见电池规格。

## 使用方法

1. 打开 `equipment-recommender.html` 文件
2. 选择房屋样本（GIS ID）
3. 选择用户所在州
4. 选择电网相位类型
5. 查看完整推导过程和三套方案对比
