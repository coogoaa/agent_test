## 🎯 核心功能

### 1. 配置编辑器 (config-editor.html)

**四个按钮**:
- 💾 **保存配置**: 将当前配置保存到浏览器localStorage
- 📥 **导出配置**: 下载JSON文件，可分享或备份
- 📂 **导入配置**: 从JSON文件加载配置并自动保存
- 🔄 **重置**: 清除保存的配置，恢复默认值

**自动加载**:
- 页面加载时自动恢复上次保存的配置
- 修改后的值会显示在表单中

### 2. 配置加载器 (config-loader.js)

**共享配置**:
- 所有页面通过此文件加载配置
- 优先使用localStorage中的配置
- 如果没有保存的配置，使用默认值

### 3. 推荐器页面 (equipment-recommender.html)

**使用配置**:
- 自动从localStorage加载配置
- 逆变器规格使用配置的值
- 推导日志显示配置的规格

### 4. 批量处理器 (batch-processor.html)

**使用配置**:
- 自动从localStorage加载配置
- PV功率、用电量、逆变器规格全部使用配置
- 与推荐器页面保持一致

## 📝 使用流程

### 场景1: 修改逆变器规格

**问题**: 方案C的单相逆变器默认是 [5, 8]，想改为 [3, 5, 8, 10]

**步骤**:

1. **打开配置编辑器**
   ```
   打开 config-editor.html
   ```

2. **找到逆变器配置标签**
   ```
   点击"逆变器配置"标签
   ```

3. **修改方案C单相逆变器**
   ```
   找到: 方案C (经济型) - 单相
   原值: 5, 8
   改为: 3, 5, 8, 10
   ```

4. **保存配置**
   ```
   点击 "💾 保存配置" 按钮
   看到提示: "✅ 配置已保存！所有页面将使用新配置。"
   ```

5. **验证生效**
   ```
   打开 equipment-recommender.html
   选择任意房屋，单相电网
   查看方案C的推导日志:
   "电网类型: 单相 → Hybrid逆变器 ≤10kW (配置: 3, 5, 8, 10)"
   ```

### 场景2: 导出配置分享给同事

**步骤**:

1. **导出配置**
   ```
   在 config-editor.html 点击 "📥 导出配置 (JSON)"
   下载文件: solar_config_1732654321000.json
   ```

2. **分享文件**
   ```
   通过邮件或云盘分享JSON文件
   ```

3. **同事导入配置**
   ```
   打开 config-editor.html
   点击 "📂 导入配置文件"
   选择JSON文件
   看到提示: "✅ 配置已导入并保存！"
   ```

4. **配置同步**
   ```
   所有页面自动使用新配置
   无需手动刷新
   ```

### 场景3: 恢复默认配置

**步骤**:

1. **重置配置**
   ```
   在 config-editor.html 点击 "🔄 重置为默认值"
   确认对话框: "确定要重置所有配置为默认值吗？"
   点击"确定"
   ```

2. **页面刷新**
   ```
   页面自动刷新
   localStorage中的配置被清除
   所有值恢复为默认
   ```

## 🔧 技术实现

### localStorage存储

**存储键**: `solarConfig`

**存储内容**:
```json
{
  "pv": {
    "model": "JA Solar JAM72S30 550/MR",
    "pmax": 440
  },
  "battery": {
    "premium": { "daily": 0.5, "evening": 2.0, "pv": 1.5 },
    "balanced": { "daily": 0.3, "evening": 1.5, "pv": 1.0 },
    "economy": { "daily": 0.2, "evening": 1.0, "pv": 0.8 },
    "standards": [5, 6.5, 9.6, 10, 13.5, 16, 20]
  },
  "inverter": {
    "single": {
      "a": [5, 6, 8, 10],
      "b": [5, 8],
      "c": [3, 5, 8, 10]  // 修改后的值
    },
    "three": {
      "a": [5, 8, 10, 15, 20, 30],
      "b": [5, 8, 10, 15],
      "c": [5, 8, 10]
    },
    "targetRatio": 1.8,
    "maxRatio": 2.0
  },
  "consumption": { ... },
  "cost": { ... },
  "subsidy": { ... }
}
```

### 配置加载流程

```javascript
// 1. 页面加载时
const CONFIG = loadConfig();  // 从localStorage或默认值

// 2. 使用配置
const INVERTER_CONFIG = CONFIG.inverter;
const stdSizesA = phaseType === 'single' 
    ? INVERTER_CONFIG.single.a  // [3, 5, 8, 10]
    : INVERTER_CONFIG.three.a;

// 3. 选择逆变器
let invA = stdSizesA.find(s => s >= invA_size) || stdSizesA[0];
```

### 配置保存流程

```javascript
// 1. 收集表单数据
const config = collectConfig();

// 2. 保存到localStorage
localStorage.setItem('solarConfig', JSON.stringify(config));

// 3. 提示用户
alert('✅ 配置已保存！');
```

## 📋 可配置参数清单

### PV配置
- 型号 (model)
- 最大功率 (pmax)

### 电池配置
- 高端型系数 (premium: daily, evening, pv)
- 平衡型系数 (balanced: daily, evening, pv)
- 经济型系数 (economy: daily, evening, pv)
- 标准容量 (standards)

### 逆变器配置
- **单相逆变器**:
  - 方案A (高端型): `single.a`
  - 方案B (平衡型): `single.b`
  - 方案C (经济型): `single.c`
- **三相逆变器**:
  - 方案A (高端型): `three.a`
  - 方案B (平衡型): `three.b`
  - 方案C (经济型): `three.c`
- 目标容配比 (targetRatio)
- 最大容配比 (maxRatio)

### 用电量配置
- 各州年度用电量 (TAS, NT, ACT, SA, NSW, QLD, VIC, WA)

### 成本配置
- PV单价 (pvPerKw)
- 逆变器单价 (inverterPerKw)
- 电池单价 (batteryPerKwh)
- GST税率 (gstRate)

### 补贴配置
- STC价格 (stcPrice)
- 安装年份 (installYear)
- Deeming结束年份 (deemingEndYear)
- 电池STC系数 (batteryStcFactor)
- 电池容量上限 (batteryCapacityCap)
- 各州Zone Rating (TAS, NT, ACT, SA, NSW, QLD, VIC, WA)

## ⚠️ 注意事项

### 1. 浏览器兼容性

**localStorage限制**:
- 仅在同一浏览器中有效
- 不同浏览器之间不共享
- 隐私模式下可能不可用

**解决方案**:
- 使用"导出配置"功能备份
- 在其他浏览器中"导入配置"

### 2. 配置验证

**无效值处理**:
- 逆变器规格必须是数字数组
- 用电量必须是正整数
- 成本和补贴参数必须是正数

**错误提示**:
- 导入配置时会验证JSON格式
- 无效配置会显示错误提示

### 3. 默认值

**何时使用默认值**:
- 首次访问页面
- 点击"重置"按钮后
- localStorage被清除后
- 配置文件损坏时

## 🎉 完整示例

### 示例: 修改方案C逆变器规格

**原配置**:
```javascript
single: {
  c: [5, 8]  // 默认值
}
```

**修改为**:
```javascript
single: {
  c: [3, 5, 8, 10]  // 新值
}
```

**效果对比**:

| 场景 | PV容量 | 原逆变器 | 新逆变器 | 容配比 |
|------|--------|---------|---------|--------|
| 房屋27 | 6.6kW | 5kW | 5kW | 132% |
| 房屋15 | 4.4kW | 5kW | 3kW | 147% |
| 房屋8 | 3.5kW | 5kW | 3kW | 117% |

**优势**:
- 小容量系统可以选择3kW逆变器
- 容配比更合理
- 成本更低
