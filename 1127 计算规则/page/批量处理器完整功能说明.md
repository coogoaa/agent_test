# 批量处理器完整功能说明

## ✅ 功能完成

### 1. 完整方案和报价 ✓

每个房屋生成三套方案（A/B/C），每套方案包含：

#### 基础配置
- PV容量（数值 + 单位）
- 面板数量
- 逆变器功率（数值 + 单位）
- 容配比（数值 + 单位）
- 电池容量（数值 + 单位）

#### 成本计算
- 含税价（数值 + 单位）
- 计算公式：PV成本 + 逆变器成本 + 电池成本 × 1.1

#### 补贴计算
- STC补贴（数值 + 单位）
- 使用可用容量 = 标称容量 × 0.9

#### 最终报价
- 客户实付（数值 + 单位）
- 计算公式：含税价 - 补贴

### 2. 数值和单位分离 ✓

**原格式**（不便于Excel分析）:
```
PV容量: "6.6 kW"
逆变器: "5kW Hybrid"
电池: "6.5kWh"
```

**新格式**（便于Excel分析）:
```

pvKw_unit: "kW"
inverter_value: 5
inverter_unit: "kW"
battery_value: 6.5
battery_unit: "kWh"
```

## 💰 成本和补贴计算

### 成本计算公式

```javascript
// 1. 组件成本
pvCost = pvKw × 540  // AUD/kW
inverterCost = inverterKw × 280  // AUD/kW
batteryCost = batteryKwh × 865  // AUD/kWh

// 2. 总成本
preTaxTotal = pvCost + inverterCost + batteryCost
taxTotal = preTaxTotal × 1.1  // GST 10%
```

### 补贴计算公式

```javascript
// 1. Deeming Period
deemingPeriod = 2030 - 2025 + 1 = 6年

// 2. PV STC
pvStc = FLOOR(pvKw × zoneRating × deemingPeriod)

// 3. Battery STC (使用可用容量)
usableCapacity = batteryNominalKwh × 0.9  // DoD
batteryStc = FLOOR(usableCapacity × 9.3)

// 4. 总补贴
totalStc = pvStc + batteryStc
subsidyAmount = totalStc × 39  // AUD per STC
```

### 最终报价

```javascript
finalPrice = taxTotal - subsidyAmount
```

## 🔧 技术实现

### 核心函数

```javascript
// 1. 成本计算
function calculateCost(pvKw, inverterKw, batteryKwh) {
    const pvCost = pvKw * 540;
    const inverterCost = inverterKw * 280;
    const batteryCost = batteryKwh * 865;
    const preTaxTotal = pvCost + inverterCost + batteryCost;
    const taxTotal = preTaxTotal * 1.1;
    return { pvCost, inverterCost, batteryCost, preTaxTotal, taxTotal };
}

// 2. 补贴计算
function calculateSubsidy(pvKw, batteryNominalKwh, state) {
    const deemingPeriod = 6;  // 2025-2030
    const zoneRating = SUBSIDY_CONFIG.zoneRating[state];
    const pvStc = Math.floor(pvKw * zoneRating * deemingPeriod);
    
    const usableCapacity = batteryNominalKwh * 0.9;  // DoD
    const batteryStc = Math.floor(usableCapacity * 9.3);
    
    const totalStc = pvStc + batteryStc;
    const subsidyAmount = totalStc * 39;
    
    return { pvStc, batteryStc, totalStc, subsidyAmount, usableCapacity };
}
```
