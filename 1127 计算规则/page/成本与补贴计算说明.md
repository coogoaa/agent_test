# 成本与补贴计算说明

## 一、成本计算

### 1.1 计算公式

#### 税前报价
```
税前报价 = PV容量(kW) × 每kW面板报价 + 逆变器功率(kW) × 每kW逆变器报价 + 电池容量(kWh) × 每kWh电池报价
```

#### 含税报价
```
含税报价 = 税前报价 × (1 + GST税率)
```

### 1.2 默认参数

| 参数 | 默认值 | 单位 | 说明 |
|------|--------|------|------|
| 每kW面板税前报价 | 540 | AUD/kW | 包含组件、支架、安装 |
| 每kW逆变器报价 | 280 | AUD/kW | 包含设备、安装 |
| 每kWh电池报价 | 865 | AUD/kWh | 基于标称容量 |
| GST税率 | 0.1 | - | 澳洲商品及服务税（10%） |

### 1.3 计算示例

#### 示例1: 方案C (经济型)
**配置**: 6.6kW PV + 5kW逆变器 + 6.5kWh电池

**计算过程**:
```
PV成本 = 6.6 × 540 = 3,564 AUD
逆变器成本 = 5 × 280 = 1,400 AUD
电池成本 = 6.5 × 865 = 5,622.5 AUD
税前总价 = 3,564 + 1,400 + 5,622.5 = 10,586.5 AUD
含税总价 = 10,586.5 × 1.1 = 11,645.15 AUD
```

#### 示例2: 方案B (平衡型)
**配置**: 13.2kW PV + 8kW逆变器 + 13.5kWh电池

**计算过程**:
```
PV成本 = 13.2 × 540 = 7,128 AUD
逆变器成本 = 8 × 280 = 2,240 AUD
电池成本 = 13.5 × 865 = 11,677.5 AUD
税前总价 = 7,128 + 2,240 + 11,677.5 = 21,045.5 AUD
含税总价 = 21,045.5 × 1.1 = 23,150.05 AUD
```

#### 示例3: 方案A (高端型)
**配置**: 19.8kW PV + 10kW逆变器 + 20kWh电池

**计算过程**:
```
PV成本 = 19.8 × 540 = 10,692 AUD
逆变器成本 = 10 × 280 = 2,800 AUD
电池成本 = 20 × 865 = 17,300 AUD
税前总价 = 10,692 + 2,800 + 17,300 = 30,792 AUD
含税总价 = 30,792 × 1.1 = 33,871.20 AUD
```

## 二、补贴计算 (STC)

### 2.1 补贴体系说明

**STC (Small-scale Technology Certificates)** 是澳洲政府为鼓励可再生能源安装而提供的小规模技术证书补贴。

### 2.2 计算公式

#### PV系统STC
```
PV STC数量 = FLOOR(PV容量(kW) × Zone Rating × Deeming Period)
```

#### 电池系统STC
```
Battery STC数量 = FLOOR(可用电池容量(kWh) × STC因子/kWh)
```
**注意**: 可用电池容量上限为50kWh，超出部分不予补贴

#### 总补贴金额
```
总STC数量 = PV STC数量 + Battery STC数量
补贴金额 = 总STC数量 × STC单价
```

### 2.3 关键参数

#### 2.3.1 Deeming Period（计算年限）
```
Deeming Period = 终止年 - 安装年 + 1
```

**示例**:
| 安装年份 | 计算 | Deeming Period | 包含年份 |
|---------|------|---------------|---------|
| 2024 | 2030 - 2024 + 1 | 7年 | 2024-2030 |
| 2025 | 2030 - 2025 + 1 | 6年 | 2025-2030 |
| 2026 | 2030 - 2026 + 1 | 5年 | 2026-2030 |
| 2030 | 2030 - 2030 + 1 | 1年 | 仅2030 |

**默认值**:
- 终止年: 2030 (政策固定)
- 安装年: 2025

#### 2.3.2 Zone Rating（区域系数）

根据不同州/领地的太阳能资源确定：

| 州/领地 | Zone Rating | 说明 |
|--------|-------------|------|
| NT (北领地) | 1.622 | 最高（阳光最充足） |
| SA (南澳) | 1.536 | 较高 |
| QLD (昆士兰) | 1.536 | 较高 |
| WA (西澳) | 1.536 | 较高 |
| TAS (塔斯马尼亚) | 1.382 | 标准 |
| ACT (首都领地) | 1.382 | 标准 |
| NSW (新南威尔士) | 1.382 | 标准 |
| VIC (维多利亚) | 1.382 | 标准 |

#### 2.3.3 Battery STC因子

**2025年标准**: 9.3 STC/kWh

**说明**: 该系数每年递减，基于Deeming Period逐年降低

#### 2.3.4 STC单价

**默认值**: 39 AUD/STC

**说明**: 市场价格，会根据供需波动（通常在35-40 AUD之间）

### 2.4 计算示例

#### 示例1: NSW州，2025年安装
**配置**: 6.6kW PV + 6.5kWh电池

**步骤1: 计算Deeming Period**
```
Deeming Period = 2030 - 2025 + 1 = 6年
```

**步骤2: 计算PV STC**
```
PV STC = FLOOR(6.6 × 1.382 × 6)
       = FLOOR(54.7)
       = 54 STC
```

**步骤3: 计算Battery STC**
```
Battery STC = FLOOR(6.5 × 9.3)
            = FLOOR(60.45)
            = 60 STC
```

**步骤4: 计算总补贴**
```
总STC = 54 + 60 = 114 STC
补贴金额 = 114 × 39 = 4,446 AUD
```

#### 示例2: QLD州，2025年安装
**配置**: 13.2kW PV + 13.5kWh电池

**步骤1: Deeming Period**
```
Deeming Period = 6年 (同上)
```

**步骤2: PV STC**
```
PV STC = FLOOR(13.2 × 1.536 × 6)
       = FLOOR(121.7)
       = 121 STC
```

**步骤3: Battery STC**
```
Battery STC = FLOOR(13.5 × 9.3)
            = FLOOR(125.55)
            = 125 STC
```

**步骤4: 总补贴**
```
总STC = 121 + 125 = 246 STC
补贴金额 = 246 × 39 = 9,594 AUD
```

#### 示例3: NT州（高Zone Rating），2025年安装
**配置**: 19.8kW PV + 20kWh电池

**步骤1: Deeming Period**
```
Deeming Period = 6年
```

**步骤2: PV STC**
```
PV STC = FLOOR(19.8 × 1.622 × 6)
       = FLOOR(192.7)
       = 192 STC
```

**步骤3: Battery STC**
```
Battery STC = FLOOR(20 × 9.3)
            = FLOOR(186)
            = 186 STC
```

**步骤4: 总补贴**
```
总STC = 192 + 186 = 378 STC
补贴金额 = 378 × 39 = 14,742 AUD
```

## 三、净成本计算

### 3.1 公式
```
客户实际支付 = 含税报价 - STC补贴
```

### 3.2 完整示例

#### 方案C (经济型) - NSW州
**配置**: 6.6kW PV + 5kW逆变器 + 6.5kWh电池

**成本计算**:
```
税前报价 = 10,586.5 AUD
含税报价 = 11,645.15 AUD
```

**补贴计算**:
```
STC补贴 = 4,446 AUD
```

**净成本**:
```
客户实际支付 = 11,645.15 - 4,446 = 7,199.15 AUD
```

#### 方案B (平衡型) - QLD州
**配置**: 13.2kW PV + 8kW逆变器 + 13.5kWh电池

**成本计算**:
```
税前报价 = 21,045.5 AUD
含税报价 = 23,150.05 AUD
```

**补贴计算**:
```
STC补贴 = 9,594 AUD
```

**净成本**:
```
客户实际支付 = 23,150.05 - 9,594 = 13,556.05 AUD
```

#### 方案A (高端型) - NT州
**配置**: 19.8kW PV + 10kW逆变器 + 20kWh电池

**成本计算**:
```
税前报价 = 30,792 AUD
```

## 四、JavaScript实现

### 4.1 成本计算函数

```javascript
function calculateCost(pvKw, inverterKw, batteryKwh, config) {
    const pvCost = pvKw * config.cost.pvPerKw;
    const inverterCost = inverterKw * config.cost.inverterPerKw;
    const batteryCost = batteryKwh * config.cost.batteryPerKwh;
    
    const preTaxTotal = pvCost + inverterCost + batteryCost;
    const taxTotal = preTaxTotal * (1 + config.cost.gstRate);
    
    return {
        pvCost: pvCost.toFixed(2),
        inverterCost: inverterCost.toFixed(2),
        batteryCost: batteryCost.toFixed(2),
        preTaxTotal: preTaxTotal.toFixed(2),
        taxTotal: taxTotal.toFixed(2)
    };
}
```

### 4.2 补贴计算函数

```javascript
function calculateSubsidy(pvKw, batteryKwh, state, config) {
    // 计算Deeming Period
    const deemingPeriod = config.subsidy.deemingEndYear - config.subsidy.installYear + 1;
    
    // PV STC
    const zoneRating = config.subsidy.zoneRating[state];
    const pvStc = Math.floor(pvKw * zoneRating * deemingPeriod);
    
    // Battery STC (上限50kWh)
    const usableBatteryKwh = Math.min(batteryKwh, config.subsidy.batteryCapacityCap);
    const batteryStc = Math.floor(usableBatteryKwh * config.subsidy.batteryStcFactor);
    
    // 总补贴
    const totalStc = pvStc + batteryStc;
    const subsidyAmount = totalStc * config.subsidy.stcPrice;
    
    return {
        deemingPeriod,
        zoneRating,
        pvStc,
        batteryStc,
        totalStc,
        subsidyAmount: subsidyAmount.toFixed(2)
    };
}
```

### 4.3 完整计算函数

```javascript
function calculateFullCostAndSubsidy(pvKw, inverterKw, batteryKwh, state, config) {
    const cost = calculateCost(pvKw, inverterKw, batteryKwh, config);
    const subsidy = calculateSubsidy(pvKw, batteryKwh, state, config);
    
    const netCost = parseFloat(cost.taxTotal) - parseFloat(subsidy.subsidyAmount);
    
    return {
        cost,
        subsidy,
        netCost: netCost.toFixed(2)
    };
}
```

## 五、配置参数管理

### 5.1 在配置编辑器中修改

打开 `config-editor.html`，切换到对应Tab：

1. **成本参数Tab**: 修改单价和税率
2. **补贴参数Tab**: 修改STC相关参数和Zone Rating

### 5.2 导出配置

点击"导出配置"按钮，生成JSON文件：

```json
{
  "cost": {
    "pvPerKw": 540,
    "inverterPerKw": 280,
    "batteryPerKwh": 865,
    "gstRate": 0.1
  },
  "subsidy": {
    "stcPrice": 39,
    "installYear": 2025,
    "deemingEndYear": 2030,
    "batteryStcFactor": 9.3,
    "batteryCapacityCap": 50,
    "zoneRating": {
      "TAS": 1.382,
      "NT": 1.622,
      "ACT": 1.382,
      "SA": 1.536,
      "NSW": 1.382,
      "QLD": 1.536,
      "VIC": 1.382,
      "WA": 1.536
    }
  }
}
```

### 5.3 在主页面中使用

在 `equipment-recommender.html` 或 `batch-processor.html` 中导入配置文件，系统会自动使用新参数计算成本和补贴。

## 六、注意事项

### 6.1 成本计算
- 所有单价均为税前价格
- GST税率固定为10%（可在配置中修改）
- 电池成本基于标称容量，不是可用容量

### 6.2 补贴计算
- STC数量必须向下取整（FLOOR函数）
- 电池可用容量上限50kWh
- Zone Rating根据州/邮编确定，可能有细微差异
- Deeming Period每年递减
- STC单价受市场波动影响

### 6.3 政策更新
- 2030年后STC政策可能调整
- Battery STC因子每年递减
- 建议定期更新配置参数

## 七、常见问题

### Q1: 为什么电池补贴有50kWh上限？
**A**: 这是澳洲政府政策规定，超出50kWh的部分不予补贴，但仍需支付成本。

### Q2: Zone Rating如何确定？
**A**: 基于邮编的太阳能资源评估，可在Clean Energy Regulator官网查询具体邮编的Zone Rating。

### Q3: STC单价为什么是39 AUD？
**A**: 这是当前市场价格，实际价格在35-40 AUD之间波动，建议根据实时市场价格调整。

### Q4: 2026年安装的Deeming Period是多少？
**A**: 2030 - 2026 + 1 = 5年

### Q5: 如何计算不同年份的Battery STC因子？
**A**: 2025年为9.3，每年递减约0.5-0.6，具体数值需参考官方公布的年度标准。
