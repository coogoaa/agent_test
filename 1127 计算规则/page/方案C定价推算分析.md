## 四、三套方案价格对比计算

### 方案 A: 线性定价
```
PV成本 = pvKw × $540/kW
逆变器成本 = inverterKw × $280/kW  
电池成本 = batteryKwh × $865/kWh
税前总价 = PV成本 + 逆变器成本 + 电池成本
含税总价 = 税前总价 × 1.1
最终价格 = 含税总价 - 补贴
```

### 方案 B: 基准+增量定价
```
基准价格 = $4,500 (6.6kW)
超额价格 = (pvKw - 6.6) × $500/kW
电池价格 = $1,500 + batteryKwh × $700/kWh
税前总价 = 基准价格 + 超额价格 + 电池价格
含税总价 = 税前总价 × 1.1
最终价格 = 含税总价 - 补贴
```

### 方案 C: $/kW 简化定价 (原始参数)
```
不含税不含补贴:
  PV成本 = pvKw × $1,150/kW (Hybrid)
  电池成本 = batteryKwh × $750/kWh
  总价 = PV成本 + 电池成本

含税含补贴:
  PV成本 = pvKw × $920/kW
  电池成本 = batteryKwh × $500/kWh
  总价 = PV成本 + 电池成本
```

## 六、调整后的方案 C 参数

为了使方案 C 与方案 A/B 价格贴近，需要调整参数：

### 反推合理参数

从方案 A/B 的税前价格反推：
- 方案 A 税前: $13,894 → 6.6kW + 10kWh
- 方案 B 税前: $13,000 → 6.6kW + 10kWh

**反推 PV 单价 (不含税不含补贴):**
- 方案 A: PV+逆变器 = $3,564 + $1,680 = $5,244 → $5,244 / 6.6 = **$794/kW**
- 方案 B: PV = $4,500 → $4,500 / 6.6 = **$682/kW**

**反推电池单价 (不含税不含补贴):**
- 方案 A: $8,650 / 10 = **$865/kWh**
- 方案 B: ($8,500 - $1,500) / 10 = **$700/kWh**

### 建议的方案 C 参数

| 类型 | 不含税不含补贴 | 含税含补贴 |
|------|--------------|----------|
| **Solar Only** | $750/kW | $600/kW |
| **Hybrid PV** | $800/kW | $650/kW |
| **电池** | $700/kWh | $450/kWh |

### 验证调整后的价格

**6.6kW PV + 10kWh 电池 (TAS州):**
- 不含税不含补贴: 6.6 × $800 + 10 × $700 = $5,280 + $7,000 = **$12,280**
- 含税含补贴: 6.6 × $650 + 10 × $450 = $4,290 + $4,500 = **$8,790**

**对比:**
| 方案 | 最终价格 | $/kW 单价 |
|------|---------|----------|
| 方案 A (含税-补贴) | $9,300 | $1,409 |
| 方案 B (含税-补贴) | $8,539 | $1,294 |
| 方案 C (不含税不含补贴) | $12,280 | $1,861 |
| 方案 C (含税含补贴) | $8,790 | $1,332 |

## 八、方案 D: 分离式定价

### 公式 (含税含补贴)

```
// 无电池系统
system_cost = system_capacity_kW × $900

// 有电池系统
system_cost = battery_cost + system_capacity_kW × $700

// 电池成本
battery_cost = capacity_kWh × $750 + $3000 (安装费)
```

### 推算不含税不含补贴价格

| 项目 | 含税含补贴 | 不含税不含补贴 (推算) |
|------|----------|-------------------|
| Solar Only | $900/kW | $1,100/kW |
| Hybrid PV | $700/kW | $860/kW |
| 电池安装费 | $3,000 | $3,700 |
| 电池容量 | $750/kWh | $920/kWh |

### 验证计算 (6.6kW + 10kWh, TAS)

**含税含补贴:**
- PV: 6.6 × $700 = $4,620
- 电池: $3,000 + 10 × $750 = $10,500
- 总计: **$15,120**

**不含税不含补贴:**
- PV: 6.6 × $860 = $5,676
- 电池: $3,700 + 10 × $920 = $12,900
- 总计: **$18,576**

### 价格对比

| 方案 | 6.6kW+10kWh (含税补) | $/kW |
|------|---------------------|------|
| 方案 A | $9,300 | $1,409 |
| 方案 B | $8,539 | $1,294 |
| 方案 C | $8,790 | $1,332 |
| **方案 D** | **$15,120** | **$2,291** |

**注意**: 方案 D 的价格明显高于其他方案，这是因为公式中的电池成本较高（$750/kWh + $3000安装费）。如需调整，可以在配置编辑器中修改参数。
