## 一、问题总结

### 1.1 用户反馈的核心问题

**问题描述**:
> 选择房屋 ID 44，该房屋共 5 个坡面，5 个可安装，物理上限 46 片 (20.24kW)
> 界面的逆变器选型不对。
> 
> 推导显示：
> ```
> 最终配置: 46 片 × 440W = 20.24 kW
> 方案类型: 高端型 (含储能) → 允许容配比 150%-200%
> 电网类型: 单相 → Hybrid逆变器限制 ≤10kW (配置: 5, 6, 8, 10)
> 逆变器选型: 目标容配比180% → 需要 1.0kW → 选择 5kW Hybrid
> ```

**问题分析**:
- "需要 1.0kW" 明显错误，应该是约 12kW
- 实际容配比: 20.24kW / 5kW = 405%，严重超标！

### 1.2 根本原因

**配置不一致问题**:

| 文件 | targetRatio 值 | 说明 |
|------|---------------|------|
| config-loader.js (默认) | 1.8 | 表示 1.8 倍 (180%) |
| config-editor.html (界面) | 180 | 表示 180% |
| 计算代码 | 直接除以 targetRatio | 期望小数格式 |

**错误计算**:
```javascript
// 如果用户在配置编辑器中保存了 180
let invA_size = Math.ceil(20.24 / 180);  // = 1kW ❌

// 正确应该是
let invA_size = Math.ceil(20.24 / 1.8);  // = 12kW ✓
```

## 二、修复方案

### 2.1 统一 targetRatio 配置格式

**决策**: 统一使用百分比格式 (180, 200)，在计算时除以 100

**修改文件**:
1. `config-loader.js`
2. `equipment-recommender.html`
3. `batch-processor.html`

#### 修改 1: config-loader.js

**修改前**:
```javascript
inverter: {
    // ...
    targetRatio: 1.8,
    maxRatio: 2.0
}
```

**修改后**:
```javascript
inverter: {
    // ...
    targetRatio: 180,  // 目标容配比 180%
    maxRatio: 200      // 最大容配比 200%
}
```

#### 修改 2: equipment-recommender.html (3处)

**修改前**:
```javascript
let invA_size = Math.ceil(resultA.totalKw / INVERTER_CONFIG.targetRatio);
```

**修改后**:
```javascript
let invA_size = Math.ceil(resultA.totalKw / (INVERTER_CONFIG.targetRatio / 100));
```

**影响位置**:
- 方案A逆变器选型 (第735行)
- 方案B逆变器选型 (第864行)
- 方案C逆变器选型 (第994行)

#### 修改 3: batch-processor.html (3处)

同样的修改应用到批量处理页面，确保逻辑一致。

**验证计算**:
```javascript
// 配置: targetRatio = 180
// PV容量: 20.24kW

let invA_size = Math.ceil(20.24 / (180 / 100));
// = Math.ceil(20.24 / 1.8)
// = Math.ceil(11.24)
// = 12kW ✓
```

### 2.2 添加标准电池规格开关

**需求**: 支持启用/禁用标准电池规格标准化

#### 修改 1: config-loader.js

**添加配置项**:
```javascript
battery: {
    premium: { daily: 0.5, evening: 2.0, pv: 1.5 },
    balanced: { daily: 0.3, evening: 1.5, pv: 1.0 },
    economy: { daily: 0.2, evening: 1.0, pv: 0.8 },
    standards: [5, 6.5, 9.6, 10, 13.5, 16, 20],
    useStandards: true,  // 新增: 是否使用标准电池规格标准化
    dod: 0.9,
    rte: 0.9
}
```

#### 修改 2: config-editor.html

**添加开关控件**:
```html
<div class="flex items-center mb-3 bg-yellow-50 p-3 rounded border border-yellow-200">
    <input type="checkbox" id="battery-use-standards" class="mr-2 w-4 h-4">
    <label for="battery-use-standards" class="text-sm font-medium text-gray-700">
        启用标准电池规格标准化
    </label>
</div>
```

**配置收集**:
```javascript
battery: {
    // ...
    useStandards: document.getElementById('battery-use-standards').checked,
    // ...
}
```

#### 修改 3: equipment-recommender.html

**修改电池容量计算函数**:
```javascript
// 根据配置决定是否标准化到常见电池规格
let finalCapacity = capacity;
if (CONFIG.battery.useStandards) {
    const standardSizes = CONFIG.battery.standards || [0, 5, 6.5, 9.6, 10, 13.5, 16, 20];
    finalCapacity = standardSizes.find(s => s >= capacity) || capacity;
}

return {
    calculated: capacity,
    standard: finalCapacity,
    isStandardized: CONFIG.battery.useStandards,
    methodDesc: methodDesc,
    dailyConsumption: dailyConsumption,
    eveningPeak: eveningPeakConsumption
};
```

#### 修改 4: batch-processor.html

同样的逻辑应用到批量处理页面。

**功能说明**:
- **开启** (默认): 电池容量标准化到 [5, 6.5, 9.6, 10, 13.5, 16, 20] kWh
- **关闭**: 使用计算出的精确值

**示例**:
```
计算值: 13.2 kWh

开启标准化: 13.5 kWh (向上取整到最接近的标准规格)
关闭标准化: 13.2 kWh (使用精确值)
```

## 六、使用说明

### 6.1 配置编辑器使用

#### 修改目标容配比
1. 打开 `config-editor.html`
2. 切换到"逆变器规格"标签
3. 修改"目标容配比 (%)"，例如改为 170
4. 点击"保存配置"

#### 启用/禁用电池规格标准化
1. 打开 `config-editor.html`
2. 切换到"电池计算系数"标签
3. 勾选/取消勾选"启用标准电池规格标准化"
4. 点击"保存配置"
