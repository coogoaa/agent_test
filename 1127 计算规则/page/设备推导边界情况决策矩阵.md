## 2. 详细决策矩阵

### A. 屋顶相关边界情况

#### A1. 无可用坡面

| 项目 | 内容 |
|------|------|
| **触发条件** | 所有坡面的 `nums = 0` |
| **检测方式** | `roofPlanes.every(p => p.max === 0)` |
| **处理策略** | 返回空配置，提示用户 |
| **输出结果** | PV=0kW, 逆变器=N/A, 电池=0kWh |
| **用户提示** | "该房屋无可安装光伏组件的屋顶空间" |

```javascript
// 代码实现
if (totalMaxPanels === 0) {
    return {
        count: 0,
        totalKw: 0,
        layoutStr: "无可用空间",
        warning: "该房屋无可安装光伏组件的屋顶空间"
    };
}
```

#### A2. 屋顶容量不足

| 项目 | 内容 |
|------|------|
| **触发条件** | 物理最大容量 < 目标容量 |
| **检测方式** | `totalMaxKw < targetKw` |
| **处理策略** | 使用实际最大容量，不强制达到目标 |
| **输出结果** | PV = 实际最大容量 |
| **用户提示** | "屋顶空间有限，已使用最大可用容量 X.XX kW" |

**决策流程**：

```
目标容量 = 13 kW
物理上限 = 8.8 kW (20片 × 440W)
    ↓
实际配置 = 8.8 kW
提示: "屋顶空间有限，已使用最大可用容量 8.8 kW"
```

#### A3. 所有坡面朝向不佳

| 项目 | 内容 |
|------|------|
| **触发条件** | 所有坡面评分 < 60 (均为南向) |
| **检测方式** | `roofPlanes.every(p => calculateSlopeScore(p.aspect) < 60)` |
| **处理策略** | 正常计算，但添加警告提示 |
| **输出结果** | 正常配置 + 警告信息 |
| **用户提示** | "⚠️ 该房屋屋顶朝向不佳，发电效率可能低于预期" |

#### A4. 单一坡面容量过大

| 项目 | 内容 |
|------|------|
| **触发条件** | 单个坡面容量 > 总目标容量的 80% |
| **检测方式** | `plane.max * PV_WATT / 1000 > targetKw * 0.8` |
| **处理策略** | 正常计算，记录布局信息 |
| **输出结果** | 布局显示主要集中在单一坡面 |
| **用户提示** | "组件主要安装在 [坡面ID]，建议检查结构承重" |

### B. 逆变器相关边界情况

#### B1. 容配比超过200%上限

| 项目 | 内容 |
|------|------|
| **触发条件** | `PV容量 / 逆变器容量 > 200%` |
| **检测方式** | `(resultKw / inverterKw * 100) > maxRatio` |
| **处理策略** | 优先升级逆变器，否则减少组件 |

**决策流程图**：

```
容配比 > 200%
    ↓
┌─────────────────────────────────────┐
│ 尝试升级逆变器                       │
│ minInv = ceil(PV容量 / 2.0)         │
└──────────────┬──────────────────────┘
               ↓
    ┌──────────┴──────────┐
    ↓                     ↓
有更大规格可用         已达电网上限
    ↓                     ↓
升级逆变器            减少PV组件
    ↓                     ↓
重新计算容配比        从低评分坡面移除
```

**减少组件计算公式**：

```javascript
// 计算需要移除的组件数
maxAllowedKw = maxInverter * 2.0;  // 最大允许PV容量
excessKw = actualPvKw - maxAllowedKw;  // 超出容量
panelsToRemove = Math.ceil(excessKw * 1000 / PV_WATT);  // 需移除组件数

// 从低评分坡面开始移除
sortedByScore = roofPlanes.sort((a, b) => a.score - b.score);
for (let plane of sortedByScore) {
    // 依次从评分最低的坡面移除
}
```

#### B2. 容配比低于150%下限

| 项目 | 内容 |
|------|------|
| **触发条件** | `PV容量 / 逆变器容量 < 150%` |
| **检测方式** | `(resultKw / inverterKw * 100) < 150` |
| **处理策略** | 仅提示，不强制调整 |
| **输出结果** | 正常配置 + 优化建议 |
| **用户提示** | "💡 容配比偏低，可考虑减小逆变器以提高经济性" |

**为什么不强制调整**：
- 低容配比不违反技术规范
- 用户可能有扩容计划
- 保留灵活性

#### B3. 逆变器已达电网相位上限

| 项目 | 内容 |
|------|------|
| **触发条件** | 需要的逆变器 > 电网相位允许的最大值 |
| **检测方式** | `requiredInverter > phaseMaxLimit` |
| **处理策略** | 使用最大允许逆变器，减少PV组件 |

**单相/三相限制**：

| 电网类型 | 最大逆变器 | 最大PV容量 (200%容配比) |
|---------|-----------|----------------------|
| 单相 | 10 kW | 20 kW |
| 三相 | 30 kW | 60 kW |

#### B4. 无匹配的标准逆变器规格

| 项目 | 内容 |
|------|------|
| **触发条件** | 计算出的需求不在标准规格列表中 |
| **检测方式** | `!options.includes(requiredKw)` |
| **处理策略** | 向上取整到最近的可用规格 |

**示例**：

```
需求: 7.33 kW
可选规格: [3, 5, 6, 8, 10]
选择: 8 kW (≥7.33 的最小值)
```

### C. 电池相关边界情况

#### C1. 计算容量超过最大标准规格

| 项目 | 内容 |
|------|------|
| **触发条件** | 计算出的电池容量 > 20 kWh (最大标准规格) |
| **检测方式** | `calculatedCapacity > maxStandardSize` |
| **处理策略** | 使用计算值，标记为"定制规格" |
| **输出结果** | 实际计算值 + 定制标记 |
| **用户提示** | "推荐容量超过标准规格，可能需要多电池组合" |

```javascript
// 代码实现
const standardSizes = [0, 5, 6.5, 9.6, 10, 13.5, 16, 20];
const maxStandard = standardSizes[standardSizes.length - 1];

if (calculatedCapacity > maxStandard) {
    return {
        capacity: calculatedCapacity,
        isCustom: true,
        note: "推荐容量超过标准规格，可能需要多电池组合"
    };
}
```

#### C2. 计算容量为零或负值

| 项目 | 内容 |
|------|------|
| **触发条件** | PV容量 = 0 或计算异常 |
| **检测方式** | `calculatedCapacity <= 0` |
| **处理策略** | 返回 0，不配置电池 |
| **输出结果** | 电池容量 = 0 kWh |

#### C3. 三维度计算结果差异过大

| 项目 | 内容 |
|------|------|
| **触发条件** | max(三维度) / min(三维度) > 3 |
| **检测方式** | 比较三个维度的计算结果 |
| **处理策略** | 正常取最大值，但添加说明 |
| **用户提示** | "电池容量由 [维度名称] 决定，确保 [具体保障目标]" |

**示例**：

```
维度1 (日用电): 4 kWh
维度2 (傍晚峰值): 5 kWh
维度3 (PV匹配): 15 kWh  ← 决定因素

提示: "电池容量由PV匹配维度决定，确保充分吸收光伏发电"
```

### D. 方案冲突边界情况

#### D1. 三套方案配置相同

| 项目 | 内容 |
|------|------|
| **触发条件** | 方案A = 方案B = 方案C |
| **检测方式** | 比较三套方案的PV容量 |
| **原因分析** | 屋顶容量过小，所有方案都达到物理上限 |
| **处理策略** | 正常显示，添加说明 |
| **用户提示** | "由于屋顶空间限制，三套方案配置相同" |

#### D2. 经济型方案超过平衡型

| 项目 | 内容 |
|------|------|
| **触发条件** | 方案C的PV容量 > 方案B的PV容量 |
| **检测方式** | `planC.totalKw > planB.totalKw` |
| **原因分析** | 配置参数异常或屋顶数据特殊 |
| **处理策略** | 调整方案C容量 ≤ 方案B容量 |

```javascript
// 确保方案层级合理
if (planC.totalKw > planB.totalKw) {
    planC.totalKw = planB.totalKw;
    planC.count = planB.count;
}
```

#### D3. 目标容量超过物理上限

| 项目 | 内容 |
|------|------|
| **触发条件** | 配置的目标容量 > 屋顶物理上限 |
| **检测方式** | `targetKw > totalMaxKw` |
| **处理策略** | 自动降级到物理上限 |
| **输出结果** | 实际配置 = 物理上限 |

## 3. 边界情况优先级

当多个边界情况同时发生时，按以下优先级处理：

| 优先级 | 边界情况 | 原因 |
|--------|---------|------|
| 1 | A1. 无可用坡面 | 无法继续计算 |
| 2 | B3. 逆变器达电网上限 | 硬性限制 |
| 3 | B1. 容配比超限 | 技术规范要求 |
| 4 | A2. 屋顶容量不足 | 物理限制 |
| 5 | D2. 方案层级冲突 | 逻辑一致性 |
| 6 | 其他提示类 | 仅供参考 |

## 4. 错误处理与用户反馈

### 4.1 错误分级

| 级别 | 类型 | 处理方式 | 示例 |
|------|------|---------|------|
| **Error** | 致命错误 | 终止计算，显示错误 | 无可用坡面 |
| **Warning** | 警告 | 继续计算，显示警告 | 容配比超限已调整 |
| **Info** | 提示 | 继续计算，显示建议 | 容配比偏低 |

### 4.2 用户反馈模板

**Error 级别**：
```
❌ 计算失败
原因: [具体原因]
建议: [解决方案]
```

**Warning 级别**：
```
⚠️ 配置已自动调整
原配置: [原始值]
调整后: [调整值]
原因: [调整原因]
```

**Info 级别**：
```
💡 优化建议
当前配置: [当前值]
建议: [优化方向]
```

## 6. 配置参数参考

### 6.1 系统默认参数

```javascript
const DEFAULT_CONFIG = {
    // 容配比参数
    inverter: {
        targetRatio: 180,    // 目标容配比 %
        maxRatio: 200,       // 最大容配比 %
        minRatio: 150,       // 建议最小容配比 %
        singleMaxKw: 10,     // 单相最大逆变器
        threeMaxKw: 30       // 三相最大逆变器
    },
    
    // 方案目标参数
    proposals: {
        premium: { targetKw: 999 },           // 高端型：满铺
        balanced: { 
            targetKwSmall: 10.0,              // 小屋顶目标
            targetKwLarge: 13.0,              // 大屋顶目标
            roofThreshold: 15                 // 大小屋顶阈值
        },
        economy: { targetKw: 6.6 }            // 经济型：固定6.6kW
    },
    
    // 电池参数
    battery: {
        standards: [0, 5, 6.5, 9.6, 10, 13.5, 16, 20],
        useStandards: true
    }
};
```

### 6.2 可调整参数说明

| 参数 | 调整影响 | 建议范围 |
|------|---------|---------|
| `targetRatio` | 影响逆变器选型 | 150-200% |
| `maxRatio` | 影响容配比上限校验 | 180-220% |
| `roofThreshold` | 影响方案B目标容量 | 10-20 kW |
| `economy.targetKw` | 影响方案C配置 | 5-8 kW |
