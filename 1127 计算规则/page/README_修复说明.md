# 光伏设备推荐系统 - 修复说明

## 🎯 核心问题

**用户反馈**: 房屋ID 44 的逆变器选型显示 "需要 1.0kW"，明显错误。

**根本原因**: 配置文件中 `targetRatio` 格式不一致
- config-loader.js: `1.8` (小数)
- config-editor.html: `180` (百分比)
- 导致计算错误: `20.24 / 180 = 0.11kW` ❌

---

## ✅ 已修复

### 1. 统一 targetRatio 配置格式
- **修改**: 统一使用百分比格式 (180, 200)
- **文件**: 
  - `config-loader.js`: 默认值改为 180
  - `equipment-recommender.html`: 计算时除以100
  - `batch-processor.html`: 计算时除以100

**修复后计算**:
```javascript
// 配置: targetRatio = 180
// PV: 20.24kW
逆变器需求 = ceil(20.24 / (180/100)) = ceil(11.24) = 12kW ✓
```

### 2. 添加标准电池规格开关
- **新功能**: 支持启用/禁用电池容量标准化
- **默认**: 开启 (保持现有行为)
- **位置**: config-editor.html → 电池计算系数标签

**功能说明**:
- 开启: 13.2kWh → 13.5kWh (标准化)
- 关闭: 13.2kWh → 13.2kWh (精确值)
