# 电网相位对逆变器选型的影响

## 修复说明

### 问题
之前的代码中，电网相位选择器没有真正影响逆变器选型，存在以下问题：
1. 方案B中有一行代码错误：`invB = phaseType === 'single' ? 8 : 8;` （无论单相还是三相都是8）
2. 方案A和C没有考虑电网相位的影响
3. 推导过程中没有显示电网类型的判断逻辑

### 修复内容

#### 1. 方案 A (经济型)
**单相 (Single Phase)**:
- 逆变器限制：≤5kW
- 选型逻辑：
  - PV ≤ 4kW → 3kW 逆变器
  - PV > 4kW → 5kW 逆变器

**三相 (Three Phase)**:
- 逆变器限制：≤8kW (经济型)
- 选型逻辑：
  - PV ≤ 4kW → 5kW 逆变器
  - 4kW < PV ≤ 7kW → 6kW 逆变器
  - PV > 7kW → 8kW 逆变器

#### 2. 方案 B (平衡型 - Hybrid)
**单相 (Single Phase)**:
- 逆变器限制：5-8kW
- 选型逻辑：
  - PV ≤ 10kW → 5kW Hybrid
  - PV > 10kW → 8kW Hybrid

**三相 (Three Phase)**:
- 逆变器限制：5-15kW
- 选型逻辑：
  - PV ≤ 10kW → 5kW Hybrid
  - 10kW < PV ≤ 16kW → 8kW Hybrid
  - 16kW < PV ≤ 20kW → 10kW Hybrid
  - PV > 20kW → 15kW Hybrid

#### 3. 方案 C (高端型)
**单相 (Single Phase)**:
- 逆变器限制：≤10kW
- 可选规格：5, 6, 8, 10 kW

**三相 (Three Phase)**:
- 逆变器限制：≤30kW
- 可选规格：5, 8, 10, 15, 20, 30 kW

## 测试方法

### 测试用例 1：小屋顶 + 单相
- 房屋ID: 1 (仅2片可用)
- 电网相位: 单相
- 预期结果：
  - 方案A: 3kW 逆变器
  - 方案B: 5kW Hybrid
  - 方案C: 5kW

### 测试用例 2：小屋顶 + 三相
- 房屋ID: 1
- 电网相位: 三相
- 预期结果：
  - 方案A: 5kW 逆变器（三相可选更大）
  - 方案B: 5kW Hybrid
  - 方案C: 5kW

### 测试用例 3：大屋顶 + 单相
- 房屋ID: 44 (46片可用)
- 电网相位: 单相
- 预期结果：
  - 方案A: 5kW 逆变器
  - 方案B: 8kW Hybrid（单相最大）
  - 方案C: 10kW（单相最大）

### 测试用例 4：大屋顶 + 三相
- 房屋ID: 44
- 电网相位: 三相
- 预期结果：
  - 方案A: 8kW 逆变器
  - 方案B: 10-15kW Hybrid（三相可选更大）
  - 方案C: 15-20kW（三相可选大功率）

## 澳洲DNSP规则参考

### 单相连接限制
- 大部分DNSP限制单相逆变器 ≤5kW
- 部分DNSP允许单相 ≤10kW（需申请）
- Hybrid逆变器部分DNSP允许单相8kW

### 三相连接限制
- 标准三相可安装 ≤30kW
- 更大功率需要特殊申请和审批

## 容配比规则
- **无储能系统**：≤133% (CEC规则)
- **Hybrid系统**：≤200% (允许超配，电池吸收削峰能量)
