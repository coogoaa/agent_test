### 6. 成本计算函数 ✓

```javascript
function calculateCost(pvKw, inverterKw, batteryKwh) {
    const pvCost = pvKw * 540;
    const inverterCost = inverterKw * 280;
    const batteryCost = batteryKwh * 865;
    const preTaxTotal = pvCost + inverterCost + batteryCost;
    const taxTotal = preTaxTotal * 1.1;
    return { pvCost, inverterCost, batteryCost, preTaxTotal, taxTotal };
}
```

### 7. 补贴计算函数 ✓

```javascript
function calculateSubsidy(pvKw, batteryNominalKwh, state) {
    const deemingPeriod = 2030 - 2025 + 1;  // 6年
    const zoneRating = SUBSIDY_CONFIG.zoneRating[state];
    
    // PV STC
    const pvStc = Math.floor(pvKw * zoneRating * deemingPeriod);
    
    // Battery STC (使用可用容量)
    const usableCapacity = batteryNominalKwh * 0.9;
    const batteryStc = Math.floor(Math.min(usableCapacity, 50) * 9.3);
    
    const totalStc = pvStc + batteryStc;
    const subsidyAmount = totalStc * 39;
    
    return { pvStc, batteryStc, totalStc, subsidyAmount, usableCapacity };
}
```

## 📊 完整计算示例

### 方案C (经济型) - NSW州

#### 配置
- PV: 6.6kW (15片 × 440W)
- 逆变器: 5kW Hybrid
- 电池: 6.5kWh (标称)

#### 成本计算
```
PV成本      = 6.6 × $540  = $3,564.00
逆变器成本  = 5 × $280    = $1,400.00
电池成本    = 6.5 × $865  = $5,622.50
────────────────────────────────────
税前总价    = $10,586.50
含税总价    = $10,586.50 × 1.1 = $11,645.15
```

#### 补贴计算
```
Deeming Period = 2030 - 2025 + 1 = 6年
Zone Rating (NSW) = 1.382
DoD = 0.9

PV STC:
  = FLOOR(6.6 × 1.382 × 6)
  = FLOOR(54.7)
  = 54 STC

Battery STC:
  可用容量 = 6.5 × 0.9 = 5.85kWh
  = FLOOR(5.85 × 9.3)
  = FLOOR(54.405)
  = 54 STC

总STC = 54 + 54 = 108 STC
补贴金额 = 108 × $39 = $4,212
```

#### 最终报价
```
客户实付 = $11,645 - $4,212 = $7,433
```

```javascript
// 成本参数
COST_CONFIG = {
    pvPerKw: 540,
    inverterPerKw: 280,
    batteryPerKwh: 865,
    gstRate: 0.1
}

// 电池参数
BATTERY_PARAMS = {
    dod: 0.9,
    rte: 0.95
}

// 补贴参数
SUBSIDY_CONFIG = {
    stcPrice: 39,
    installYear: 2025,
    deemingEndYear: 2030,
    batteryStcFactor: 9.3,
    batteryCapacityCap: 50,
    zoneRating: { NSW: 1.382, ... }
}
```

### 核心函数
1. `calculateCost()` - 成本计算
2. `calculateSubsidy()` - 补贴计算（使用可用容量）
3. `generateCostDerivation()` - 成本推导生成
4. `renderCostDerivationSteps()` - 成本推导渲染
5. `updateCard()` - 卡片更新（含价格）

### 事件流程
