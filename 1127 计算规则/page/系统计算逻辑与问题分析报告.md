### 2.2 坡面评分与排序

**评分算法** (南半球规则):
```javascript
function calculateSlopeScore(aspect) {
    let deviationFromNorth = Math.abs(aspect - 0);
    if (deviationFromNorth > 180) deviationFromNorth = 360 - deviationFromNorth;
    
    // 分段评分
    if (deviationFromNorth <= 45) return 90 + (45 - deviationFromNorth) / 4.5;
    if (deviationFromNorth <= 135) return 70 + (135 - deviationFromNorth) / 4.5;
    return Math.max(40, 60 - (deviationFromNorth - 135) / 2);
}
```

### 2.4 成本与补贴计算

```

含税报价 = 税前报价 × 1.1
```

#### 补贴计算公式 (TAS州, 2025年)
```
Deeming Period = 2030 - 2025 + 1 = 6年
Zone Rating (TAS) = 1.382
Battery DoD = 0.9

PV STC = FLOOR(PV容量 × 1.382 × 6)
Battery STC = FLOOR(电池容量 × 0.9 × 9.3)
总STC = PV STC + Battery STC
补贴金额 = 总STC × 39
```

## 三、问题自检与分析

### 3.1 用户反馈的问题

**问题描述**:
> 房屋ID 44，5个坡面，46片 (20.24kW)
> 界面显示的逆变器选型不对

**用户期望的推导**:
```
最终配置: 46片 × 440W = 20.24kW
方案类型: 高端型 (含储能) → 允许容配比 150%-200%
电网类型: 单相 → Hybrid逆变器限制 ≤10kW (配置: 5, 6, 8, 10)
逆变器选型: 目标容配比180% → 需要 1.0kW → 选择 5kW Hybrid
```

**实际问题**:
1. **逆变器选型逻辑错误**: "需要 1.0kW" 明显不对，应该是 `ceil(20.24 / 1.8) ≈ 12kW`
2. **容配比计算错误**: 20.24kW / 5kW = 405%，严重超标！

### 3.2 根本原因分析

#### 问题1: 逆变器选型计算错误

**错误代码位置**: `equipment-recommender.html` 第735行
```javascript
let invA_size = Math.ceil(resultA.totalKw / INVERTER_CONFIG.targetRatio);
```

**问题**: `INVERTER_CONFIG.targetRatio` 的值是 `1.8`（表示180%），但应该除以100后使用，或者直接用 `1.8` 作为目标比率。

**正确计算**:
```javascript
// targetRatio = 1.8 表示 180%
let invA_size = Math.ceil(resultA.totalKw / 1.8);  // 20.24 / 1.8 ≈ 12kW
```

**当前错误计算**:
```javascript
// 如果 targetRatio = 180 (数字180)
let invA_size = Math.ceil(20.24 / 180);  // = 1kW ❌
```

#### 问题2: 配置文件中的 targetRatio 定义不一致

**config-loader.js** 第31行:
```javascript
targetRatio: 1.8,  // 表示 1.8 倍，即 180%
```

**config-editor.html** 第217行:
```html
<input type="number" id="inv-target-ratio" class="w-full border rounded p-2" value="180">
<p class="text-xs text-gray-500 mt-1">Hybrid系统的目标容配比</p>
```

**问题**: 配置编辑器中显示的是 `180`，但实际存储的应该是 `1.8`。这导致了混淆。

### 3.3 其他潜在问题

#### 问题3: 标准电池规格未在卡片中展示

**当前**: 电池容量计算后标准化到 [5, 6.5, 9.6, 10, 13.5, 16, 20]，但卡片中没有明确显示这是标准化后的规格。

#### 问题4: 逆变器功率未在卡片中单独展示

**当前**: 卡片中显示 "5kW Hybrid"，但没有单独字段显示原始推导的逆变器功率（如 "目标4kW → 选择5kW"）。

#### 问题5: 标准电池规格开关未实现

**需求**: config-editor.html 支持标准电池规格可开启或关闭，默认关闭。

**当前状态**: 电池规格始终标准化，没有开关控制。
