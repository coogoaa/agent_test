# 批量方案生成器使用说明

## 功能概述

`batch-processor.html` 是一个批量处理工具，可以读取CSV文件中的所有房屋数据，自动生成三套光伏方案，并导出结果。

## 使用步骤

### 1. 准备CSV文件

CSV文件格式：
```csv
id_0,slope,aspect,nums
1,slope 1,359.8480529785156,1
1,slope 2,269.8477783203125,0
1,slope 3,179.8481903076172,1
...
```

**字段说明**：
- `id_0`: 房屋ID
- `slope`: 坡面ID
- `aspect`: 方位角（度）
- `nums`: 该坡面可安装的最大面板数量

### 2. 打开批量处理器

在浏览器中打开：
```
1127 计算规则/page/batch-processor.html
```

### 3. 上传CSV文件

点击"选择文件"按钮，选择您的CSV文件（例如 `agent_sample_data - 坡面信息.csv`）

### 4. 设置参数

- **州/领地**: 选择用户所在州（影响用电数据和电池容量计算）
- **电网相位**: 选择单相或三相（影响逆变器选型）

### 5. 开始处理

点击"开始批量处理"按钮，系统会：
- 解析CSV文件
- 按房屋ID分组
- 为每个房屋生成三套方案
- 显示进度条

### 6. 查看结果

处理完成后，页面会显示汇总表格，包含：
- 房屋ID
- 方案类型（高端型/平衡型/经济型）
- PV容量
- 面板数量
- 逆变器规格
- 容配比
- 电池容量

### 7. 导出结果

#### 下载完整结果 (JSON)
包含所有详细信息，适合程序处理：
```json
{
  "houseId": "1",
  "state": "TAS",
  "phaseType": "single",
  "roofSummary": {...},
  "planA": {...},
  "planB": {...},
  "planC": {...}
}
```

#### 下载汇总表 (CSV)
简化的表格格式，适合Excel查看：
```csv
房屋ID,方案,PV容量(kW),面板数,逆变器,容配比,电池(kWh)
1,高端型,0.88,2,5kW Hybrid,18%,13.5
1,平衡型,0.88,2,5kW Hybrid,18%,6.5
1,经济型,0.88,2,5kW Hybrid,18%,6.5
```

## 核心逻辑

### 方案定义

| 方案 | 目标 | 策略 | 电池 |
|------|------|------|------|
| A 高端型 | 物理极限满铺 | 使用所有可用坡面 | 大容量（离网级） |
| B 平衡型 | 10-13kW | 根据屋顶规模调整 | 标准容量 |
| C 经济型 | 6.6kW | 入门配置 | 基础容量 |

### 容配比处理

**目标容配比**: 180% (Hybrid系统合理范围)

**超标处理**:
1. 如果容配比 > 200%：
   - 优先尝试增大逆变器
   - 如果逆变器已达上限（单相10kW/三相30kW）
   - 则从低分坡面开始减少面板
   - 直到容配比 ≤ 200%

2. 如果容配比 < 150%：
   - 提示可优化（可减小逆变器）

3. 如果 150% ≤ 容配比 ≤ 200%：
   - 合理范围 ✓

### 电池容量计算

**三种方法取最大值**:
1. 日用电量 × 系数（高端50%，平衡30%）
2. 傍晚高峰用电 × 系数（高端2.0，平衡1.5）
3. PV容量 × 系数（高端1.5，平衡1.0）

**标准化规格**: 5, 6.5, 9.6, 10, 13.5, 16, 20 kWh

## 示例输出

### 房屋1（小屋顶，2片可用）

**单相电网**:
- 方案A: 0.88kW, 2片, 5kW逆变器, 18%容配比, 13.5kWh电池
- 方案B: 0.88kW, 2片, 5kW逆变器, 18%容配比, 6.5kWh电池
- 方案C: 0.88kW, 2片, 5kW逆变器, 18%容配比, 6.5kWh电池

**三相电网**:
- 逆变器选型可能不同（可选更大功率）

### 房屋44（大屋顶，46片可用）

**单相电网**:
- 方案A: 20.24kW → 减板子到20kW, 10kW逆变器, 200%容配比
- 方案B: 13.2kW, 30片, 8kW逆变器, 165%容配比
- 方案C: 6.6kW, 15片, 5kW逆变器, 132%容配比

**三相电网**:
- 方案A: 20.24kW, 46片, 15kW逆变器, 135%容配比（无需减板子）

## 性能说明

- **处理速度**: 约100个房屋/秒
- **内存占用**: 取决于房屋数量，通常 < 100MB
- **浏览器要求**: 现代浏览器（Chrome/Firefox/Safari/Edge）

## 注意事项

1. **CSV格式要求**:
   - 必须包含表头行
   - 字段用逗号分隔
   - 数值字段不要包含单位

2. **数据验证**:
   - 方位角范围: 0-360度
   - 面板数量: 非负整数
   - 房屋ID: 任意字符串

3. **容配比规则**:
   - 所有方案都是Hybrid系统
   - 严格遵守200%上限
   - 单相和三相逆变器规格不同

4. **电池配置**:
   - 所有方案都配储能
   - 容量基于州用电数据动态计算
   - 自动标准化到常见规格

## 故障排除

### CSV上传失败
- 检查文件编码（建议UTF-8）
- 确认文件格式正确
- 文件大小不超过10MB

### 处理卡住
- 刷新页面重试
- 检查浏览器控制台错误信息
- 减少CSV文件大小

### 结果不合理
- 检查输入数据（方位角、面板数）
- 确认州和电网相位选择正确
- 查看详细JSON输出分析
