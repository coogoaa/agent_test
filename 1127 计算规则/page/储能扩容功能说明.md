# 储能扩容功能实现说明

## 功能概述

本次更新实现了储能扩容计算模式，适用于已有光伏系统的用户希望增加储能容量或扩展光伏装机的场景。

## 主要变更

### 1. 页面重命名
- **单个分析** → **新建系统** (`equipment-recommender.html`)
- 所有页面导航链接已同步更新

### 2. 新增配置参数

在 `config-loader.js` 和 `config-editor.html` 中新增：

```javascript
expansion: {
    roofCapacityFactor: 0.7,  // 屋顶容量系数（默认0.7）
    replaceInverter: true      // 是否更换逆变器（默认true）
}
```

**配置说明：**
- **屋顶容量系数**：考虑到已有组件占用，可用屋顶空间 = GIS分析潜力 × 容量系数
- **更换逆变器**：储能扩容时是否默认更换为新的混合逆变器

### 3. 新建储能扩容页面

创建 `storage-expansion.html`，功能特点：

#### 计算逻辑
- 复用新建系统的完整推导逻辑
- 在物理限制分析阶段应用屋顶容量系数
- 每个坡面的可用容量 = 原始容量 × 屋顶容量系数（向下取整）

#### 示例计算
```
假设：GIS分析显示屋顶最大可装30片组件 (13.2kW)
屋顶容量系数 = 0.7

扩容可用 = 30 × 0.7 = 21片 (9.24kW)
系统将基于9.24kW进行三套方案推导
```

#### UI特性
- 顶部显示储能扩容模式说明卡片
- 动态显示当前配置的容量系数和逆变器更换策略
- 推导步骤中明确标注"储能扩容模式"
- 完整的推导日志和成本补贴计算

### 4. 批量处理支持

在 `batch-processor.html` 中新增：

#### 模式选择器
```html
<select id="calcMode">
    <option value="new">新建系统</option>
    <option value="expansion">储能扩容</option>
</select>
```

#### 动态提示
- **新建系统**：使用全部屋顶容量
- **储能扩容**：使用70%屋顶容量（可在配置中修改）

#### 批量计算
- `generateProposals` 函数新增 `calcMode` 参数
- 储能扩容模式下自动应用屋顶容量系数
- 结果中包含完整的逆变器元数据和成本补贴信息

### 5. 导航更新

所有页面的导航栏已更新，包含：
- 📊 新建系统
- 🔋 储能扩容
- 📦 批量处理
- ⚙️ 配置编辑

## 使用指南

### 单个房屋储能扩容分析

1. 访问 `storage-expansion.html`
2. 选择房屋ID、州和电网相位
3. 系统自动应用配置的屋顶容量系数（默认0.7）
4. 查看三套差异化扩容方案及详细推导

### 批量储能扩容处理

1. 访问 `batch-processor.html`
2. 上传CSV文件（格式：id_0, slope, aspect, nums）
3. 选择**计算模式**为"储能扩容"
4. 设置州和电网相位
5. 点击"开始批量处理"
6. 下载JSON或CSV格式的结果

### 配置修改

1. 访问 `config-editor.html`
2. 切换到"储能扩容"标签页
3. 修改：
   - 屋顶容量系数（0-1之间，默认0.7）
   - 是否更换逆变器（默认勾选）
4. 保存配置

## 技术实现细节

### 核心逻辑修改

在 `generateProposalsWithDerivation` 函数中：

```javascript
// 储能扩容模式：应用屋顶容量系数
const roofCapacityFactor = CONFIG.expansion?.roofCapacityFactor || 0.7;
const expansionMaxPanels = Math.floor(totalMaxPanels * roofCapacityFactor);

// 应用容量系数到每个坡面
roofPlanes.forEach(p => {
    p.max = Math.floor(p.max * roofCapacityFactor);
});
```

### 批量处理集成

```javascript
function generateProposals(houseId, roofData, state, phaseType, calcMode = 'new') {
    // 储能扩容模式：应用屋顶容量系数
    if (calcMode === 'expansion') {
        const roofCapacityFactor = CONFIG.expansion?.roofCapacityFactor || 0.7;
        roofPlanes.forEach(p => {
            p.max = Math.floor(p.max * roofCapacityFactor);
        });
    }
    // ... 其余逻辑保持不变
}
```
