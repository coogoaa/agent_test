## 快速开始

### 1. 单个房屋分析

**打开**: `equipment-recommender.html`

**步骤**:
1. 选择房屋ID（预设样本）
2. 选择州/领地
3. 选择电网相位（单相/三相）
4. 查看三套方案和详细推导过程

**输出**:
- 方案A（高端型）：满铺屋顶
- 方案B（平衡型）：10-13kW
- 方案C（经济型）：6.6kW入门

### 2. 批量处理

**打开**: `batch-processor.html`

**步骤**:
1. 上传CSV文件（格式: id_0, slope, aspect, nums）
2. 选择州/领地和电网相位
3. 点击"开始批量处理"
4. 下载结果（JSON或CSV）

**适用场景**:
- 处理大量房屋数据
- 生成批量报告
- 数据分析和统计

### 3. 配置编辑

**打开**: `config-editor.html`

**功能**:
- **PV组件参数**: 修改面板功率、尺寸、效率
- **电池计算系数**: 调整三套方案的电池系数
- **逆变器规格**: 自定义可用逆变器规格
- **州用电数据**: 修改各州年度用电量
- **自定义房屋**: 输入自己的屋顶数据

**使用场景**:
- 测试不同参数组合
- 适配新的PV组件型号
- 添加自定义房屋样本

## 自定义房屋数据

### 方法1: 通过配置编辑器

1. 打开 `config-editor.html`
2. 切换到"自定义房屋"标签
3. 输入房屋ID
4. 输入坡面数据（每行一个坡面）:
   ```
   359.8, 30
   269.8, 0
   179.8, 16
   89.8, 0
   ```
5. 点击"测试计算"查看结果
6. 点击"添加到系统"保存

### 方法2: 直接修改数据文件

编辑 `solar-designer-data.js`:

```javascript
const HOUSE_DATA = {
    "custom_1": [
        { id: "slope 1", aspect: 359.8, max: 30 },
        { id: "slope 2", aspect: 269.8, max: 0 },
        { id: "slope 3", aspect: 179.8, max: 16 },
        { id: "slope 4", aspect: 89.8, max: 0 }
    ]
};
```

### 坡面数据格式

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| id | string | 坡面ID | "slope 1" |
| aspect | number | 方位角（0-360度） | 359.8 |
| max | number | 最大可安装面板数 | 30 |

**方位角参考**:
- 0° = 正北（最佳）
- 90° = 正东
- 180° = 正南（最差）
- 270° = 正西

## 常见问题

### Q1: 为什么房屋35显示0kW？

**A**: 房屋35的所有坡面 `max=0`，没有可用空间。系统会返回N/A。

**解决**: 检查CSV数据，确保至少有一个坡面 `max > 0`。

### Q2: 为什么方案A需要减板子？

**A**: 单相电网逆变器最大10kW，容配比不能超过200%，所以最多20kW PV。如果满铺超过20kW，需要减板子。

**解决**: 
- 切换到三相电网（可选更大逆变器）
- 或接受减板子的结果

### Q3: 电池容量为什么显示29.7而不是30？

**A**: 浮点数精度问题。

**解决**: 已修复，现在会显示为 `30.0 kWh`。

### Q4: 如何修改PV组件型号？

**A**: 
1. 打开 `config-editor.html`
2. 修改PV组件参数
3. 导出配置文件
4. 在主页面导入配置

### Q5: 批量处理CSV格式要求？

**A**: 
```csv
id_0,slope,aspect,nums
1,slope 1,359.8,30
1,slope 2,269.8,0
```

- 必须包含表头
- 字段用逗号分隔
- 同一房屋ID的多个坡面分多行

## 最佳实践

### 1. 参数调优流程

1. 使用默认参数测试几个样本
2. 分析结果是否合理
3. 在配置编辑器中调整参数
4. 重新测试
5. 导出最优配置

### 2. 批量处理流程

1. 准备标准格式CSV
2. 先用小样本测试（10个房屋）
3. 检查结果准确性
4. 再处理完整数据集
5. 导出结果并分析

### 3. 自定义房屋流程

1. 在配置编辑器中输入数据
2. 点击"测试计算"验证
3. 确认无误后添加到系统
4. 在主页面选择自定义房屋
5. 查看详细推导过程
