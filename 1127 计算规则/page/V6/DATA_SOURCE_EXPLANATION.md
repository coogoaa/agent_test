# V6 各州数据来源说明

## 数据来源总览

V6 版本使用的所有数据都是**预设的兜底数据**，不依赖真实房屋数据。

---

## 1. 发电量数据

### 📊 各州年发电系数（kWh/kW/年）

**数据来源**：`config.pv.annualYieldByState`

| 州 | 年发电系数 | 说明 |
|----|-----------|------|
| TAS | 1,278 | 塔斯马尼亚 |
| VIC | 1,314 | 维多利亚 |
| NSW | 1,460 | 新南威尔士 |
| SA | 1,533 | 南澳大利亚 |
| QLD | 1,533 | 昆士兰 |
| ACT | 1,570 | 首都领地 |
| NT | 1,606 | 北领地 |
| WA | 1,606 | 西澳大利亚 |

**计算方法**：

```javascript
// 1. 计算年发电量
年发电量 = PV_kW × annualYieldByState[state]

// 例如：NSW 州，6.6kW 系统
年发电量 = 6.6 × 1460 = 9,636 kWh

// 2. 计算全年日均发电
日均发电 = 年发电量 / 365

// 例如：
日均发电 = 9,636 / 365 = 26.40 kWh
```

### ⏰ 小时发电占比

**数据来源**：`PV_HOURLY_SHARE`（全澳统一）

```javascript
const PV_HOURLY_SHARE = [
  0, 0, 0, 0, 0, 0,  // 0-5点：无发电
  0.02, 0.04, 0.07, 0.10, 0.13, 0.14,  // 6-11点：上升
  0.14, 0.13, 0.10, 0.07, 0.04, 0.02,  // 12-17点：下降
  0, 0, 0, 0, 0, 0   // 18-23点：无发电
];
```

**特点**：
- 24小时加总为 100%
- 对称分布，中午12-13点最高（14%）
- 所有州使用相同的小时分布

**计算方法**：

```javascript
// 逐小时发电
PV_hour[h] = 日均发电 × PV_HOURLY_SHARE[h]

// 例如：NSW 州，6.6kW 系统，12点
PV_hour[12] = 26.40 × 0.14 = 3.70 kWh
```

## 2. 用电量数据

### 📊 各州全年用电量（kWh/年）

**数据来源**：`config.consumption`

| 州 | 年用电量 | 说明 |
|----|---------|------|
| TAS | 10,148 | 塔斯马尼亚（最高） |
| NT | 10,008 | 北领地 |
| ACT | 8,632 | 首都领地 |
| NSW | 7,778 | 新南威尔士 |
| WA | 7,634 | 西澳大利亚 |
| SA | 7,129 | 南澳大利亚 |
| QLD | 7,270 | 昆士兰 |
| VIC | 6,778 | 维多利亚（最低） |

**计算方法**：

```javascript
// 1. 计算全年日均用电
日均用电 = consumption[state] / 365

// 例如：NSW 州
日均用电 = 7,778 / 365 = 21.31 kWh
```

### ⏰ 各州各时段用电比例

**数据来源**：`HOURLY_PROFILE_PCT`（各州不同）

**NSW 州示例**（百分比形式）：

```javascript
const HOURLY_PROFILE_PCT = {
  NSW: [
    4.427, 3.912, 3.176, 2.706, 2.583, 2.805,  // 0-5点
    3.427, 3.939, 4.089, 4.050, 3.986, 3.936,  // 6-11点
    3.948, 3.908, 3.920, 4.105, 4.569, 5.328,  // 12-17点
    5.846, 5.634, 5.329, 4.947, 4.804, 4.630   // 18-23点
  ]
};
```

**特点**：
- 24小时加总为 100%
- 晚高峰（17-20点）用电比例最高
- 各州有不同的用电模式

**计算方法**：

```javascript
// 1. 转换为小数
hourlyProfile = HOURLY_PROFILE_PCT[state].map(pct => pct / 100)

// 2. 逐小时用电
Load_hour[h] = 日均用电 × hourlyProfile[h]

// 例如：NSW 州，18点（晚高峰）
Load_hour[18] = 21.31 × 0.05846 = 1.25 kWh
```

## 3. 关键时段需求计算

### 晚高峰需求（17:00-21:00）

```javascript
const eveningHours = [17, 18, 19, 20];
const eveningKwh = eveningHours.reduce((sum, h) => 
  sum + Load_hour[h], 0
);

// NSW 州示例
// 17点: 21.31 × 0.05328 = 1.14 kWh
// 18点: 21.31 × 0.05846 = 1.25 kWh
// 19点: 21.31 × 0.05634 = 1.20 kWh
// 20点: 21.31 × 0.05329 = 1.14 kWh
// 合计: 4.72 kWh
```

const nightHours = [17, 18, 19, 20, 21, 22, 23, 0, 1, 2, 3, 4, 5, 6];
const nightKwh = nightHours.reduce((sum, h) => 
  sum + Load_hour[h], 0

// NSW 州示例：12.69 kWh

## 4. 光伏剩余计算

### V6 简化方法：全年日均

```javascript
// 逐小时计算剩余
const surplusKwh = pvHour.reduce((sum, pv, h) => 
  sum + Math.max(0, pv - Load_hour[h]), 0
);
```

**示例**（NSW 州，6.6kW 系统）：

| 时段 | PV发电 | 用电 | 剩余 |
|------|--------|------|------|
| 8点 | 1.85 kWh | 0.87 kWh | 0.98 kWh |
| 9点 | 2.64 kWh | 0.86 kWh | 1.78 kWh |
| 10点 | 3.43 kWh | 0.85 kWh | 2.58 kWh |
| ... | ... | ... | ... |
| **全天合计** | 26.40 kWh | 21.31 kWh | **16.72 kWh** |

## 5. 数据特点总结

### ✅ 优点

1. **简单可靠**：不依赖外部数据源
2. **全国覆盖**：支持所有澳洲州和领地
3. **即时可用**：无需等待数据采集
4. **一致性好**：计算结果可重现

### ⚠️ 局限性

1. **通用性**：使用平均值，不反映个体差异
2. **季节性**：V6 使用全年平均，不考虑季节波动
3. **真实性**：兜底数据可能与实际情况有偏差

## 6. 未来改进方向

### 接入真实数据

当获得真实房屋数据时，可以替换：

```javascript
// 替换发电数据
PV_hour[h] = 用户真实的全年日均逐小时发电

// 替换用电数据
Load_hour[h] = 用户真实的全年日均逐小时用电
```

**优势**：
- 更准确的光伏剩余计算
- 更个性化的电池容量推荐
- 更精确的财务分析

**保持不变**：
- 计算公式和逻辑
- A/B/C 方案定义
- 参数配置（aSurplus, bSurplus）

## 总结

**是的，V6 完全使用预设的兜底数据进行计算**：

1. **发电量**：基于各州年发电系数 + 统一的小时发电占比
2. **用电量**：基于各州年用电量 + 各州的小时用电比例
3. **计算方法**：全年日均，不依赖特定月份
4. **数据类型**：所有数据都是预设的统计平均值

这种设计使得 V6 可以在没有真实数据的情况下快速运行，同时为未来接入真实数据预留了接口。
