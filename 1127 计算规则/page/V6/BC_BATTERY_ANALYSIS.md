# B 和 C 方案电池容量对比分析报告

## 统计结果总览

基于 9,277 组对比数据（包含 new 和 expansion 两种模式）：

| 项目 | 数量 | 占比 |
|------|------|------|
| **B = C（电池相同）** | 2,855 | 30.8% |
| **B > C（电池不同）** | 6,422 | 69.2% |
| **总计** | 9,277 | 100% |

## B=C 时的 PV 容量分布

当 B 和 C 方案电池容量相同时，对应的 PV 容量分布：

| PV 容量 | 次数 | 占比 |
|---------|------|------|
| 0.4 kW | 164 | 5.7% |
| 0.9 kW | 300 | 10.5% |
| 1.3 kW | 152 | 5.3% |

| 2.2 kW | 196 | 6.9% |

**观察**：B=C 主要发生在小屋顶（≤4.4kW），这些屋顶的光伏剩余较少。

## 电池容量计算详解

### 1. battery_calculated_nominal_kwh（计算值）

这是根据公式直接计算出的**理论电池容量**，未经标准化。

#### 计算步骤

**步骤 1：确定所需能量 E_req**

```
A 方案: E_req = max(整夜需求, 0.8 × 光伏剩余)
B 方案: E_req = max(晚高峰需求, 0.55 × 光伏剩余)
C 方案: E_req = 晚高峰需求
```

其中：
- 整夜需求：17:00-07:00（14小时）= 12.69 kWh（NSW州）
- 晚高峰需求：17:00-21:00（4小时）= 4.72 kWh（NSW州）
- 光伏剩余：全年日均光伏剩余能量

**步骤 2：除以效率得到电池容量**

```
Battery_calc = E_req / 效率
效率 = RTE × DOD = 0.95 × 0.9 = 0.855
```

其中：
- RTE（Round Trip Efficiency）：往返效率 = 0.95
- DOD（Depth of Discharge）：放电深度 = 0.9

**步骤 3：限制在范围内**

```
Battery_calc = max(5, min(50, Battery_calc))
```

- 最小值：5 kWh
- 最大值：50 kWh（补贴上限）

---

### 2. battery_nominal_kwh（标准化值）

这是将计算值**标准化到市场可用的电池规格**。

#### 标准电池规格

```
[5, 6.5, 9.6, 10, 13.5, 16, 20, 25, 30, 40, 50] kWh
```

#### 标准化规则

选择 **≥ 计算值的最小标准规格**

**示例**：
- 计算值 5.52 kWh → 标准化为 **6.5 kWh**
- 计算值 14.84 kWh → 标准化为 **16 kWh**
- 计算值 20.39 kWh → 标准化为 **25 kWh**
- 计算值 51.12 kWh → 标准化为 **50 kWh**（上限）

## 完整计算示例

### 案例 1：小屋顶（PV 3.96kW）

**输入参数**：
- PV 容量：3.96 kW
- 光伏剩余：7.13 kWh
- 晚高峰需求：4.72 kWh
- 整夜需求：12.69 kWh

**C 方案计算**：
```
E_req = 晚高峰 = 4.72 kWh
Battery_calc = 4.72 / 0.855 = 5.52 kWh
Battery_nominal = 6.5 kWh（标准化）
```

**B 方案计算**：
```
0.55×剩余 = 0.55 × 7.13 = 3.92 kWh
E_req = max(4.72, 3.92) = 4.72 kWh（取晚高峰）
Battery_calc = 4.72 / 0.855 = 5.52 kWh
Battery_nominal = 6.5 kWh（标准化）
```

**结果**：B = C = 6.5 kWh ✓

**原因**：光伏剩余较少，0.55×剩余 < 晚高峰，B 方案退化为 C 方案

---

### 案例 2：中等屋顶（PV 6.6kW）

**输入参数**：
- PV 容量：6.6 kW
- 光伏剩余：16.72 kWh
- 晚高峰需求：4.72 kWh
- 整夜需求：12.69 kWh

**C 方案计算**：
```
E_req = 晚高峰 = 4.72 kWh
Battery_calc = 4.72 / 0.855 = 5.52 kWh
Battery_nominal = 6.5 kWh（标准化）
```

**B 方案计算**：
```
0.55×剩余 = 0.55 × 16.72 = 9.20 kWh
E_req = max(4.72, 9.20) = 9.20 kWh（取光伏剩余）
Battery_calc = 9.20 / 0.855 = 10.76 kWh
Battery_nominal = 13.5 kWh（标准化）
```

**A 方案计算**：
```
0.8×剩余 = 0.8 × 16.72 = 13.38 kWh
E_req = max(12.69, 13.38) = 13.38 kWh（取光伏剩余）
Battery_calc = 13.38 / 0.855 = 15.65 kWh
Battery_nominal = 16 kWh（标准化）
```

**结果**：A = 16 kWh, B = 13.5 kWh, C = 6.5 kWh

**原因**：光伏剩余充足，B 方案由光伏剩余驱动，与 C 方案拉开差距

## B=C 的条件分析

### 临界条件

B 和 C 方案电池相同的条件：

```
当 0.55 × 光伏剩余 ≤ 晚高峰需求 时
B 方案取 max(晚高峰, 0.55×剩余) = 晚高峰
与 C 方案相同
```

### 临界点计算

对于 NSW 州（晚高峰 4.72 kWh）：

```
临界点：光伏剩余 ≤ 晚高峰 / 0.55
       = 4.72 / 0.55
       = 8.58 kWh
```

### 分类规则

| 光伏剩余 | B vs C | 原因 |
|---------|--------|------|
| < 8.58 kWh | B = C | 0.55×剩余 ≤ 晚高峰，B 退化为 C |
| ≥ 8.58 kWh | B > C | 0.55×剩余 > 晚高峰，B 由剩余驱动 |

### 验证数据

临界点附近的实际数据（光伏剩余 8.68 kWh）：

```
光伏剩余 8.68 kWh: B=6.5 kWh, C=6.5 kWh [B=C]
```

**分析**：
- 0.55 × 8.68 = 4.77 kWh
- 晚高峰 = 4.72 kWh
- 4.77 > 4.72，理论上应该 B > C
- 但标准化后都是 6.5 kWh，所以 B = C

这说明**标准化过程**也会影响最终结果。

## PV 容量与光伏剩余的关系

### 估算公式

```
光伏剩余 ≈ PV_kW × 年发电系数 / 365 - 日均用电
         ≈ PV_kW × 1460 / 365 - 21.31
         ≈ PV_kW × 4.0 - 21.31
```

### B=C 的 PV 容量范围

根据临界点 8.58 kWh：

```
8.58 ≈ PV_kW × 4.0 - 21.31
PV_kW ≈ (8.58 + 21.31) / 4.0
      ≈ 7.47 kW
```

但实际数据显示 B=C 主要在 ≤4.4kW，这是因为：
1. 小屋顶光伏剩余更少
2. 标准化过程的影响
3. 逐小时计算的精确性

## 关键洞察

### 1. 小屋顶特征（≤4.4kW）

- **光伏剩余少**：< 8.58 kWh
- **B=C 概率高**：30.8%
- **电池容量**：通常 5-6.5 kWh
- **驱动因素**：晚高峰需求

### 2. 中等屋顶特征（4.4-10kW）

- **光伏剩余增加**：8-30 kWh
- **B>C**：B 方案开始由光伏剩余驱动
- **电池容量**：B 为 9.6-20 kWh，C 仍为 6.5 kWh
- **差距拉大**：B 和 C 的差距明显

### 3. 大屋顶特征（>10kW）

- **光伏剩余充足**：> 30 kWh
- **B>>C**：B 方案电池容量远大于 C
- **电池容量**：B 为 25-50 kWh，C 仍为 6.5 kWh
- **A 接近上限**：A 方案接近或达到 50kWh

---

## 总结

### battery_calculated_nominal_kwh（计算值）

- **定义**：根据公式计算的理论电池容量
- **公式**：E_req / 0.855
- **范围**：5-50 kWh
- **用途**：展示精确的计算结果

### battery_nominal_kwh（标准化值）

- **定义**：标准化到市场可用规格的电池容量
- **规格**：[5, 6.5, 9.6, 10, 13.5, 16, 20, 25, 30, 40, 50] kWh
- **规则**：向上取整到最近的标准规格
- **用途**：实际推荐给用户的电池容量

### B=C 的条件

- **临界点**：光伏剩余 ≤ 8.58 kWh（NSW州）
- **发生率**：30.8%
- **主要发生在**：小屋顶（≤4.4kW）
- **原因**：光伏剩余不足，B 方案退化为 C 方案
