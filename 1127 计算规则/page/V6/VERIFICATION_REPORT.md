## 计算逻辑验证

### 全年日均计算验证

**NSW州参数**：
- 年用电量：7,778 kWh
- 日均用电：7,778 ÷ 365 = 21.31 kWh ✓
- 年发电系数：1,460 kWh/kW/年

**示例验证（7.92kW系统）**：
```
年发电量 = 7.92 × 1,460 = 11,563.2 kWh
日均发电 = 11,563.2 ÷ 365 = 31.68 kWh ✓
```

### 时段需求计算验证

**晚高峰（17:00-21:00）**：
- 时段比例：4.72% × 4小时
- 需求：21.31 × 比例 = 4.72 kWh ✓

**整夜（17:00-07:00）**：
- 14小时累计比例
- 需求：12.69 kWh ✓

### 光伏剩余计算验证

**逐小时计算**：
```
for h in 0..23:
  surplus += max(0, PV_hour[h] - Load_hour[h])
```

**示例（7.92kW系统）**：
- 日均发电：31.68 kWh
- 日均用电：21.31 kWh
- 光伏剩余：21.79 kWh ✓
- 验证：剩余 < 发电量 < 发电量 + 用电量 ✓

### 电池容量计算验证

**A方案公式**：
```
E_req = max(整夜需求, 0.8 × 光伏剩余)
Battery = min(E_req / 0.855, 50kWh)
```

**各规模验证**：
