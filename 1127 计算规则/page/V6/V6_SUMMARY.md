## 核心简化

**V6 相对于 V4 的主要简化**：光伏剩余使用**全年日均**来估算，不再查找对应的 6 月数据。

### 计算公式变化

**V4 方式**：
```
年发电量 = PV_kW × 年发电系数
6月发电量 = 年发电量 × 6月占比（6%）
6月日均发电 = 6月发电量 / 30天
光伏剩余 = 基于6月日均的逐小时计算
```

**V6 方式**：
```
年发电量 = PV_kW × 年发电系数
全年日均发电 = 年发电量 / 365天
光伏剩余 = 基于全年日均的逐小时计算
```

### 参数简化

**移除的参数**：
- `PV_MONTHLY_SHARE`（月度发电占比）
- `LOAD_MONTHLY_SHARE`（月度用电占比）
- 6 月特定计算逻辑

**保留的参数**：
- 各州年发电系数
- 各州年用电量
- 各州各时段用电比例
- 小时发电占比
- 电池系数（aSurplus: 0.8, bSurplus: 0.55）

### 关键指标验证

**日均用电量**（NSW州）：21.31 kWh
- 来源：7778 kWh/年 ÷ 365 天 = 21.31 kWh/天

**晚高峰需求**：4.72 kWh
- 时间：17:00-21:00（4小时）
- 计算：21.31 × (4.72% × 4) ≈ 4.72 kWh

**整夜需求**：12.69 kWh
- 时间：17:00-07:00（14小时）
- 计算：基于各时段用电比例累加

**光伏剩余计算**：
- 逐小时计算：max(0, PV_hour - Load_hour)
- 累加全天 24 小时

## 电池容量推算验证

### A 方案（高端型）

公式：`Battery = min(max(整夜需求, 0.8×光伏剩余) / 效率, 50kWh)`

**案例验证**：
- 小屋顶（光伏剩余 < 15.86kWh）：由整夜需求决定 → 16kWh
- 中屋顶（光伏剩余 15-40kWh）：由光伏剩余决定 → 16-40kWh
- 大屋顶（光伏剩余 > 53kWh）：达到上限 → 50kWh

### B 方案（平衡型）

公式：`Battery = min(max(晚高峰需求, 0.55×光伏剩余) / 效率, 50kWh)`

**特点**：
- 系数更小（0.55 vs 0.8）
- 最低保障晚高峰需求（4.72kWh）
- 适合移峰套利场景

### C 方案（经济型）

公式：`Battery = min(晚高峰需求 / 效率, 50kWh)`

**特点**：
- 固定基于晚高峰需求
- 所有案例都是 5-6.5kWh（标准化后）
- 最经济的配置
