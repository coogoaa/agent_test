## 修复的问题

### 1. ❌ 成本显示 $NaN 问题

**问题描述**：
页面显示价格时出现 `$NaN`，无法正常显示成本信息。

**根本原因**：
方案 A 线性定价的 `calculateCostByScheme` 函数返回对象缺少 `exGstExStc` 和 `incGstIncStc` 字段，导致页面访问这些字段时返回 `undefined`。

**修复方案**：
在 `@/Users/paulgao/Documents/augment-projects/Sales_Agent_测试/1127 计算规则/page/V6/page/config-loader.js` 中修改方案 A 的返回值：

```javascript
// 修复前
return {
    pvCost,
    inverterCost,
    batteryCost,
    systemCost,
    preTaxTotal,
    taxTotal,
    scheme: schemeType
};

// 修复后
const subsidy = calculateSubsidy(config, pvKw, batteryKwh, state);
const exGstExStc = preTaxTotal;
const incGstIncStc = (preTaxTotal - subsidy.subsidyAmount) * (1 + gstRate);

return {
    pvCost,
    inverterCost,
    batteryCost,
    systemCost,
    preTaxTotal,
    taxTotal,
    exGstExStc,        // ✅ 新增
    incGstIncStc,      // ✅ 新增
    scheme: schemeType
};
```

**同时修复**：
所有调用 `calculateCostByScheme` 的地方都添加了 `state` 参数：
- `equipment-recommender-logic.js`
- `storage-expansion-logic.js`
- `batch-processor.html`

### 2. ❌ 默认房屋未设置为 27

**问题描述**：
页面加载时默认选择第一个房屋（房屋 1），而非用户要求的房屋 27。

**修复方案**：
在初始化函数中添加默认选择逻辑：

```javascript
// equipment-recommender-logic.js 和 storage-expansion-logic.js
const houseIds = Object.keys(AppData.houses).sort((a, b) => parseInt(a) - parseInt(b));
houseIds.forEach(id => {
    const opt = document.createElement('option');
    opt.value = id;
    opt.textContent = `房屋 ${id} (${AppData.houses[id].length} 个坡面)`;
    // ✅ 默认选择房屋 27
    if (id === '27') {
        opt.selected = true;
    }
    selector.appendChild(opt);
});
```

**额外改进**：
房屋列表现在按数字顺序排序（1, 3, 4, 5, 27, 44），而非字符串顺序。

## 技术细节

### 方案 A 成本计算公式
```javascript
不含税不含补贴 = PV容量 × pvPerKw + 逆变器容量 × inverterPerKw + 电池容量 × batteryPerKwh
含税含补贴 = (不含税不含补贴 - 补贴金额) × (1 + GST税率)
```

### 默认参数（方案 A）
```javascript
pvPerKw: 1000       // $/kW
inverterPerKw: 500  // $/kW
batteryPerKwh: 800  // $/kWh
gstRate: 0.1        // 10%
```
