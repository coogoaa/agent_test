3.1.1.6 逆变器选型与容配比校验
- 背景与策略假设：
  - 新建系统的方案都带电池，电池都配混合逆变器（Hybrid inverter），储能电池可以直接从 PV 面板进行充电。
  - 需要满足澳洲对容配比的限制要求，配备了储能电池的 PV 系统的容配比可以达到 150% - 200%，但是不能超过 200% 
  - 默认分析的屋顶都是单相电。

- 计算流程
1. 初选：
- 方案目标逆变器功率 = PV 总容量 / 目标容配比
- 目标容配比默认参数为 1.8
2. 匹配：
在相位允许的规格库，寻找>=目标功率的最小规格
3. 校验与调整：
计算 实际容配比 = PV总功率 / 选定逆变器功率

Case 1 (合规): 容配比 ≤ 200%。 -> 通过。

Case 2 (过高 > 200%):
- 优先尝试增大逆变器规格。
- 若已达相位允许的最大规格 (单相不超过 10kW)，则触发削减面板逻辑。
- 削减逻辑：计算允许的最大 PV 功率 (逆变器功率 * 2.0)，从最低分坡面开始减少面板，直到满足要求。

确保在太阳下山后，用白天储存的电力支撑晚间用电高峰

→ 确保储能系统能够有效吸收光伏系统的发电量

最终的电池推荐容量（标称容量）= max (日用电维度，傍晚峰值维度，光伏容量维度）
