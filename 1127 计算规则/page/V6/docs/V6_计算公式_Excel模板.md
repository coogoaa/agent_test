| 列 | 名称 | 公式 |

## 完整公式汇总

### 1. 日均能量计算
```
日均用电量 = 年用电量 / 365
日均发电量 = PV容量 × 年发电系数 / 365
```

### 2. 逐小时计算
```
逐小时用电 = 日均用电量 × 该小时用电比例
逐小时发电 = 日均发电量 × 该小时发电比例
光伏剩余 = MAX(0, 逐小时发电 - 逐小时用电)
```

### 3. 能量汇总
```
晚高峰用电 = Σ(17:00-20:00 用电)
整夜用电 = Σ(17:00-23:00 用电) + Σ(00:00-06:00 用电)
光伏剩余总量 = Σ(0:00-23:00 光伏剩余)
```

### 4. 电池容量计算
```
方案A目标能量 = MAX(整夜用电, 0.7 × 光伏剩余)
方案B目标能量 = MAX(晚高峰用电, 0.55 × 光伏剩余)
方案C目标能量 = 晚高峰用电

电池容量 = 目标能量 / (DOD × RTE)
标准化容量 = CEILING(电池容量, 标准规格)
```

### 5. 成本计算
```
PV成本 = PV容量 × PV单价
逆变器成本 = 逆变器容量 × 逆变器单价
电池成本 = 电池容量 × 电池单价
不含税不含补贴 = PV成本 + 逆变器成本 + 电池成本

STC数量 = PV容量 × 区域系数 × Deeming年数
补贴金额 = STC数量 × STC单价

含税含补贴 = (不含税不含补贴 - 补贴金额) × (1 + GST税率)
```

## 示例计算 (TAS, 13.2kW PV)

### 输入
- PV容量: 13.2 kW
- 逆变器: 10 kW
- 州: TAS

### 中间计算
- 日均用电: 10148 / 365 = 27.80 kWh
- 日均发电: 13.2 × 1277 / 365 = 46.19 kWh
- 晚高峰用电: ~6.4 kWh
- 整夜用电: ~11.2 kWh
- 光伏剩余: ~22.5 kWh

### 电池容量
- 方案A: max(11.2, 0.7×22.5) = max(11.2, 15.75) = 15.75 / 0.855 = 18.4 → **20 kWh**
- 方案B: max(6.4, 0.55×22.5) = max(6.4, 12.38) = 12.38 / 0.855 = 14.5 → **16 kWh**
- 方案C: 6.4 / 0.855 = 7.5 → **9.6 kWh**

### 成本 (方案A线性定价)
- 方案B 不含税不含补贴: 13.2×540 + 10×280 + 16×865 = $24,768
- 补贴: 13.2 × 1.382 × 5 × 39 = $3,560
- 含税含补贴: (24768 - 3560) × 1.1 = $23,329
