# V6 版本完整计算逻辑文档

## 1. 版本说明

### 1.1 版本定位

**V6 是基于 V4 的简化版本**，核心简化：
- **光伏剩余使用全年日均估算**，不再使用 6 月数据
- 减少月度分布参数依赖
- 计算逻辑更简洁、更易维护

### 1.2 与 V4 的主要差异

| 项目 | V4 | V6 |
|------|----|----|
| 光伏剩余计算基准 | 6 月份数据 | 全年日均数据 |
| 月度分布参数 | 需要 | 不需要 |
| 计算复杂度 | 较高 | 较低 |
| 代表性 | 冬季代表月 | 全年平均 |

## 3. 屋顶潜力评估

### 3.1 数据来源

- 基于用户提交的屋顶地址
- 由 GIS 和 3D 屋顶满铺面板
- 提供方位角和默认坡度供下游计算

### 3.2 坡面评分

```javascript
// 计算坡面朝向评分（0-100分）
function calculateRoofScore(aspect) {
  const north = 0;  // 正北为最佳朝向
  let diff = Math.abs(aspect - north);
  if (diff > 180) diff = 360 - diff;
  return Math.max(0, 100 - (diff / 180) * 100);
}
```

**说明**：
- 正北（0°）得分 100
- 正南（180°）得分 0
- 东西向（90°/270°）得分 50

## 4. 基于预设用电量的需求计算

### 4.1 计算目的

作为电池容量推算的依据之一

### 4.2 计算公式

#### 4.2.1 全年日均用电

```
日均用电 = 州年均用电 / 365
```

**NSW 州示例**：
```
日均用电 = 7,778 / 365 = 21.31 kWh
```

#### 4.2.2 逐小时用电

```
Load_hour[h] = 日均用电 × 小时用电比例[h]
```

**NSW 州 18 点示例**：
```
Load_hour[18] = 21.31 × 0.05846 = 1.25 kWh
```

#### 4.2.3 晚高峰用电（17:00-21:00）

```
晚高峰用电 = Σ Load_hour[17..20]
```

**NSW 州示例**：
```
晚高峰用电 = 4.72 kWh
```

#### 4.2.4 整夜用电（17:00-07:00）

```
整夜用电 = Σ Load_hour[17..23] + Σ Load_hour[0..6]
```

**NSW 州示例**：
```
整夜用电 = 12.69 kWh
```

### 4.3 未来扩展

该模块未来可支持：
- 用户上传电费账单
- 输入用电信息
- 选择不同的用电曲线来个性化计算

## 5. 基于预设发电量的计算

### 5.1 计算公式

#### 5.1.1 全年日均发电

```
年发电量 = PV_kW × 各州年发电系数
日均发电 = 年发电量 / 365
```

**NSW 州 6.6kW 示例**：
```
年发电量 = 6.6 × 1,460 = 9,636 kWh
日均发电 = 9,636 / 365 = 26.40 kWh
```

#### 5.1.2 逐小时发电

```
PV_hour[h] = 日均发电 × 小时发电占比[h]
```

**12 点示例**：
```
PV_hour[12] = 26.40 × 0.14 = 3.70 kWh
```

### 5.2 光伏剩余计算（V6 核心简化）

```
光伏剩余 = Σ max(0, PV_hour[h] - Load_hour[h])
```

**NSW 州 6.6kW 示例**：
```
日均发电：26.40 kWh
日均用电：21.31 kWh
光伏剩余：16.72 kWh
```

**说明**：
- V6 使用全年日均数据
- V4 使用 6 月份数据
- V6 更简单、更具代表性

## 6. 方案生成策略

### 6.1 新建系统

**屋顶理论最大容量**：
```
理论最大容量 = 理论可铺满的面板数量 × 预设面板功率
```

### 6.2 储能扩容

**屋顶理论最大容量**：
```
理论最大容量 = FLOOR(理论可铺满的面板数量 × 0.7) × 预设面板功率
```

**说明**：假设已使用 70% 的屋顶潜力

### 6.3 各方案策略

#### 6.3.1 方案 A（高端型）

**目标**：屋顶面板物理极限铺满，最大化利用

**策略**：
1. **新建系统**：铺满，得到最大面板数量
2. **储能扩容**：铺满 × 0.7

#### 6.3.2 方案 B（平衡型）

**目标**：覆盖市场主流 10-13kW 的需求

**策略**：
```
IF 屋顶理论容量 > 15kW:
    目标容量 = 13.0kW
ELSE:
    目标容量 = 10.0kW

IF 屋顶理论容量 > 目标容量:
    从发电量最小的坡面开始扣除面板，直至匹配目标容量
ELSE:
    直接按屋顶实际最大可铺满来计算
```

#### 6.3.3 方案 C（经济型）

**目标**：贴靠澳洲市场 6.6kW 的入门容量

**策略**：
```
目标容量 = 6.6kW

IF 屋顶理论容量 > 6.6kW:
    从发电量最小的坡面开始扣除面板，直至匹配 6.6kW
ELSE:
    直接按屋顶实际最大可铺满来计算
```

## 7. 逆变器选型与容配比校验

### 7.1 背景与策略假设

- 新建系统的方案都带电池，配混合逆变器（Hybrid inverter）
- 储能电池可以直接从 PV 面板进行充电
- 需要满足澳洲对容配比的限制要求
- 配备储能电池的 PV 系统容配比可达 150%-200%，但不能超过 200%
- 默认分析的屋顶都是单相电

### 7.2 计算流程

#### 步骤 1：初选

```
目标逆变器功率 = PV 总容量 / 目标容配比
目标容配比 = 180%
```

#### 步骤 2：匹配

在相位允许的规格库中，寻找 ≥ 目标功率的最小规格

#### 步骤 3：校验与调整

```
实际容配比 = PV 总功率 / 选定逆变器功率
```

**Case 1（合规）**：容配比 ≤ 200%
- 通过，无需调整

**Case 2（过高 > 200%）**：
1. 优先尝试增大逆变器规格
2. 若已达相位允许的最大规格（单相 10kW），则触发削减面板逻辑
3. 削减逻辑：
   ```
   允许的最大 PV 功率 = 逆变器功率 × 2.0
   从最低分坡面开始减少面板，直到满足要求
   ```

## 8. 电池容量推荐（V6 核心逻辑）

### 8.1 策略说明

基于预设的各州用电量、每小时用电比例，推导电池容量需求。

### 8.2 计算公式

#### 8.2.1 A 方案（高端型）

```
E_req = max(整夜需求, aSurplus × 光伏剩余)
Battery_calc = E_req / 效率
Battery_nominal = 标准化(Battery_calc)

其中：
- 整夜需求：17:00-07:00（14小时）
- aSurplus：0.7（调整后）
- 效率：0.855
```

**定位**：
- 整夜覆盖（舒适性/备电）
- 更强的移峰能力
- 50kWh 补贴上限

#### 8.2.2 B 方案（平衡型）

```
E_req = max(晚高峰需求, bSurplus × 光伏剩余)
Battery_calc = E_req / 效率
Battery_nominal = 标准化(Battery_calc)

其中：
- 晚高峰需求：17:00-21:00（4小时）
- bSurplus：0.55
- 效率：0.855
```

**定位**：
- 至少覆盖晚高峰
- 额外容量用于移峰/套利/VPP
- 可用光伏剩余或电网谷电充电

#### 8.2.3 C 方案（经济型）

```
E_req = 晚高峰需求
Battery_calc = E_req / 效率
Battery_nominal = 标准化(Battery_calc)

其中：
- 晚高峰需求：17:00-21:00（4小时）
- 效率：0.855
```

**定位**：
- 晚高峰削峰
- 最经济的配置

### 8.3 标准化处理

```
1. 计算理论容量：Battery_calc = E_req / 0.855
2. 限制范围：Battery_calc = max(5, min(50, Battery_calc))
3. 标准化：选择 ≥ Battery_calc 的最小标准规格
```

**标准规格**：[5, 6.5, 9.6, 10, 13.5, 16, 20, 25, 30, 40, 50] kWh

## 9. 系统投入与报价计算

### 9.1 新建系统

#### 9.1.1 税前整体报价

```
税前报价 = PV容量 × 540 + 逆变器功率 × 280 + 电池容量 × 865
```

#### 9.1.2 补贴计算

**PV 补贴**：
```
Deeming Period = 2030 - 2025 + 1 = 6年
PV_STC = FLOOR(PV_kW × Zone_Rating × Deeming_Period)
```

**电池补贴**：
```
可用容量 = 电池标称容量 × DoD
上限可用容量 = min(可用容量, 50kWh)
Battery_STC = FLOOR(上限可用容量 × 9.3)
```

**总补贴**：
```
总 STC = PV_STC + Battery_STC
补贴金额 = 总 STC × 39
```

#### 9.1.3 最终报价

```
含税总价 = 税前报价 × 1.1
最终报价 = 含税总价 - 补贴金额
```

### 9.2 储能扩容

#### 9.2.1 税前整体报价

```
税前报价 = 逆变器功率 × 280 + 电池容量 × 865
```

**说明**：默认更换新的逆变器，需要增加逆变器成本

#### 9.2.2 补贴计算

维持与新建系统相同的逻辑

#### 9.2.3 最终报价

```
含税总价 = 税前报价 × 1.1
最终报价 = 含税总价 - 补贴金额
```

## 10. 完整推导过程示例

### 10.1 示例 1：大屋顶（27.72kW）

#### 步骤 1：屋顶坡面信息

```
slope 4: 方位角 269.9°, 20 块面板
slope 5: 方位角 180.0°, 4 块面板
slope 6: 方位角 90.0°, 4 块面板
slope 7: 方位角 180.0°, 17 块面板
slope 12: 方位角 90.0°, 3 块面板
slope 13: 方位角 0.0°, 15 块面板
合计：63 块面板
```

#### 步骤 2：物理限制分析

```
有效坡面数量：6 个
物理最大容量：63 片面板
对应总功率：63 × 0.44 = 27.72 kW
```

#### 步骤 3：用户用电需求计算（NSW 州）

```
年用电量：7,778 kWh
日均用电：7,778 / 365 = 21.31 kWh
晚高峰占比：22.1%
晚高峰用电：21.31 × 22.1% = 4.72 kWh
整夜用电：12.69 kWh
```

#### 步骤 4：方案 A 推导

**目标**：物理极限满铺

**初始配置**：63 片 × 440W = 27.72 kW

**逆变器初选**：
```
目标功率 = 27.72 / 1.8 = 15.4 kW
选择：10 kW（单相最大）
```

**容配比校验**：
```
实际容配比 = 27.72 / 10 = 277%（超过 200%）
需要调整！
```

**削减面板**：
```
最大允许 PV = 10 × 2.0 = 20.00 kW
需要削减：27.72 - 20.00 = 7.72 kW → 18 片面板
从发电量最小的坡面顺次削减
```

**最终配置**：
```
PV：45 片 × 440W = 19.80 kW
逆变器：10 kW
容配比：198%（符合要求）
```

**发电计算**：
```
年发电量 = 19.80 × 1,460 = 28,908 kWh
日均发电 = 28,908 / 365 = 79.20 kWh
光伏剩余 = 68.71 kWh（逐小时计算）
```

**电池容量计算**：
```
整夜需求 = 12.69 kWh
0.7 × 剩余 = 0.7 × 68.71 = 48.10 kWh
E_req = max(12.69, 48.10) = 48.10 kWh
Battery_calc = 48.10 / 0.855 = 56.26 kWh
Battery_nominal = 50 kWh（达到上限）
```

#### 步骤 5：方案 B 推导

**目标**：13.0 kW（屋顶容量 > 15kW）

**面板削减**：
```
需要面板 = CEILING(13.0 / 0.44) = 30 块
从发电量最小的坡面开始削减
```

**最终配置**：
```
PV：30 片 × 440W = 13.20 kW
逆变器：8 kW（目标 7.3kW，选择 8kW）
容配比：165%（符合要求）
```

**发电计算**：
```
日均发电 = 13.20 × 1,460 / 365 = 52.80 kWh
光伏剩余 = 42.39 kWh
```

**电池容量计算**：
```
晚高峰需求 = 4.72 kWh
0.55 × 剩余 = 0.55 × 42.39 = 23.31 kWh
E_req = max(4.72, 23.31) = 23.31 kWh
Battery_calc = 23.31 / 0.855 = 27.26 kWh
Battery_nominal = 30 kWh
```

#### 步骤 6：方案 C 推导

**目标**：6.6 kW

**面板削减**：
```
需要面板 = CEILING(6.6 / 0.44) = 15 块
```

**最终配置**：
```
PV：15 片 × 440W = 6.60 kW
逆变器：5 kW（目标 3.7kW，选择 5kW）
容配比：132%（符合要求）
```

**发电计算**：
```
日均发电 = 6.60 × 1,460 / 365 = 26.40 kWh
光伏剩余 = 16.72 kWh
```

**电池容量计算**：
```
晚高峰需求 = 4.72 kWh
0.55 × 剩余 = 0.55 × 16.72 = 9.20 kWh
E_req = max(4.72, 9.20) = 9.20 kWh
Battery_calc = 9.20 / 0.855 = 10.76 kWh
Battery_nominal = 13.5 kWh
```
