## 🎯 核心简化对比

### V4 方式
```
使用 6 月份数据
├── 需要月度发电占比（PV_MONTHLY_SHARE）
├── 需要月度用电占比（LOAD_MONTHLY_SHARE）
└── 计算 6 月日均光伏剩余
```

### V6 方式
```
使用全年日均数据
├── 年发电量 / 365 = 日均发电
├── 年用电量 / 365 = 日均用电
└── 计算全年日均光伏剩余
```

### 优势对比

| 维度 | V4 | V6 | 改进 |
|------|----|----|------|
| 参数数量 | 多 | 少 | ✅ 减少 2 个月度参数 |
| 代码行数 | 516 | 590* | - |
| 计算复杂度 | 较高 | 较低 | ✅ 简化 |
| 代表性 | 冬季月 | 全年平均 | ✅ 更全面 |
| 可维护性 | 一般 | 好 | ✅ 更易维护 |

## 🔍 计算逻辑验证示例

### 案例：7.92kW 系统（18块板）

**输入**：
- PV容量：7.92 kW
- 州：NSW
- 年发电系数：1,460 kWh/kW/年
- 年用电量：7,778 kWh

**计算过程**：
```
1. 年发电量 = 7.92 × 1,460 = 11,563.2 kWh
2. 日均发电 = 11,563.2 / 365 = 31.68 kWh ✓
3. 日均用电 = 7,778 / 365 = 21.31 kWh ✓
4. 光伏剩余 = 21.79 kWh（逐小时计算）✓
5. 整夜需求 = 12.69 kWh ✓
6. 0.8×剩余 = 17.43 kWh
7. 取最大值 = 17.43 kWh
8. 除以效率 = 17.43 / 0.855 = 20.39 kWh
9. 标准化 = 25 kWh ✓
```

**输出**：
- 逆变器：5 kW（容配比 158%）
- 电池：25 kWh
- 最终价格：$19,346 AUD

**验证**：✅ 所有计算正确
