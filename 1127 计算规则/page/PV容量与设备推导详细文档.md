## 3. PV 容量计算

### 3.1 坡面评分算法

**目的**：评估每个坡面的发电潜力，用于优先级排序。

**规则**：南半球以正北 (0°/360°) 为最优朝向。

```javascript
// 评分公式
function calculateSlopeScore(aspect) {
    // 计算与正北的偏差角度
    let deviationFromNorth = Math.abs(aspect - 0);
    if (deviationFromNorth > 180) {
        deviationFromNorth = 360 - deviationFromNorth;
    }
    
    // 分段评分
    if (deviationFromNorth <= 45) {
        // 北向 ±45°: 90-100分
        return 90 + (45 - deviationFromNorth) / 4.5;
    }
    if (deviationFromNorth <= 135) {
        // 东/西向: 70-90分
        return 70 + (135 - deviationFromNorth) / 4.5;
    }
    // 南向: 40-60分
    return Math.max(40, 60 - (deviationFromNorth - 135) / 2);
}
```

**评分对照表**：

| 朝向 | 方位角范围 | 评分范围 | 发电效率 |
|------|-----------|---------|---------|
| 正北 (N) | 337.5°-22.5° | 90-100 | 最优 |
| 东北/西北 (NE/NW) | 22.5°-67.5° / 292.5°-337.5° | 85-95 | 优良 |
| 正东/正西 (E/W) | 67.5°-112.5° / 247.5°-292.5° | 70-85 | 良好 |
| 东南/西南 (SE/SW) | 112.5°-157.5° / 202.5°-247.5° | 55-70 | 一般 |
| 正南 (S) | 157.5°-202.5° | 40-55 | 较差 |

### 3.2 三套方案的目标容量

| 方案 | 类型 | 目标容量 | 策略说明 |
|------|------|---------|---------|
| **方案 A** | 高端型 | 物理极限 (999kW) | 满铺所有可用坡面 |
| **方案 B** | 平衡型 | 10-13kW (动态) | 根据屋顶大小调整 |
| **方案 C** | 经济型 | 6.6kW (固定) | 入门配置，快速回本 |

**方案 B 动态目标计算**：

```javascript
// 方案B目标容量计算
const totalMaxKw = totalMaxPanels * PV_WATT / 1000;  // 屋顶物理上限

if (totalMaxKw > 15) {  // roofThreshold = 15kW
    targetKwB = 13.0;   // 大屋顶：13kW
} else {
    targetKwB = 10.0;   // 小屋顶：10kW
}
```

### 3.3 贪心填充算法

**算法逻辑**：按评分从高到低依次填充坡面，直到达到目标容量。

```javascript
function fillRoofWithLog(sortedPlanes, targetKw, panelWatt) {
    // 计算需要的组件数量
    let neededPanels = Math.ceil((targetKw * 1000) / panelWatt);
    let currentPanels = 0;
    let distribution = [];
    
    // 按评分排序后的坡面依次填充
    for (let plane of sortedPlanes) {
        if (plane.max === 0) continue;  // 跳过不可用坡面
        
        let remainingNeed = neededPanels - currentPanels;
        if (remainingNeed <= 0) break;  // 已达目标
        
        // 从当前坡面取尽可能多的组件
        let take = Math.min(plane.max, remainingNeed);
        currentPanels += take;
        
        distribution.push({
            planeId: plane.id,
            count: take
        });
    }
    
    return {
        count: currentPanels,
        totalKw: currentPanels * panelWatt / 1000,
        distribution: distribution
    };
}
```

**计算公式**：

```
实际PV容量 (kW) = 实际组件数量 × 单片功率 (W) / 1000
```

## 4. 逆变器选型

### 4.1 容配比概念

**容配比 (DC/AC Ratio)** = PV 直流容量 / 逆变器交流容量

```
容配比 = PV容量 (kW) / 逆变器容量 (kW) × 100%
```

**系统配置的容配比规则**：

| 参数 | 值 | 说明 |
|------|-----|------|
| `targetRatio` | 180% | 目标容配比 |
| `maxRatio` | 200% | 最大允许容配比 |
| `minRatio` | 150% | 建议最小容配比 |

### 4.2 逆变器规格限制

**单相电网**：

| 参数 | 值 |
|------|-----|
| 最大逆变器容量 | 10kW |
| 可选规格 | 3, 5, 6, 8, 10 kW |

**三相电网**：

| 参数 | 值 |
|------|-----|
| 最大逆变器容量 | 30kW |
| 可选规格 | 5, 8, 10, 15, 20, 25, 30 kW |

### 4.3 逆变器选型公式

```javascript
// 基于目标容配比计算所需逆变器容量
rawInverterRequirement = PV容量 / 目标容配比
                       = PV容量 / 1.8

// 向上取整到可用规格
selectedInverter = 从可选规格中选择 ≥ rawInverterRequirement 的最小值
```

**示例**：

```
PV容量 = 13.2 kW
目标容配比 = 180%

rawInverterRequirement = 13.2 / 1.8 = 7.33 kW
单相可选规格: [3, 5, 6, 8, 10]
选择: 8 kW (≥7.33 的最小值)

实际容配比 = 13.2 / 8 × 100% = 165%
```

### 4.4 逆变器选型决策树

```
                    ┌─────────────────────┐
                    │ 计算原始需求容量     │
                    │ raw = PV / 1.8      │
                    └──────────┬──────────┘
                               ↓
                    ┌─────────────────────┐
                    │ 从可选规格中选择     │
                    │ inv = min(规格≥raw) │
                    └──────────┬──────────┘
                               ↓
                    ┌─────────────────────┐
                    │ 计算实际容配比       │
                    │ ratio = PV/inv×100% │
                    └──────────┬──────────┘
                               ↓
              ┌────────────────┼────────────────┐
              ↓                ↓                ↓
        ratio < 150%    150% ≤ ratio ≤ 200%   ratio > 200%
              ↓                ↓                ↓
        ┌─────────┐      ┌─────────┐      ┌─────────┐
        │ 提示偏低 │      │ 合格通过 │      │ 需要调整 │
        │ 可减小   │      │         │      │         │
        │ 逆变器   │      │         │      │         │

                    └─────────────────┘              └─────────────────┘
```

## 5. 电池容量计算

### 5.1 三维度计算法

电池容量基于三个维度计算，取最大值：

```
最终电池容量 = max(维度1, 维度2, 维度3)
```

#### 维度 1：日用电覆盖

```
维度1 = 日均用电量 × 覆盖系数

日均用电量 = 年用电量 / 365
```

#### 维度 2：傍晚高峰覆盖

```
维度2 = 傍晚高峰用电 × 倍率系数

傍晚高峰用电 = 日均用电量 × 傍晚占比
傍晚占比 = Σ(17:00-21:00 各小时用电比例)
```

#### 维度 3：光伏容量匹配

```
维度3 = PV系统容量 × 匹配系数
```

### 5.2 各方案系数配置

| 方案 | 日用电系数 | 傍晚峰值系数 | PV匹配系数 | 设计目标 |
|------|-----------|-------------|-----------|---------|
| **经济型** | 0.2 (20%) | 1.0 | 0.8 | 基础储能，确保晴天充满 |
| **平衡型** | 0.3 (30%) | 1.5 | 1.0 | 标准配置，充分利用发电 |
| **高端型** | 0.5 (50%) | 2.0 | 1.5 | 大容量，追求能源独立 |

### 5.3 完整计算公式

```javascript
function calculateBatteryCapacity(pvSystemKw, state, method) {
    // 获取用电数据
    const annualConsumption = STATE_CONSUMPTION[state];
    const dailyConsumption = annualConsumption / 365;
    
    // 计算傍晚高峰用电 (17:00-21:00)
    const hourlyProfile = STATE_HOURLY_PROFILE[state];
    const eveningPeakRatio = (
        hourlyProfile[16] + hourlyProfile[17] + 
        hourlyProfile[18] + hourlyProfile[19] + 
        hourlyProfile[20]
    ) / 100;
    const eveningPeakConsumption = dailyConsumption * eveningPeakRatio;
    
    // 根据方案类型计算
    let capacity;
    if (method === 'economy') {
        const method1 = dailyConsumption * 0.2;
        const method2 = eveningPeakConsumption * 1.0;
        const method3 = pvSystemKw * 0.8;
        capacity = Math.max(method1, method2, method3);
    } else if (method === 'balanced') {
        const method1 = dailyConsumption * 0.3;
        const method2 = eveningPeakConsumption * 1.5;
        const method3 = pvSystemKw * 1.0;
        capacity = Math.max(method1, method2, method3);
    } else if (method === 'premium') {
        const method1 = dailyConsumption * 0.5;
        const method2 = eveningPeakConsumption * 2.0;
        const method3 = pvSystemKw * 1.5;
        capacity = Math.max(method1, method2, method3);
    }
    
    // 标准化到常见电池规格
    const standardSizes = [0, 5, 6.5, 9.6, 10, 13.5, 16, 20];
    const finalCapacity = standardSizes.find(s => s >= capacity) || capacity;
    
    return finalCapacity;
}
```

### 5.4 为什么取三者最大值？

这是一种**保守且全面的设计策略**，确保储能系统能够**同时满足**：

| 维度 | 保障目标 | 避免的问题 |
|------|---------|-----------|
| 日用电覆盖 | 覆盖家庭基本用电 | 储能容量不足，晚间用电不够 |
| 傍晚高峰覆盖 | 支撑傍晚用电高峰 | 高峰时段需要购买高价电 |
| 光伏容量匹配 | 避免发电浪费 | 光伏发电无法储存，白白浪费 |

## 6. 边界情况处理

### 6.1 容配比超限 (>200%)

**触发条件**：实际容配比 > 200%

**处理策略**：

```
优先策略: 升级逆变器
    ↓
如果逆变器已达上限:
    ↓
备选策略: 减少PV组件 (从低评分坡面开始移除)
```

**计算公式**：

```javascript
// 计算需要的最小逆变器容量
minInverterForCompliance = Math.ceil(PV容量 / 2.0);

// 如果无法升级逆变器，计算需要减少的组件
maxAllowedKw = 最大逆变器容量 × 2.0;
excessKw = PV容量 - maxAllowedKw;
panelsToRemove = Math.ceil(excessKw × 1000 / 单片功率);
```

**示例**：

```
场景: 单相电网，PV容量 = 22kW
最大逆变器 = 10kW
最大允许PV = 10 × 2.0 = 20kW
超出 = 22 - 20 = 2kW
需移除 = ceil(2000 / 440) = 5 片

调整后: 22 - 5×0.44 = 19.8kW
容配比 = 19.8 / 10 = 198% ✓
```

### 6.2 容配比偏低 (<150%)

**触发条件**：实际容配比 < 150%

**处理方式**：仅提示，不强制调整

```
💡 容配比偏低，可考虑减小逆变器以提高经济性
```

### 6.3 屋顶容量不足

**触发条件**：物理最大容量 < 目标容量

**处理方式**：使用实际可用的最大容量

```javascript
// 贪心算法会自动处理
// 当所有坡面填满后，返回实际可用容量
if (currentPanels < neededPanels) {
    // 实际容量 = 所有可用坡面的总和
    actualKw = currentPanels * panelWatt / 1000;
}
```

### 6.4 无可用坡面

**触发条件**：所有坡面的 nums = 0

**处理方式**：

```javascript
// 返回零配置
return {
    count: 0,
    totalKw: 0,
    layoutStr: "无可用空间"
};
```

### 6.5 逆变器规格不在可选列表

**触发条件**：计算出的逆变器需求不在标准规格中

**处理方式**：向上取整到最近的可用规格

```javascript
// 示例: 需要 7.33kW，可选 [3, 5, 6, 8, 10]
selected = options.find(s => s >= 7.33);  // 返回 8
```

### 6.6 电池容量标准化

**触发条件**：计算出的电池容量不是标准规格

**处理方式**：向上取整到最近的标准规格

```javascript
// 标准电池规格
standardSizes = [0, 5, 6.5, 9.6, 10, 13.5, 16, 20];

// 示例: 计算出 7.2kWh
finalCapacity = standardSizes.find(s => s >= 7.2);  // 返回 9.6
```

## 7. 完整计算示例

### 示例场景

```
输入数据:
- 房屋 ID: 27
- 所在州: NSW
- 电网类型: 单相
- 年用电量: 7,300 kWh

屋顶坡面数据:
| 坡面 | 方位角 | 可安装数量 |
|------|--------|-----------|
| slope 4 | 269.9° | 17 |
| slope 5 | 180.0° | 3 |
| slope 6 | 90.0° | 4 |
| slope 7 | 180.0° | 15 |
| slope 12 | 90.0° | 4 |
| slope 13 | 0° | 20 |
```

### Step 1: 坡面评分与排序

```
slope 13: 方位角 0° (正北) → 评分 100
slope 4: 方位角 269.9° (西) → 评分 74.5
slope 6: 方位角 90° (东) → 评分 80
slope 12: 方位角 90° (东) → 评分 80
slope 5: 方位角 180° (南) → 评分 50
slope 7: 方位角 180° (南) → 评分 50

排序后: slope 13 > slope 6 = slope 12 > slope 4 > slope 5 = slope 7
```

### Step 2: 物理限制分析

```
总可安装组件 = 17 + 3 + 4 + 15 + 4 + 20 = 63 片
物理最大容量 = 63 × 440W / 1000 = 27.72 kW
```

### Step 3: 用电数据分析

```
年用电量: 7,300 kWh
日均用电: 7,300 / 365 = 20 kWh
傍晚高峰占比 (NSW): 4.569 + 5.328 + 5.846 + 5.634 + 5.329 = 26.7%
傍晚高峰用电: 20 × 26.7% = 5.34 kWh
```

### Step 4-6: 方案 B (平衡型) 推导

```
1. 确定目标容量:
   屋顶容量 27.72kW > 阈值 15kW → 目标 13kW

2. 贪心填充:
   需要组件数 = ceil(13000 / 440) = 30 片
   
   填充过程:
   - slope 13 (评分100): 使用 20/20 片
   - slope 6 (评分80): 使用 4/4 片
   - slope 12 (评分80): 使用 4/4 片
   - slope 4 (评分74.5): 使用 2/17 片
   
   实际组件数 = 20 + 4 + 4 + 2 = 30 片
   实际PV容量 = 30 × 440 / 1000 = 13.2 kW

3. 逆变器选型:
   原始需求 = 13.2 / 1.8 = 7.33 kW
   单相可选: [3, 5, 6, 8, 10]
   选择: 8 kW

4. 容配比校验:
   实际容配比 = 13.2 / 8 × 100% = 165%
   165% 在 150%-200% 范围内 ✓

5. 电池容量计算 (平衡型):
   维度1 = 20 × 0.3 = 6.0 kWh
   维度2 = 5.34 × 1.5 = 8.01 kWh
   维度3 = 13.2 × 1.0 = 13.2 kWh
   
   计算值 = max(6.0, 8.01, 13.2) = 13.2 kWh
   标准化 = 13.5 kWh (向上取整到标准规格)
```

### 最终配置 (方案 B)

| 项目 | 值 |
|------|-----|
| PV 容量 | 13.2 kW |
| 组件数量 | 30 片 |
| 逆变器 | 8 kW Hybrid |
| 容配比 | 165% |
| 电池容量 | 13.5 kWh |
