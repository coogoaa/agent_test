# 逆变器选型逻辑详解

## 问题修复

### 原问题
1. **方案C容配比超标**：房屋44选择单相时，方案C容配比达到202%，违反澳洲规定
2. **逆变器选型不透明**：没有清晰展示逆变器是如何推导出来的

### 根本原因
- 方案C原本使用 `1.33` 的容配比计算逆变器（适用于无储能系统）
- 但方案C是高端型，包含储能，应该允许 `150%-200%` 的容配比
- 没有根据容配比规则反推逆变器功率

## 新的选型逻辑

### 核心原则
1. **先确定方案类型** → 确定容配比限制
2. **根据容配比规则反推** → 计算最小逆变器功率
3. **考虑电网相位限制** → 选择合适的逆变器规格
4. **验证容配比** → 确保符合澳洲规定

## 方案 A (经济型 - 无储能)

### 容配比规则
- **限制**: ≤133% (CEC规定)
- **原因**: 无储能系统，削峰能量直接损失

### 选型步骤
```
1. 方案类型: 经济型 (无储能) → 容配比限制 ≤133%
2. 计算最小逆变器: minInv = PV功率 / 1.33
3. 根据电网相位选择:
   - 单相: [3, 5] kW
   - 三相: [5, 6, 8, 10] kW
4. 选择 ≥ minInv 的最小规格
5. 验证容配比是否 ≤133%
```

### 示例（房屋44，单相）
```
PV功率: 6.6 kW
最小逆变器: 6.6 / 1.33 = 4.96 kW
电网类型: 单相 → 可选 [3, 5] kW
选择: 5 kW String
实际容配比: 6.6 / 5 = 132% ✓ 符合规则
```

## 方案 B (平衡型 - Hybrid)

### 容配比规则
- **限制**: 150%-200% (澳洲Hybrid系统)
- **目标**: 180% (合理范围中值)
- **原因**: 电池可吸收削峰能量，允许超配

### 选型步骤
```
1. 方案类型: 平衡型 (含储能) → 允许容配比 150%-200%
2. 目标容配比: 180%
3. 计算目标逆变器: targetInv = PV功率 / 1.8
4. 根据电网相位选择:
   - 单相: [5, 8] kW
   - 三相: [5, 8, 10, 15] kW
5. 选择 ≥ targetInv 的最小规格
6. 验证容配比是否在 150%-200% 范围
```

### 示例（房屋44，单相，10kW PV）
```
PV功率: 10.0 kW
目标逆变器: 10.0 / 1.8 = 5.56 kW
电网类型: 单相 → 可选 [5, 8] kW
选择: 8 kW Hybrid
实际容配比: 10.0 / 8 = 125% 
⚠️ 偏低，可考虑减小逆变器
建议: 5 kW Hybrid → 容配比 200% ✓
```

## 方案 C (高端型 - Hybrid满铺)

### 容配比规则
- **限制**: 150%-200% (澳洲Hybrid系统)
- **目标**: 180% (合理范围中值)
- **原因**: 高端型配大容量储能，允许超配

### 选型步骤
```
1. 方案类型: 高端型 (含储能) → 允许容配比 150%-200%
2. 目标容配比: 180%
3. 计算目标逆变器: targetInv = PV功率 / 1.8
4. 根据电网相位选择:
   - 单相: [5, 6, 8, 10] kW
   - 三相: [5, 8, 10, 15, 20, 30] kW
5. 选择 ≥ targetInv 的最小规格
6. 验证容配比:
   - 如果 > 200%: 强制调整到符合规则
   - 如果 < 150%: 提示可优化
   - 如果 150%-200%: 合理范围 ✓
```

### 示例（房屋44，单相，20.24kW PV）
```
PV功率: 20.24 kW (满铺)
目标逆变器: 20.24 / 1.8 = 11.24 kW
电网类型: 单相 → 可选 [5, 6, 8, 10] kW
初选: 10 kW Hybrid (单相最大)
实际容配比: 20.24 / 10 = 202% ⚠️ 超过200%！

⚠️ 容配比 202% 超过 200%，违反澳洲Hybrid系统规则！
需要调整: 最小逆变器 = 20.24 / 2.0 = 10.12 kW
但单相最大只有10kW，无法满足！

解决方案:
1. 减少面板数量到 10kW × 2.0 = 20kW
2. 或升级为三相电网 → 可选15kW逆变器
   容配比: 20.24 / 15 = 135% ✓ 符合规则
```

## 澳洲容配比规定

### 无储能系统 (String Inverter)
- **CEC规定**: DC/AC ≤ 133%
- **原因**: 
  - 削峰能量直接损失
  - 逆变器长期过载影响寿命
  - 电网稳定性要求

### Hybrid系统 (含储能)
- **澳洲标准**: DC/AC ≤ 200%
- **合理范围**: 150%-200%
- **原因**:
  - 电池可吸收削峰能量
  - 提高系统经济性
  - 充分利用屋顶空间

### 电网相位限制
| 电网类型 | String逆变器 | Hybrid逆变器 | 备注 |
|---------|------------|-------------|------|
| 单相 | ≤5kW | ≤10kW | 部分DNSP允许8kW |
| 三相 | ≤30kW | ≤30kW | 标准限制，更大需申请 |

## 优化建议

### 当容配比过高 (>200%)
1. **增大逆变器**（首选）
2. **减少面板数量**
3. **升级电网相位**（单相→三相）

### 当容配比过低 (<150% for Hybrid)
1. **减小逆变器**（提高经济性）
2. **增加面板数量**（充分利用容配比空间）

### 当单相无法满足
```
问题: 20.24kW PV，单相最大10kW逆变器
容配比: 202% > 200% ❌

解决方案:
1. 减少到 20kW PV (10kW × 2.0)
2. 升级三相 → 15kW逆变器 (容配比 135%)
3. 分两个系统: 2×10kW PV + 2×5kW逆变器
```
