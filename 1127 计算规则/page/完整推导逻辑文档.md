# 光伏设备推荐系统 - 完整推导逻辑文档

## 系统概述

本系统基于GIS屋顶数据、用户位置信息和澳洲CEC标准，动态生成三套差异化的光伏设备配置方案。所有参数均通过算法推导，无固定预设值。

---

## 核心输入参数

### 1. 屋顶数据（GIS）
```javascript
{
  id: "slope 1",        // 坡面ID
  aspect: 359.8,        // 方位角（度，0=正北）
  max: 15               // 最大可安装面板数
}
```

### 2. 用户信息
- **房屋ID**: 唯一标识
- **州/领地**: TAS/NT/ACT/SA/NSW/QLD/VIC/WA
- **电网相位**: 单相 / 三相

### 3. 固定参数
- **PV组件功率**: 440W (JA Solar)
- **组件尺寸**: 1.134m × 1.722m
- **组件效率**: 21.06%

## 推导流程（6步）

### Step 1: 屋顶坡面评分

**目的**: 评估每个坡面的发电潜力

**公式**:
```javascript
// 南半球，正北（0°）为最佳方向
diff = Math.abs(aspect - 0);
if (diff > 180) diff = 360 - diff;
score = Math.max(0, 100 - (diff / 180) * 100);
```

**评分标准**:
| 方位 | 方位角 | 评分 | 等级 |
|------|--------|------|------|
| 正北 | 0° | 100 | 优秀 |
| 东北/西北 | 45°/315° | 75 | 良好 |
| 正东/正西 | 90°/270° | 50 | 一般 |
| 东南/西南 | 135°/225° | 25 | 较差 |
| 正南 | 180° | 0 | 不推荐 |

**输出示例**:
```
坡面评分结果:
  slope 1 (方位角 359.8°): 评分 100 (正北, 优秀)
  slope 2 (方位角 269.8°): 评分 50 (西偏北, 一般)
```

#### 3.2 逆变器选型

**规则**: Hybrid系统，目标容配比180%

**算法**:
```javascript
// 1. 计算目标逆变器功率
targetInv = Math.ceil(totalKw / 1.8);  // 180%容配比

// 2. 根据电网相位选择可用规格
if (phaseType === 'single') {
    availableSizes = [5, 6, 8, 10];  // 单相限制 ≤10kW
} else {
    availableSizes = [5, 8, 10, 15, 20, 30];  // 三相可选 ≤30kW
}

// 3. 选择最接近的规格
selectedInv = availableSizes.find(s => s >= targetInv) || availableSizes[last];

// 4. 计算实际容配比
actualRatio = (totalKw / selectedInv) × 100;
```

**容配比验证**:
```javascript
if (actualRatio > 200) {
    // 违反澳洲规定，需要调整
    
    // 方案1: 尝试增大逆变器
    minInv = Math.ceil(totalKw / 2.0);
    compliantInv = availableSizes.find(s => s >= minInv);
    
    if (compliantInv && compliantInv > selectedInv) {
        // 可以通过增大逆变器解决
        selectedInv = compliantInv;
    } else {
        // 方案2: 逆变器已达上限，减少面板
        maxInv = availableSizes[last];
        maxAllowedKw = maxInv × 2.0;  // 200%限制
        excessKw = totalKw - maxAllowedKw;
        panelsToRemove = Math.ceil(excessKw × 1000 / 440);
        
        // 从低分坡面开始减板子
        sortedByScore = roofPlanes.sort((a, b) => a.score - b.score);
        for (plane of sortedByScore) {
            if (removedCount >= panelsToRemove) break;
            removeFromPlane(plane);
        }
        
        // 重新计算
        totalKw = (totalPanels - panelsToRemove) × 0.44;
        actualRatio = (totalKw / maxInv) × 100;
    }
}
```

## 关键算法详解

### 1. 贪心填充算法

**目的**: 在满足目标容量的前提下，优先使用高分坡面

**伪代码**:
```python
def fillRoof(sortedPlanes, targetKw):
    neededPanels = ceil(targetKw * 1000 / 440)
    currentPanels = 0
    usedPlanes = []
    
    for plane in sortedPlanes:
        if plane.max == 0:
            continue
        
        remainingNeed = neededPanels - currentPanels
        if remainingNeed <= 0:
            break
        
        take = min(plane.max, remainingNeed)
        currentPanels += take
        usedPlanes.append({plane.id, take})
    
    return {
        count: currentPanels,
        totalKw: currentPanels * 0.44,
        usedPlanes: usedPlanes
    }
```

**时间复杂度**: O(n)，n为坡面数量

### 2. 容配比调整算法

**目的**: 确保所有方案符合澳洲200%容配比限制

**决策树**:
```
容配比 > 200%?
├─ Yes
│  ├─ 尝试增大逆变器
│  │  ├─ 有更大规格可用? → 增大逆变器 ✓
│  │  └─ 已达上限? → 减少面板
│  │     ├─ 计算超出量
│  │     ├─ 从低分坡面减板子
│  │     └─ 重新计算 ✓
│  └─ 完成
└─ No
   ├─ 150% ≤ 容配比 ≤ 200%? → 合理范围 ✓
   └─ 容配比 < 150%? → 提示可优化
```

### 3. 电池容量标准化

**目的**: 将计算值标准化到市场常见规格

**规格列表**: [5, 6.5, 9.6, 10, 13.5, 16, 20] kWh

**算法**:
```javascript
function standardize(calculated) {
    const standards = [5, 6.5, 9.6, 10, 13.5, 16, 20];
    return standards.find(s => s >= calculated) || calculated;
}
```

**示例**:
- 计算值 5.6 kWh → 标准化 6.5 kWh
- 计算值 11.2 kWh → 标准化 13.5 kWh
- 计算值 29.7 kWh → 标准化 20 kWh (上限)

## 边界情况处理

### 1. 无可用屋顶空间

**条件**: 所有坡面 `max = 0`

**处理**:
```javascript
if (totalMaxPanels === 0) {
    return {
        error: '无可用屋顶空间',
        allPlans: 'N/A'
    };
}
```

### 2. 屋顶空间不足

**条件**: `totalMaxKw < targetKw`

**处理**: 使用实际可用容量，不强制达到目标

```javascript
// 方案C目标6.6kW，但只有2片可用
targetPanels = 15;
actualPanels = 2;  // 只能装2片
actualKw = 0.88;   // 实际0.88kW
```

### 3. 容配比极端情况

**情况1**: 容配比过高（>200%）
- 处理: 增大逆变器或减少面板

**情况2**: 容配比过低（<100%）
- 处理: 提示可优化，但不强制调整

**情况3**: 单相电网大系统
- 限制: 逆变器≤10kW
- 处理: 自动减板子确保合规
