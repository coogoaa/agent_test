# 竞品逻辑深度解析与定价策略建议

本文档旨在深入剖析 SolarQuotes (SQ) 的核心计算逻辑，并结合安装商反馈与销售目标，为现有系统的成本定价和配置策略提供改进建议。

---

## 1. 竞品核心逻辑解析：能量平衡法 (Energy Balance Method)

目前的系统计算逻辑侧重于“需求侧”（即：用户用多少电，就配多大电池），而 SQ 的逻辑引入了“供给侧”约束（即：光伏能发多少电，能否喂饱电池）。

### 1.1 核心概念：供需剪刀差
SQ 不仅仅看电池容量，而是看**实际可用的存储能量**。

*   **公式**：`可存储能量 (Storable Energy) = 出口电量 (Exported) × 充电效率 (Charge Eff)`
*   **逻辑推演**：
    1.  **发电 (Generation)**：系统产生电能。
    2.  **自用 (Self-Consumption)**：家庭负载优先消耗。
    3.  **出口 (Exported)**：`发电 - 自用 = 剩余电量`。只有这部分“剩余电量”才能进电池。
    4.  **存储 (Stored)**：电池实际充进去的电量。

### 1.2 为什么 SQ 的逻辑更严谨？
*   **场景 A (大屋顶，小用电)**：光伏剩余很多。SQ 逻辑允许配大电池。
*   **场景 B (小屋顶，大用电)**：
    *   **现有逻辑**：因为用电大，系统推荐大电池（如 13.5kWh）。
    *   **SQ 逻辑**：计算发现冬天每天剩余电量只有 5kWh。装 13.5kWh 电池是浪费，因为永远充不满。**SQ 会限制电池收益计算，或者建议不装大电池。**

### 1.3 效率损耗与保留容量
SQ 非常诚实地计算了损耗，这会让 ROI 看起来略低，但更真实：
*   **往返效率 (RTE ~90%)**：充进 10度，只能放出 9度。意味着每存一度电，都在亏损 10% 的电能成本（如果算上损失的 FiT 收入，成本更高）。
*   **保留容量 (Reserve ~20%)**：10kWh 的电池，只有 8kWh 用于日常套利，剩下 2kWh 留给防停电（Blackout protection）。计算回本时，分母变小了，回本周期变长。

## 2. 成本定价策略：从 SQ 验证 "方案B"

### 2.1 竞品定价模型分析
SQ 的模型非常简单粗暴：
*   **Solar Only**: `$900 / kW`
*   **Hybrid (Solar + Battery)**: `$700 / kW` + 电池成本

**这个价差 ($200/kW) 说明了什么？**
这验证了**边际成本递减**的商业逻辑。
*   当用户购买“光储套餐”时，安装商只需上门一次（Truck Roll），布线和人工成本是共享的。
*   因此，光伏部分的单价可以打折。

### 2.2 "方案B" (基准+增量) 的优势
我们设计的方案B（Base + Incremental）其实是 SQ 模型的**通用数学版**，且更具弹性。

*   **SQ 模型**：`总价 = (700 * 容量) + 电池`
*   **方案B**：`总价 = 基准包价格 + (增量单价 * 增量容量) + 电池`

**结论**：我们不需要改变方案B的内核，只需要**简化安装商的输入界面**。安装商不需要理解“线性回归”，他们只需要理解“套餐价”和“加板子钱”。

## 3. 结合客户反馈的战略建议

### 3.1 核心矛盾分析
*   **客户/安装商需求**：简单、灵活、低价吸引眼球（高 ROI）。
*   **系统现状**：追求自动化、精准、可能配置项过多。

我们需要在**“科学准确性”**和**“营销吸引力”**之间找到平衡。

### 3.2 推荐策略：分层配置 (The "Installer Freedom" Model)

建议将配置权限下放给安装商，提供三种“营销模式”的预设，而不是让安装商填几十个参数。

#### 建议 A：针对“板子铺满” vs “标准规格”的设置
在后台提供一个简单的开关或下拉菜单：

*   **选项 1：性能优先 (Maximize Yield)** —— *当前逻辑*
    *   逻辑：能装多少装多少（满铺）。
    *   适用：针对高端客户，追求能源独立。
*   **选项 2：市场标准 (Standard Sizes)** —— *客户建议逻辑*
    *   逻辑：系统强制对齐到最近的标准档位：`6.6kW`, `10kW`, `13.3kW`。
    *   算法调整：如果屋顶能装 8kW，自动“砍”到 6.6kW；如果能装 12kW，自动“砍”到 10kW。
    *   优势：符合市场主流报价习惯，安装商备货容易。

#### 建议 B：针对电池大小的设置
不要让系统死板地计算，允许安装商设置**“首推策略”**：

*   **策略 1：自给自足 (Self-Sufficiency)**：系统计算（Max算法），追求不买电。
*   **策略 2：ROI 优先 (Best Payback)**：限制电池容量，只推小电池（5-10kWh），保证回本快。
*   **策略 3：固定搭配 (Fixed Bundle)**：
    *   6.6kW 系统 -> 强制配 5kWh 电池
    *   10kW 系统 -> 强制配 10kWh 电池
    *   *这是安装商最喜欢的“傻瓜式”销售，不用动脑子算。*

#### 建议 C：产品分级 (Tiers) 的定价配置化
客户提到的“入门、中端、高端”可以直接映射到我们的 **方案 C, B, A**。

**建议的简化配置界面（给安装商看）：**

| 方案分级 | 营销标签 (Label) | 光伏策略 (PV Strategy) | 电池策略 (Battery) | 价格策略 (Pricing) |
| :--- | :--- | :--- | :--- | :--- |
| **方案 C (入门)** | "高性价比 / 快速回本" | **锁定标准值** (6.6kW) | **小/无** (可选 0 或 5kWh) | **激进低价** (低基准费, 低利润) |
| **方案 B (主流)** | "最受欢迎 / 黄金组合" | **锁定标准值** (10/13kW) | **中等** (10kWh, 覆盖晚高峰) | **标准定价** (正常利润) |
| **方案 A (高端)** | "极致性能 / 能源独立" | **满铺** (Maximize) | **大/备电** (13.5kWh+, Tesla) | **溢价定价** (高品牌溢价) |

### 3.3 针对“吸引终端用户”的特殊处理 (ROI 优化)

客户经理反馈：“不需要太复杂去追求准确性，要高回报率吸引客户”。
这是一把双刃剑。建议采取**“乐观但合理”**的默认参数策略：

1.  **乐观的自用率**：在计算 ROI 时，默认使用较高的自用率预设（如 40%-50%），除非数据明显不支持。
2.  **未来的电价通胀**：默认计入 3%-5% 的电价上涨，这会让 10年后的节省看起来很可观，从而缩短名义上的回本周期。
3.  **隐藏复杂项**：在给终端用户的简报中，隐藏“电池衰减”、“逆变器更换成本”等负面因子（但在详细合同或高级视图中保留，以免法律风险）。

## 4. 总结与行动计划

### 4.1 结论
SQ 的能量平衡法是计算的**内核**（保证不离谱），但安装商需要的**外壳**是灵活的营销工具。我们应该用 SQ 的逻辑做底层的“合理性校验”（防止推荐明显错误的配置），但把最终的“推荐权”交给安装商配置的策略。

### 4.2 下一步文档/功能规划

1.  **新建 `installer-config-guide.md`**：定义上述“简化配置界面”的字段。
2.  **修改 `equipment-recommender` 逻辑**：
    *   引入 `Standard Size Snapping` (标准规格吸附) 功能。
    *   引入 `Tiered Strategy` (分级策略)，让方案 A/B/C 不仅仅是价格不同，而是**逻辑不同**（满铺 vs 标准值）。
3.  **优化成本计算器**：
    *   保留方案 B 的数学模型。
    *   前端界面包装成“套餐设置”：输入 `6.6kW 套餐价` 和 `超出部分每 kW 单价`，系统自动反算 `Base` 和 `Incremental` 参数。

这样既满足了安装商“简单、自由”的需求，又保留了系统底层的强大扩展性。
