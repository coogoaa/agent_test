## API 说明

### 请求参数
```
filter_by=state
filters[state]=all-states
filters[size]=6.6kW
filters[panel]=0
filters[inverter]=0
```

### 可用 size 值
1kW, 1.5kW, 2kW, 3kW, 3.3kW, 4kW, 5kW, 6kW, **6.6kW**, 7kW, 8kW, 9kW, 10kW, 13kW, 15kW, 20kW

### 获取其他尺寸数据
需要通过浏览器访问网页获取（API 需要 session）：
1. 打开 https://www.solarquotes.com.au/price-explorer/
2. 打开开发者工具 (F12) → Network
3. 选择不同 System size
4. 复制 `ajx_price_explorer` 请求的响应
