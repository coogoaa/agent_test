# 发电量与自用率计算逻辑详解

## 1. 发电量计算体系

### 1.1 年度发电量计算

**输入参数**:
- `systemPower`: 光伏系统功率 (kWp)
- `annualGenerationFactor`: 年发电系数 (kWh/kWp)
- `annualGeneration`: 用户自定义年发电量 (可选)

**计算公式**:
```javascript
// 如果用户提供了年发电量，使用用户值；否则自动计算
annualSystemProduction = annualGeneration > 0 
    ? annualGeneration 
    : systemPower × annualGenerationFactor

// 示例: 8 kWp × 1526 kWh/kWp = 12,208 kWh/年
```

### 1.2 月度发电量分配

**基于月度发电比例分配**:
```javascript
// 第 M 月的发电量
monthlyGeneration[M] = annualSystemProduction × (MONTHLY_GENERATION_PERCENTAGES[M] / 100)

// 示例 (1月):
// 12,208 kWh × (10 / 100) = 1,220.8 kWh
```

**月度发电比例** (MONTHLY_GENERATION_PERCENTAGES):
```
1月: 10%, 2月: 9%, 3月: 9%, 4月: 8%, 5月: 7%, 6月: 6%
7月: 7%, 8月: 8%, 9月: 9%, 10月: 9%, 11月: 9%, 12月: 9%
```

### 1.3 日均发电量计算

```javascript
// 第 M 月的日均发电量
dailyGeneration[M] = monthlyGeneration[M] / DAYS_IN_MONTH[M]

// 示例 (1月):
// 1,220.8 kWh ÷ 31 天 = 39.38 kWh/天
```

### 1.4 小时发电量分配

**基于24小时发电系数分配**:
```javascript
// 第 M 月第 H 小时的发电量
hourlyGeneration[M][H] = dailyGeneration[M] × HOURLY_GENERATION_FACTORS[H]

// 示例 (1月 12:00):
// 39.38 kWh × 0.14 = 5.51 kWh
```

**24小时发电系数** (HOURLY_GENERATION_FACTORS):
```
0-5点: 0 (无发电)
6点: 0.01, 7点: 0.05, 8点: 0.1, 9点: 0.12, 10点: 0.13
11-12点: 0.14 (峰值)
13点: 0.12, 14点: 0.1, 15点: 0.05, 16点: 0.01
17-23点: 0 (无发电)
```

### 1.5 长期衰减计算

**20年逐月衰减模拟**:
```javascript
// 月度衰减系数
monthlyDegradationFactor = (1 - panelDegradation/100) ^ (1/12)

// 第 N 个月的实际发电量
actualGeneration[N] = baseGeneration × (monthlyDegradationFactor ^ (N-1))

// 示例 (年衰减率 0.4%):
// 月度衰减系数 = (1 - 0.004) ^ (1/12) = 0.9997
// 第12个月: baseGeneration × 0.9997^11 = baseGeneration × 0.996
// 第240个月: baseGeneration × 0.9997^239 = baseGeneration × 0.921
```

## 2. 用电量计算体系

### 2.1 年度用电量

**输入参数**:
- `state`: 州/领地代码
- `annualConsumption`: 年用电量 (kWh)

**州默认值** (可被用户覆盖):
```
TAS: 8,619 kWh, NT: 8,500 kWh, ACT: 6,407 kWh, SA: 4,950 kWh
NSW: 5,662 kWh, QLD: 5,650 kWh, WA: 5,198 kWh, VIC: 4,615 kWh
```

### 2.2 月度用电量分配

```javascript
// 第 M 月的用电量
monthlyConsumption[M] = annualConsumption × (STATE_MONTHLY_CONSUMPTION_PERCENTAGES[state][M] / 100)

// 示例 (NSW, 1月):
// 5,662 kWh × (8.55 / 100) = 484.1 kWh
```

### 2.3 日均用电量计算

```javascript
// 第 M 月的日均用电量
dailyConsumption[M] = monthlyConsumption[M] / DAYS_IN_MONTH[M]

// 示例 (NSW, 1月):
// 484.1 kWh ÷ 31 天 = 15.62 kWh/天
```

### 2.4 小时用电量分配

```javascript
// 第 M 月第 H 小时的用电量
hourlyConsumption[M][H] = dailyConsumption[M] × (STATE_HOURLY_CONSUMPTION_PERCENTAGES[state][H] / 100)

// 示例 (NSW, 1月 18:00):
// 15.62 kWh × (5.846 / 100) = 0.913 kWh
```

## 3. 自用率计算逻辑

### 3.1 逐小时能量流计算

**核心逻辑**: 每小时独立计算能量流向

```javascript
for (hour = 0; hour < 24; hour++) {
    generation = hourlyGeneration[hour]      // 该小时发电量
    consumption = hourlyConsumption[hour]    // 该小时用电量
    
    // 步骤1: 直接自用 (Direct Self-Consumption)
    directSelfConsumption = Math.min(generation, consumption)
    
    // 步骤2: 剩余发电 (可能充电池或上网)
    surplus = generation - consumption
    toBattery = Math.max(surplus, 0)  // 剩余发电量，可能充电池
    
    // 步骤3: 电网补充 (如果发电不足)
    fromGrid = Math.max(consumption - generation, 0)
}
```

**示例场景**:

#### 场景A: 白天高发电时段 (12:00)
```
发电: 5.51 kWh
用电: 0.62 kWh
---
直接自用: min(5.51, 0.62) = 0.62 kWh
剩余发电: 5.51 - 0.62 = 4.89 kWh (可充电池)
从电网: 0 kWh
```

#### 场景B: 晚间无发电时段 (18:00)
```
发电: 0 kWh
用电: 0.91 kWh
---
直接自用: min(0, 0.91) = 0 kWh
剩余发电: 0 kWh
从电网: 0.91 - 0 = 0.91 kWh (需要电池或电网)
```

### 3.2 电池储能计算

**日度电池充放电模拟**:

```javascript
// 步骤1: 计算全天直接自用
totalDirectSelfConsumption = sum(directSelfConsumption[0..23])

// 步骤2: 计算全天剩余发电 (充电潜力)
totalToBatteryPotential = sum(toBattery[0..23])

// 步骤3: 计算非发电时段用电需求
nonGenerationConsumption = totalConsumption - totalDirectSelfConsumption

// 步骤4: 计算实际有效充电量 (受三重限制)
finalEffectiveCharge = Math.min(
    totalToBatteryPotential,      // 限制1: 剩余发电量
    batteryCapacity,               // 限制2: 电池容量
    nonGenerationConsumption       // 限制3: 实际需求
)
```

**三重限制说明**:

1. **剩余发电量限制**: 不能充超过实际剩余的电
2. **电池容量限制**: 不能充超过电池物理容量
3. **实际需求限制**: 充电只为满足非发电时段需求，充多了也用不上

**示例计算**:
```
假设某天:
- 总发电: 39.38 kWh
- 总用电: 15.62 kWh
- 直接自用: 8.50 kWh (发电时段同时用电)
- 剩余发电: 39.38 - 8.50 = 30.88 kWh
- 非发电时段用电: 15.62 - 8.50 = 7.12 kWh
- 电池容量: 10 kWh

有效充电 = min(30.88, 10, 7.12) = 7.12 kWh
(受需求限制，只充7.12 kWh，因为只需要这么多)
```

### 3.3 日度自用量计算

```javascript
// 每日总自用量 = 直接自用 + 电池储能自用
dailySelfConsumption = totalDirectSelfConsumption + finalEffectiveCharge

// 示例:
// 8.50 kWh (直接) + 7.12 kWh (电池) = 15.62 kWh
```

### 3.4 月度自用量汇总

```javascript
// 第 M 月的总自用量
monthlySelfConsumption[M] = dailySelfConsumption[M] × DAYS_IN_MONTH[M]

// 示例 (1月):
// 15.62 kWh × 31 天 = 484.22 kWh
```

### 3.5 年度自用量与自用率

```javascript
// 年度总自用量
annualSelfConsumption = sum(monthlySelfConsumption[0..11])

// 年度自用率
selfConsumptionRate = annualSelfConsumption / annualGeneration

// 示例:
// 5,662 kWh / 12,208 kWh = 46.4%
```

## 4. 能量流向完整计算

### 4.1 年度能量流向

```javascript
// 1. 总发电量
totalGeneration = annualSystemProduction × degradationFactor

// 2. 总自用量 (已计算)
totalSelfConsumption = annualSelfConsumption

// 3. 上网电量
toGrid = totalGeneration - totalSelfConsumption

// 4. 从电网购电量
fromGrid = totalConsumption - totalSelfConsumption

// 5. 自用率
selfConsumptionRate = totalSelfConsumption / totalGeneration
```

**示例 (第1年)**:
```
总发电: 12,208 kWh
总用电: 5,662 kWh
总自用: 5,662 kWh (假设电池足够)
上网: 12,208 - 5,662 = 6,546 kWh
从电网: 0 kWh (理想情况)
自用率: 5,662 / 12,208 = 46.4%
```

### 4.2 20年逐月能量流模拟

```javascript
for (month = 1; month <= 240; month++) {
    // 1. 确定当前月份和年份
    year = Math.ceil(month / 12)
    monthInYear = (month - 1) % 12
    
    // 2. 应用衰减和通胀
    degradationFactor = monthlyDegradationFactor ^ (month - 1)
    inflationFactor = monthlyInflationFactor ^ (month - 1)
    
    // 3. 计算当月发电量 (含衰减)
    monthlyGeneration = baseMonthlyGeneration[monthInYear] × degradationFactor
    
    // 4. 计算当月自用量 (含衰减)
    monthlySelfConsumption = baseMonthlySelfConsumption[monthInYear] × degradationFactor
    
    // 5. 计算当月能量流向
    monthlyToGrid = monthlyGeneration - monthlySelfConsumption
    monthlyFromGrid = monthlyConsumption - monthlySelfConsumption
    
    // 6. 计算当月财务数据 (含通胀)
    currentElectricityPrice = baseElectricityPrice × inflationFactor
    currentFeedInTariff = baseFeedInTariff × inflationFactor
    
    // 7. 计算当月节省
    costWithoutSolar = monthlyConsumption × currentElectricityPrice
    costWithSolar = monthlyFromGrid × currentElectricityPrice
    revenueFromGrid = monthlyToGrid × currentFeedInTariff
    monthlySavings = costWithoutSolar - (costWithSolar - revenueFromGrid)
    
    // 8. 扣除电池分摊成本 (前120个月)
    if (month <= 120) {
        monthlySavings -= batteryReplacementCost / 120
    }
}
```

## 5. 关键假设与简化

### 5.1 电池模型假设
- **充放电效率**: 100% (实际约90-95%)
- **充电策略**: 优先充电，充满为止
- **放电策略**: 优先使用电池，用完再用电网
- **循环寿命**: 不考虑循环次数限制

### 5.2 能量流假设
- **即时平衡**: 每小时内发电和用电即时平衡
- **无损耗**: 不考虑逆变器、线路损耗
- **完美预测**: 假设能量流完全按模型执行

### 5.3 时间粒度
- **基础计算**: 小时级别 (24小时)
- **汇总层级**: 日 → 月 → 年
- **长期模拟**: 240个月 (20年)

## 6. 计算流程总结

```
输入参数
    ↓
年度发电量计算 (systemPower × annualGenerationFactor)
    ↓
月度分配 (MONTHLY_GENERATION_PERCENTAGES)
    ↓
日均计算 (monthlyGeneration / daysInMonth)
    ↓
小时分配 (HOURLY_GENERATION_FACTORS)
    ↓
逐小时能量流计算
    ├─ 直接自用 = min(generation, consumption)
    ├─ 剩余发电 = max(generation - consumption, 0)
    └─ 从电网 = max(consumption - generation, 0)
    ↓
日度电池储能计算
    └─ 有效充电 = min(剩余发电, 电池容量, 非发电时段需求)
    ↓
日度自用量 = 直接自用 + 电池储能
    ↓
月度汇总 (× daysInMonth)
    ↓
年度汇总 (sum 12个月)
    ↓
自用率 = 年度自用量 / 年度发电量
    ↓
20年逐月模拟 (含衰减、通胀、电池分摊)
    ↓
输出结果 (能量流、财务数据、回本周期)
```

## 7. 实际应用示例

```
州: NSW
年用电量: 5,662 kWh
系统功率: 8 kWp
年发电系数: 1,526 kWh/kWp
电池容量: 10 kWh
```

### 计算结果
```
年发电量: 12,208 kWh
年自用量: ~5,662 kWh (取决于时段匹配)
自用率: ~46% (无电池) → ~100% (有10kWh电池)
上网电量: ~6,546 kWh
从电网: ~0 kWh (有电池情况)
```

### 自用率影响因素
1. **用电时段**: 白天用电多 → 自用率高
2. **电池容量**: 电池大 → 自用率高
3. **系统规模**: 发电量远超用电量 → 自用率低
4. **季节变化**: 夏季发电多 → 可能降低自用率

## 8. 使用灵活的小时发电量数据的可行性分析

### 8.1 当前模型 vs 灵活数据模型对比

#### 当前模型（固定系数法）
```
年发电量 → 月度比例 → 日均 → 24小时固定系数
```

**特点**:
- 使用固定的 `HOURLY_GENERATION_FACTORS` (24个值)
- 所有月份使用相同的小时分布模式
- 简化计算，适合快速估算

#### 灵活数据模型（实际辐射数据）
```
PVGIS等API → 8760小时发电量 (365天 × 24小时)
或
全年24小时光照辐射数据 → 逐小时发电量计算
```

**特点**:
- 每个月、每天、每小时都有独立的发电量
- 反映真实的季节变化、天气模式
- 更精确，但数据量大

### 8.2 兼容性分析

#### ✅ **完全兼容** - 可以无缝替换

现有逻辑的核心是**逐小时能量流计算**，只要提供小时级发电量数据，计算逻辑完全适用：

**当前计算流程**:
```javascript
// 现有逻辑
hourlyGeneration[M][H] = dailyGeneration[M] × HOURLY_GENERATION_FACTORS[H]
hourlyConsumption[M][H] = dailyConsumption[M] × hourlyConsumptionFactors[H]

// 能量流计算（这部分不需要改）
directSelfConsumption = Math.min(hourlyGeneration, hourlyConsumption)
toBattery = Math.max(hourlyGeneration - hourlyConsumption, 0)
fromGrid = Math.max(hourlyConsumption - hourlyGeneration, 0)
```

**替换为灵活数据后**:
```javascript
// 直接使用实际小时发电量
hourlyGeneration[M][H] = pvgisHourlyData[M][day][H]  // 来自PVGIS
hourlyConsumption[M][H] = dailyConsumption[M] × hourlyConsumptionFactors[H]  // 保持不变

// 能量流计算（完全不需要改）
directSelfConsumption = Math.min(hourlyGeneration, hourlyConsumption)
toBattery = Math.max(hourlyGeneration - hourlyConsumption, 0)
fromGrid = Math.max(hourlyConsumption - hourlyGeneration, 0)
```

### 8.3 具体实施方案

#### 方案A: 使用8760小时发电量数据

**数据结构**:
```javascript
// 来自PVGIS API或其他源
pvgisHourlyData = [
    // 8760个小时的发电量 (kWh)
    { month: 1, day: 1, hour: 0, generation: 0 },
    { month: 1, day: 1, hour: 1, generation: 0 },
    ...
    { month: 1, day: 1, hour: 12, generation: 5.8 },  // 实际值
    ...
]
```

**集成方式**:
1. 保留现有的月度循环结构
2. 替换小时发电量计算部分
3. 其余逻辑（电池、自用率、财务）完全不变

**代码改动点**:
- `calculateBaseData()` 函数中的发电量计算部分
- 其他函数无需修改

#### 方案B: 使用全年24小时光照辐射数据

**数据结构**:
```javascript
// 光照辐射数据 (W/m²)
solarRadiationData = [
    // 每月每小时的平均辐射
    { month: 1, hour: 0, radiation: 0 },
    { month: 1, hour: 12, radiation: 850 },  // W/m²
    ...
]
```

**转换为发电量**:
```javascript
// 需要额外参数
systemEfficiency = 0.85  // 系统效率
panelArea = systemPower / 0.2  // 假设200W/m²标准条件

hourlyGeneration = (radiation / 1000) × panelArea × systemEfficiency
```

**集成方式**:
1. 增加辐射数据到发电量的转换层
2. 其余与方案A相同

### 8.4 日间/夜间区分的应用

#### 当前固定系数的日夜区分
```javascript
// 固定系数已经隐含了日夜区分
HOURLY_GENERATION_FACTORS = [
    0, 0, 0, 0, 0, 0,           // 0-5点: 夜间，无发电
    0.01, 0.05, 0.1, 0.12,      // 6-9点: 日出
    0.13, 0.14, 0.14, 0.12,     // 10-13点: 正午高峰
    0.1, 0.05, 0.01,            // 14-16点: 日落
    0, 0, 0, 0, 0, 0, 0         // 17-23点: 夜间，无发电
]
```

#### 使用实际辐射数据的日夜区分

**优势**:
1. **季节变化**: 夏季日照时间长，冬季短
2. **精确时段**: 真实的日出/日落时间
3. **天气影响**: 阴天、雨天的发电量下降

**示例对比**:
```
固定系数法（全年统一）:
- 发电时段: 6:00-16:59 (11小时)
- 峰值时段: 11:00-12:59

实际辐射数据（1月夏季）:
- 发电时段: 5:30-19:30 (14小时)
- 峰值时段: 12:00-14:00

实际辐射数据（6月冬季）:
- 发电时段: 7:00-16:00 (9小时)
- 峰值时段: 11:30-12:30
```

### 8.5 电池储能计算的改进

使用实际小时数据后，电池计算会更精确：

**当前逻辑（保持不变）**:
```javascript
// 日度汇总
totalToBatteryPotential = sum(hourly_toBattery[0..23])
nonGenerationConsumption = totalConsumption - totalDirectSelfConsumption
finalEffectiveCharge = min(totalToBatteryPotential, batteryCapacity, nonGenerationConsumption)
```

**改进效果**:
- 真实反映每天的充电潜力变化
- 阴天、晴天的电池使用模式不同
- 季节性电池利用率变化

### 8.6 实施建议

#### 最小改动方案（推荐）

**步骤1**: 数据准备
- 获取PVGIS 8760小时发电量数据
- 或获取月度平均小时辐射数据（12月 × 24小时 = 288个数据点）

**步骤2**: 修改数据输入层
```javascript
// 原来
const HOURLY_GENERATION_FACTORS = [固定24个值]

// 改为
const MONTHLY_HOURLY_GENERATION_DATA = {
    // 每月有24个小时的实际发电量或系数
    1: [h0, h1, ..., h23],  // 1月
    2: [h0, h1, ..., h23],  // 2月
    ...
    12: [h0, h1, ..., h23]  // 12月
}
```

**步骤3**: 修改计算函数
```javascript
// 原来
const gen = dailyGeneration * HOURLY_GENERATION_FACTORS[hour]

// 改为
const gen = dailyGeneration * MONTHLY_HOURLY_GENERATION_DATA[month][hour]
```

**步骤4**: 其他逻辑完全不变
- 能量流计算 ✓
- 电池储能 ✓
- 自用率 ✓
- 财务计算 ✓
- 20年模拟 ✓

### 8.7 数据精度对比

| 维度 | 固定系数法 | 月度小时数据 | 8760小时数据 |
|------|-----------|-------------|-------------|
| 数据点数量 | 24 | 288 (12×24) | 8760 (365×24) |
| 季节变化 | ❌ 无 | ✅ 月度级 | ✅ 日度级 |
| 日照时长变化 | ❌ 固定 | ✅ 月度变化 | ✅ 每天变化 |
| 天气影响 | ❌ 无 | ⚠️ 月平均 | ✅ 逐日变化 |
| 计算复杂度 | 低 | 中 | 中（结构相同） |
| 精度提升 | 基准 | +15-25% | +25-35% |
| 实施难度 | - | 低 | 中 |

### 8.8 结论

**✅ 完全可行，且改动很小**

1. **核心逻辑无需改动**: 逐小时能量流计算、电池储能、自用率计算完全兼容
2. **只需替换数据源**: 将固定的24小时系数替换为实际的小时发电量
3. **精度显著提升**: 特别是对于日照时长季节变化明显的地区
4. **建议实施方案**: 使用月度小时数据（288个数据点）作为平衡点，既提升精度又不过度复杂

**关键优势**:
- 真实反映日出/日落时间的季节变化
- 准确区分日间/夜间用电模式
- 电池储能计算更贴近实际
- 自用率计算更精确

**唯一需要注意**:
- 数据来源的可靠性（建议使用PVGIS、NASA等权威数据）
- 数据格式的标准化（便于集成）
