# 20年现金流展示功能使用指南

## 功能位置

打开 `index-amortized-monthly.html` 文件，在页面中找到 **"20年现金流明细"** 部分（位于 "20年财务预测" 图表之后）。

## 功能说明

### 1. 现金流趋势图 📊

**图表内容**：
- **柱状图（年度现金流）**：
  - 红色柱：第 0 年的初始投资（负值）
  - 绿色柱：每年的净节省（正值）
- **折线图（累计净收益）**：
  - 橙色曲线：显示累计净收益的增长趋势
  - 从负值开始（初始投资），逐年增长直至回本并持续盈利

**交互功能**：
- 鼠标悬停在图表上可查看具体数值
- 图表会根据参数变化自动更新

### 2. 现金流明细表 📋

**表格列说明**：

| 列名 | 说明 |
|------|------|
| 年份 | 第 0 年（初始投资）到第 20 年 |
| 年度净节省 | 每年的净节省额（已扣除电池分摊成本） |
| 累计节省（简单） | 不考虑贴现的累计节省 |
| 累计节省（贴现） | 考虑货币时间价值的累计节省 |
| 安装前成本 | 不安装太阳能系统的年度电费 |
| 安装后成本 | 安装太阳能系统后的年度电费 |
| 售电收入 | 上网电价收入 |
| 电池分摊 | 前 10 年每年分摊的电池成本 |

**特殊标记**：
- 🔴 **第 0 年**：红色背景，显示初始投资
- 🟢 **回本年份**：绿色背景，标注 "✓ 回本"
- **累计节省**：达到投资成本后以绿色粗体显示

### 3. 数据导出功能 💾

#### 导出年度数据
1. 点击 **"导出年度数据 (CSV)"** 按钮
2. 自动下载 `solar_cashflow_yearly_20years.csv` 文件
3. 包含 21 行数据（第 0-20 年）

**用途**：
- 在 Excel 中计算 IRR：`=IRR(B2:B22)`
- 制作自定义财务报表
- 进行深度财务分析

#### 导出月度数据
1. 点击 **"导出月度数据 (CSV)"** 按钮
2. 自动下载 `solar_cashflow_monthly_240months.csv` 文件
3. 包含 240 行数据（240 个月）

**用途**：
- 查看每月的详细现金流
- 分析季节性变化对现金流的影响
- 进行更精细的财务建模

### 4. 关键指标汇总 📈

表格下方显示三个关键财务指标：

#### IRR 现金流
- 显示用于 IRR 计算的现金流数组示例
- 格式：`[-$15,000, $1,234, $1,267, ...]`

#### 20年净收益
- 计算公式：20年累计节省 - 初始投资
- 显示最终的净盈利金额

#### 投资回报倍数
- 计算公式：20年累计节省 ÷ 初始投资
- 显示投资回报的倍数（如 2.5x 表示回报是投资的 2.5 倍）

## 使用场景

### 场景 1：快速评估投资回报
1. 查看现金流趋势图，直观了解回本时间
2. 查看 20年净收益和投资回报倍数
3. 判断投资是否值得

### 场景 2：详细财务分析
1. 导出年度数据 CSV
2. 在 Excel 中使用 IRR 函数验证内部收益率
3. 制作自定义财务报表

### 场景 3：对比不同方案
1. 调整参数（如电池容量、系统功率）
2. 观察现金流表格的变化
3. 导出多组数据进行对比分析

### 场景 4：月度现金流分析
1. 导出月度数据 CSV
2. 分析每月的现金流波动
3. 了解季节性对收益的影响

## 数据准确性说明

- 所有数据基于输入参数和预设的发电/用电模型计算
- 考虑了价格通胀、光伏板衰减等长期因素
- 电池成本采用计提法（前 120 个月分摊）
- 实际结果可能因天气、用电习惯等因素有所差异
