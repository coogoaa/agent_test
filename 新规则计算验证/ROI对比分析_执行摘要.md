# ROI对比分析 - 执行摘要

## 🎯 核心问题

**新旧成本参数对太阳能系统投资回报有什么影响？**

---

## 📊 关键数据（99个样本，1-100块面板）

| 核心指标 | 旧规则 | 新规则 | 差异 | 影响评估 |
|---------|-------|-------|------|---------|
| **平均最终成本** | 基准 | +2.30% | +$400-800 | 成本略高 ⚠️ |
| **简单回本周期** | 基准 | +0.16年 | +2个月 | 影响很小 ✅ |
| **贴现回本周期** | 基准 | +0.19年 | +2.3个月 | 影响很小 ✅ |
| **平均年度节省** | 基准 | $0 | 完全相同 | 无影响 ✅ |
| **IRR** | 基准 | -0.38% | 轻微降低 | 影响较小 ✅ |
| **20年总节省** | 基准 | $0 | 完全相同 | 无影响 ✅ |

---

## 🔍 关键发现

### 1. 不同规模系统表现差异显著

| 系统规模 | 成本差异 | 回本周期差异 | IRR差异 | 结论 |
|---------|---------|------------|---------|------|
| **小型（< 5kW）** | **-7.57%** | **-0.58年** | **+0.78%** | 新规则更优 ✅✅✅ |
| **中型（5-15kW）** | **-1.85%** | **-0.14年** | **+0.24%** | 新规则略优 ✅ |
| **大型（≥ 15kW）** | **+5.88%** | **+0.39年** | **-0.80%** | 新规则略贵 ⚠️ |

### 2. 典型案例对比

#### 案例A：小型系统（5块面板，2.2kW）
```
成本：$15,739 → $14,502 (-$1,238, -7.86%)
回本：15.81年 → 15.13年 (-0.68年)
IRR：3.35% → 4.04% (+0.70%)
✅ 新规则显著更优
```

#### 案例B：中型系统（33块面板，14.52kW）
```
成本：$20,519 → $20,575 (+$56, +0.27%)
回本：7.39年 → 7.41年 (+0.02年)
IRR：14.68% → 14.64% (-0.04%)
✅ 新旧规则基本持平
```

#### 案例C：大型系统（89块面板，39.16kW）
```
成本：$38,951 → $42,314 (+$3,362, +8.63%)
回本：6.81年 → 7.34年 (+0.53年)
IRR：15.64% → 14.37% (-1.28%)
⚠️ 新规则略贵，但IRR仍然很高
```

### 3. 为什么年度节省和20年总节省完全相同？

**关键洞察**：
- 年度节省取决于**能量流**（发电量、自用率、电价）
- 与**初始投资成本**无关
- 成本差异仅影响**回本时间点**，不影响**回本后的收益**

**示例**：
```
旧规则：投资$20,000，回本7.4年，年度节省$2,954
新规则：投资$20,575，回本7.4年，年度节省$2,954
        ↑ 成本高$575    ↑ 回本慢0.02年  ↑ 节省相同
```

## 🔧 参数优化方案

### 方案1：统一调整（推荐）

**目标**：将平均成本差异从+2.30%降至0%

```
面板：500 → 489 AUD/kW (-2.2%)
逆变器：260 → 254 AUD/kW (-2.3%)
电池：800 → 782 AUD/kWh (-2.3%)
```

**预期效果**：
- 平均成本差异：+2.30% → 0%
- 大型系统成本差异：+5.88% → +3.58%
- 小型系统成本差异：-7.57% → -9.87%（更优惠）

---

### 方案2：分档定价

| 系统规模 | 面板单价 | 逆变器单价 | 电池单价 | 效果 |
|---------|---------|-----------|---------|------|
| < 5kW | 500 | 260 | 800 | 保持优势 |
| 5-15kW | 490 | 255 | 785 | 增强竞争力 |
| ≥ 15kW | 480 | 250 | 770 | 解决贵的问题 |

---

### 方案3：容量折扣

```
基础单价：489/254/782
系统容量 > 20kW：总价打98折
系统容量 > 30kW：总价打96折
```

**优势**：简单透明，大型系统自动享受折扣

## 📈 ROI影响总结

### 成本增加2.30%的连锁反应

```
初始投资 ↑ 2.30%
    ↓
回本周期 ↑ 0.16年（2个月）
    ↓
IRR ↓ 0.38%
    ↓
年度节省 = 0（无影响）
    ↓
20年总节省 = 0（无影响）
```

**结论**：成本增加的影响主要体现在**初期投资**和**回本时间**，对**长期收益**无影响。

## 🎯 最终结论

### ✅ 新规则可以使用

**理由**：
1. 平均回本周期仅延长2个月，影响很小
2. IRR仅降低0.38%，投资吸引力基本不变
3. 年度节省和20年总节省完全相同
4. 小型系统竞争力大幅提升（-7.57%成本）
5. 中型系统略有优势（-1.85%成本）

### ⚠️ 大型系统需要优化

**理由**：
1. 成本增加5.88%，回本延长0.39年
2. IRR降低0.80%（但仍然很高，14%+）

**建议**：
- 短期：提供折扣或使用旧规则
- 中期：参数微调（489/254/782）或引入分档定价
