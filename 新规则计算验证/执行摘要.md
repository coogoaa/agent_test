## 五、为什么会有这个趋势？

### 旧规则的固定成本效应

```
旧规则总成本 = 固定成本 2,600 AUD + 变动成本

固定成本占比：
- 1块面板系统：2,600 / 21,498 = 12.1%
- 30块面板系统：2,600 / 31,110 = 8.4%
- 82块面板系统：2,600 / 60,521 = 4.3%

→ 小系统固定成本占比大，单位成本高
→ 大系统固定成本摊薄，单位成本低
```

### 新规则的线性定价

```
新规则总成本 = 变动成本（无固定成本）

单位成本恒定，不随规模变化

→ 与旧规则在30块面板处交叉
→ 小于30块：新规则更优惠
→ 大于30块：旧规则更优惠
```

如果希望实现完全持平，可以选择以下方案：

```

```

**方案2：电池分档定价**
```
小系统（< 25kWh）：790 AUD/kWh
中系统（25-40kWh）：770 AUD/kWh

效果：所有规模都有竞争力

**方案3：容量折扣**
```
基础单价：494/257/790

系统容量 > 30kW：总价打96折

效果：大系统自动享受折扣
优点：简单易懂，鼓励大系统
