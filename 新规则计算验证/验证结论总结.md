# 新老计算规则验证结论总结

## 执行摘要

通过对比**旧规则**（成本+利润率模式）和**新规则**（统一单价模式），在相同系统配置下进行了三个方案的详细验证。

**核心结论：新规则整体比旧规则低 2.46%，更有竞争力。**

---

## 一、验证结果汇总

| 方案 | 系统配置 | 旧规则报价 | 新规则报价 | 差异 | 差异率 | 结论 |
|------|---------|-----------|-----------|------|--------|------|
| **方案A (GS)** | 14.52kW + 9.3kW逆变器 + 28.04kWh电池 | 20,519.35 AUD | 20,575.41 AUD | +56.06 AUD | +0.27% | 基本持平 |
| **方案B (GD)** | 14.52kW + 10.0kW逆变器 + 22.22kWh电池 | 18,040.72 AUD | 17,719.06 AUD | -321.66 AUD | -1.78% | 新规则更优 |
| **方案C (公式)** | 14.52kW + 9.7kW逆变器 + 14.20kWh电池 | 14,333.92 AUD | 13,491.77 AUD | -842.15 AUD | -5.88% | 新规则显著更优 |

**平均差异率：-2.46%**

## 二、关键发现

### 2.1 定价模式对比

#### 旧规则（复杂成本模式）
```
税前总成本 = 核心硬件成本 + BOS成本

核心硬件成本 = 
  面板数量 × 80 × 1.3 +
  逆变器kW × 200 × 1.3 +
  电池kWh × 320 × 1.3

BOS成本 = 
  光伏基础安装费 1000 × 1.3 +
  光伏每kW安装费 × 150 × 1.3 +
  电池基础安装费 1000 × 1.3 +
  电池每kWh安装费 × 250 × 1.3

含税总价 = 税前总成本 × 1.1
```

**特点：**
- 固定基础费用高（光伏1,300 + 电池1,300 = 2,600 AUD）
- 多层利润率计算（30%）
- 成本结构透明但复杂

#### 新规则（简化单价模式）
```
税前总成本 = 
  光伏kW × 500 +
  逆变器kW × 260 +
  电池kWh × 800

含税总价 = 税前总成本 × 1.1
```

**特点：**
- 无固定基础费用
- 完全按容量线性计价
- 计算简单快速

### 2.2 差异原因分析

#### 方案A：基本持平（+0.27%）
- **大容量电池系统**（28.04kWh）
- 旧规则税前：32,059.04 AUD
- 新规则税前：32,110.00 AUD
- **结论**：新规则单价设定与旧规则大容量系统成本基本匹配

#### 方案B：略微优惠（-1.78%）
- **中等容量电池系统**（22.22kWh）
- 旧规则税前：27,928.42 AUD
- 新规则税前：27,636.00 AUD
- **结论**：新规则在中等容量时开始显现优势

#### 方案C：显著优惠（-5.88%）
- **小容量电池系统**（14.20kWh）
- 旧规则税前：21,907.69 AUD（含固定基础费2,600 AUD）
- 新规则税前：21,142.10 AUD（无固定费用）
- **结论**：新规则对小容量系统优势明显，节省842.15 AUD

### 2.3 核心差异点：固定基础费用

**旧规则的固定成本负担：**
```
固定基础费用 = 1,300（光伏基础）+ 1,300（电池基础）= 2,600 AUD

在不同容量系统中的占比：
- 方案A（大容量）：2,600 / 32,059 = 8.1%
- 方案B（中容量）：2,600 / 27,928 = 9.3%
- 方案C（小容量）：2,600 / 21,908 = 11.9%
```

**结论**：小容量系统受固定成本影响更大，新规则取消固定费用后优势显著。

## 三、单价对比分析

### 3.1 面板单价

| 项目 | 旧规则 | 新规则 | 差异 |
|------|--------|--------|------|
| 面板成本 | 80 AUD/块 × 1.3 = 104 AUD/块 | - | - |
| 换算成kW | 104 / 0.44 = 236 AUD/kW | 500 AUD/kW | +264 AUD/kW |
| 光伏安装费 | 1,300基础 + 150×1.3/kW = 195 AUD/kW | 已包含 | - |
| **综合单价** | **236 + 195 = 431 AUD/kW** | **500 AUD/kW** | **+69 AUD/kW** |

**结论**：新规则面板单价略高，但考虑到安装复杂度差异，基本合理。

### 3.2 逆变器单价

| 项目 | 旧规则 | 新规则 | 差异 |
|------|--------|--------|------|
| 逆变器成本 | 200 AUD/kW × 1.3 | 260 AUD/kW | 0 |
| **综合单价** | **260 AUD/kW** | **260 AUD/kW** | **完全一致** |

**结论**：逆变器定价完全匹配。

### 3.3 电池单价

| 项目 | 旧规则 | 新规则 | 差异 |
|------|--------|--------|------|
| 电池成本 | 320 AUD/kWh × 1.3 = 416 AUD/kWh | 800 AUD/kWh | +384 AUD/kWh |
| 电池安装费 | 1,300基础 + 250×1.3/kWh = 325 AUD/kWh | 已包含 | - |
| **综合单价** | **416 + 325 = 741 AUD/kWh** | **800 AUD/kWh** | **+59 AUD/kWh** |

**但考虑固定基础费1,300 AUD的影响：**

```
实际单价 = (电池总成本 - 固定基础费) / 电池容量

方案A (28.04kWh): (11,664.64 + 9,113.00 - 1,300) / 28.04 = 691 AUD/kWh
方案B (22.22kWh): (9,243.52 + 7,221.50 - 1,300) / 22.22 = 683 AUD/kWh
方案C (14.20kWh): (5,907.25 + 4,615.04 - 1,300) / 14.20 = 651 AUD/kWh

新规则统一: 800 AUD/kWh
```

**结论**：
- 大容量系统（>25kWh）：旧规则实际单价约691 AUD/kWh，新规则800 AUD/kWh略高
- 中容量系统（20-25kWh）：旧规则约683 AUD/kWh，新规则800 AUD/kWh略高
- 小容量系统（<20kWh）：旧规则约651 AUD/kWh，但固定费用占比大，新规则整体更优

## 四、适用场景建议

### 4.1 新规则优势场景

✅ **强烈推荐使用新规则：**
1. **小容量电池系统**（< 20kWh）- 节省5-6%
2. **储能扩容项目**（无光伏安装成本）- 预计节省更多
3. **快速报价场景** - 计算简单，客户易理解
4. **标准化产品** - 统一定价，便于管理

### 4.2 旧规则优势场景

⚠️ **考虑保留旧规则：**
1. **超大容量电池系统**（> 30kWh）- 可能略有优势
2. **特殊安装条件** - 需要调整BOS成本的项目
3. **精细化成本控制** - 需要透明成本结构的场景
4. **定制化项目** - 非标准配置需要灵活定价

### 4.3 混合策略建议

**推荐方案：**
- **主策略**：使用新规则作为标准定价方式（覆盖80%场景）
- **备选策略**：保留旧规则用于特殊项目（20%场景）
- **决策依据**：
  - 电池容量 < 25kWh → 新规则
  - 电池容量 ≥ 25kWh → 对比两种规则，选择更优方案
  - 特殊安装条件 → 旧规则

## 六、风险提示

### 6.1 潜在风险

1. **大容量系统竞争力**
   - 方案A新规则略高0.27%
   - 需要关注大客户反馈
   - 可能需要针对性调整

2. **客户沟通**
   - 老客户可能质疑价格变化
   - 需要准备清晰的解释
   - 强调简化和透明的优势

3. **内部适应**
   - 销售团队需要培训
   - 报价系统需要更新
   - 过渡期可能有混乱

### 6.2 缓解措施

1. **价格保护期**
   - 给予老客户1-2个月的价格保护
   - 平滑过渡，避免突然变化

2. **灵活定价**
   - 保留一定的议价空间
   - 针对大客户可以特殊处理

3. **充分测试**
   - 先在小范围试点
   - 收集反馈后再全面推广
