# 新规则参数下限建议报告

## 🎯 新规则说明

**改动前（旧规则）**：
- 分别计算 Key Products、Balance of System、Additional Charges
- 每个部分有独立的成本和利润率

**改动后（新规则）**：
- **不再区分** Key Products、BOS、Additional Charges
- **直接使用整体报价**：每kW面板报价、每kW逆变器报价、每kWh电池报价
- **税前整体报价 = 面板容量 × 每kW面板报价 + 逆变器功率 × 每kW逆变器报价 + 电池标称容量 × 每kWh电池报价**
- 新建系统：计算面板+逆变器+电池
- 储能扩容：只计算电池（面板和逆变器报价为0）

**新的预设单价**：
- 每kW面板报价：$540/kW
- 每kW逆变器报价：$280/kW
- 每kWh电池报价：$865/kWh（标称容量）

## ❌ 关键发现：负值风险

### 最严重的负值案例

**场景**：极低参数（50/50/100）+ 新建系统 + VIC州 + 100块面板

```
系统配置：
- 光伏容量：39.60 kW
- 逆变器功率：19.50 kW
- 电池标称容量：50.32 kWh

税前整体报价计算：
  面板成本 = 39.60 kW × $50/kW = $1,980.00
  逆变器成本 = 19.50 kW × $50/kW = $975.00
  电池成本 = 50.32 kWh × $100/kWh = $5,032.00
  税前总价 = $7,987.00
  GST = $798.70
  含税总价 = $8,785.70

补贴计算：
  PV STC补贴 = 39.60 × 1.382 × 6 × $39 = $12,799.08
  电池STC补贴 = floor(45.29 × 9.3) × $39 = $16,419.00
  VIC Rebate = $1,400.00
  VIC Loan = $1,400.00
  补贴总计 = $32,018.08

最终报价 = $8,785.70 - $32,018.08 = -$23,232.38 ❌
```

**问题**：补贴（$32,018）远超售价（$8,786），导致负值！

## 🔍 为什么会出现负值？

### 新规则 vs 旧规则的关键差异

**旧规则（Quote/index.html）**：
```
成本 = Key Products + BOS
     = (面板+逆变器+电池) + (安装费用)
     
BOS固定成本很高：
- 光伏基础安装费：$1,300
- 电池基础安装费：$1,300
- 光伏每kW安装费：$150/kW × 1.3
- 电池每kWh安装费：$250/kWh × 1.3

即使产品成本很低，BOS也能保证总价不会太低
```

**新规则**：
```
税前总价 = 面板容量 × 单价 + 逆变器功率 × 单价 + 电池容量 × 单价

没有固定的BOS成本！
如果单价设置过低，总价可能低于补贴
```

### 补贴结构分析

**典型50块面板系统（VIC州）的补贴**：

| 补贴类型 | 计算方式 | 金额 |
|---------|---------|------|
| PV STC | 19.80kW × 1.382 × 6 × $39 | $6,403 |
| 电池STC | floor(25.24 × 9.3) × $39 | $9,126 |
| VIC Rebate | 固定 | $1,400 |
| VIC Loan | 固定 | $1,400 |
| **总计** | | **$18,329** |

**关键**：补贴总额高达$18,329！如果税前总价低于这个数字，就会出现负值。

## 📋 详细案例分析

### 案例1：边界案例（低参数200/150/400）

**50块面板，VIC州，新建系统**

```
步骤1：系统配置
  实际面板数 = floor(50 × 0.9) = 45块
  光伏容量 = 45 × 0.44 = 19.80 kW
  逆变器功率 = 9.3 kW（查表）
  电池标称容量 = 28.04 kWh（查表）

步骤2：税前整体报价
  面板成本 = 19.80 × $200 = $3,960
  逆变器成本 = 9.3 × $150 = $1,395
  电池成本 = 28.04 × $400 = $11,216
  税前总价 = $16,571
  含税总价 = $16,571 × 1.1 = $18,228

步骤3：补贴
  补贴总计 = $18,329

步骤4：最终报价
  最终报价 = $18,228 - $18,329 = -$101 ❌
```

**结论**：即使参数不算太低（200/150/400），在VIC州大系统场景下仍可能出现负值。

### 案例2：安全参数（300/200/600）

**5块面板，VIC州，新建系统（最小系统）**

```
系统配置：
  光伏容量 = 1.76 kW
  逆变器功率 = 8 kW
  电池标称容量 = 22.44 kWh

税前整体报价：
  面板成本 = 1.76 × $300 = $528
  逆变器成本 = 8 × $200 = $1,600
  电池成本 = 22.44 × $600 = $13,464
  含税总价 = $15,592 × 1.1 = $17,151

补贴：
  补贴总计 = $10,662

最终报价 = $17,151 - $10,662 = $6,489 ✅
```

**结论**：使用300/200/600参数，即使是最小系统+最高补贴（VIC州），最终报价仍然安全。

### 案例3：电池扩容的风险

**50块面板，VIC州，电池扩容，极低参数（50/50/100）**

```
税前整体报价：
  面板成本 = $0（扩容不计算）
  逆变器成本 = $0（扩容不计算）
  电池成本 = 28.04 × $100 = $2,804
  含税总价 = $2,804 × 1.1 = $3,084

补贴：
  电池STC补贴 = $9,126（扩容仍享受）

最终报价 = $3,084 - $9,126 = -$6,042 ❌
```

**结论**：电池扩容风险更高！因为只有电池收入，但仍享受电池STC补贴。
