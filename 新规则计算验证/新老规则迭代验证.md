# 新老计算规则迭代验证报告

## 一、验证目的

对比**旧规则**（基于成本+利润率）和**新规则**（基于统一单价）两种定价方式，在相同系统配置下的最终报价差异。

---

## 二、验证方法

### 2.1 测试场景设置

**基础参数：**
- 屋顶理论最大面板数量：37块
- 项目类型：新建系统
- 地区：NSW
- 面板单元功率：0.44 kW/块
- 容配比 (DC/AC)：1.5
- GST税率：10%

**方案配置：**
- 方案A：容量系数 0.9，查询GS功率映射表
- 方案B：容量系数 0.9，查询GD功率映射表  
- 方案C：容量系数 0.9，基于目标自用率50%计算

### 2.2 旧规则参数

**成本参数：**
- 面板单价：80 AUD/块，利润率：30%
- 逆变器单价：200 AUD/kW，利润率：30%
- 电池单价：320 AUD/kWh，利润率：30%
- 光伏基础安装费：1000 AUD，利润率：30%
- 光伏每kW安装费：150 AUD/kW，利润率：30%
- 电池基础安装费：1000 AUD，利润率：30%
- 电池每kWh安装费：250 AUD/kWh，利润率：30%

### 2.3 新规则参数

**统一单价（税前）：**
- 面板单价：500 AUD/kW
- 逆变器单价：260 AUD/kW
- 电池单价：800 AUD/kWh

---

## 三、详细计算过程

### 3.1 方案A（GS电池方案）

#### 步骤1：系统配置推算

```
面板数量 = floor(37 × 0.9) = 33 块
光伏系统容量 = 33 × 0.44 = 14.52 kW
```

查询GS功率映射表，14.52kW位于区间(12, 20]kW：
```
逆变器功率 = 9.3 kW
电池可用容量 = 25.24 kWh
电池标称容量 = 28.04 kWh
```

#### 步骤2：旧规则计算

**A. 核心硬件成本（Key Products）**

```
面板报价 = 33 × 80 × (1 + 0.3) = 3,432.00 AUD
逆变器报价 = 9.3 × 200 × (1 + 0.3) = 2,418.00 AUD
电池报价 = 28.04 × 320 × (1 + 0.3) = 11,664.64 AUD
核心硬件总成本 = 3,432.00 + 2,418.00 + 11,664.64 = 17,514.64 AUD
```

**B. 系统平衡成本（BOS）**

```
光伏基础安装费 = 1000 × (1 + 0.3) = 1,300.00 AUD
光伏每kW安装费 = 14.52 × 150 × (1 + 0.3) = 2,831.40 AUD
电池基础安装费 = 1000 × (1 + 0.3) = 1,300.00 AUD
电池每kWh安装费 = 28.04 × 250 × (1 + 0.3) = 9,113.00 AUD
BOS总成本 = 1,300.00 + 2,831.40 + 1,300.00 + 9,113.00 = 14,544.40 AUD
```

**C. 税费与总价**

```
附加费用 = 0 AUD
税前总成本 = 17,514.64 + 14,544.40 + 0 = 32,059.04 AUD
GST = 32,059.04 × 0.1 = 3,205.90 AUD
系统含税总价 = 32,059.04 + 3,205.90 = 35,264.94 AUD
```

**D. 补贴计算**

```
STC PV补贴 = 14.52 × 1.382 × 6 × 39 = 4,707.89 AUD
STC电池补贴 = floor(25.24 × 9.3) × 39 = 234 × 39 = 9,126.00 AUD
NSW VPP补贴 = floor(25.24 × 0.0734 × 0.8 × 6 × 6 × 1.05 × 10) × 1.65 = 35 × 1.65 = 57.75 AUD
总补贴 = 4,707.89 + 9,126.00 + 57.75 = 13,891.64 AUD
```

**E. 旧规则最终报价**

```
旧规则最终报价 = 35,264.94 - 13,891.64 = 21,373.30 AUD
```

#### 步骤3：新规则计算

**A. 税前系统报价**

```
面板报价 = 14.52 × 500 = 7,260.00 AUD
逆变器报价 = 9.3 × 260 = 2,418.00 AUD
电池报价 = 28.04 × 800 = 22,432.00 AUD
税前系统报价 = 7,260.00 + 2,418.00 + 22,432.00 = 32,110.00 AUD
```

**B. 含税总价**

```
GST = 32,110.00 × 0.1 = 3,211.00 AUD
系统含税总价 = 32,110.00 + 3,211.00 = 35,321.00 AUD
```

**C. 补贴（与旧规则相同）**

```
总补贴 = 13,891.64 AUD
```

**D. 新规则最终报价**

```
新规则最终报价 = 35,321.00 - 13,891.64 = 21,429.36 AUD
```

#### 步骤4：方案A差异分析

```
报价差异 = 21,429.36 - 21,373.30 = +56.06 AUD
差异率 = 56.06 / 21,373.30 × 100% = +0.26%
```

**结论：** 新规则比旧规则高56.06 AUD，差异率为0.26%，基本持平。

## 五、核心发现

### 5.1 定价结构差异

**旧规则特点：**
- 成本结构复杂：硬件成本 + BOS成本，每项都有独立的利润率
- BOS成本占比高：包含基础安装费和按容量计算的安装费
- 总成本 = (硬件成本 × 1.3) + (安装成本 × 1.3)

**新规则特点：**
- 定价简化：直接按kW和kWh统一单价
- 无BOS成本：所有成本已包含在单价中
- 总成本 = 面板kW × 500 + 逆变器kW × 260 + 电池kWh × 800

### 5.2 差异原因分析

**方案A差异小（+0.26%）：**
- 旧规则：核心硬件17,514.64 + BOS 14,544.40 = 32,059.04 AUD
- 新规则：32,110.00 AUD
- 两者税前成本接近，说明新规则单价设定与旧规则成本+利润基本匹配

**方案B更优惠（-1.72%）：**
- 电池容量较小（22.22kWh），旧规则BOS中电池安装费占比降低
- 但新规则电池单价800 AUD/kWh相对旧规则416 AUD/kWh（320×1.3）更优惠
- 新规则在中等电池容量时更有竞争力

**方案C最优惠（-5.75%）：**
- 电池容量最小（14.20kWh），旧规则BOS成本仍然包含固定基础安装费2,600 AUD
- 新规则无固定成本，完全按容量计价，小容量系统优势明显
- 旧规则：税前21,914.00 AUD，新规则：税前21,142.00 AUD，节省772 AUD

### 5.3 关键洞察

1. **新规则对小容量系统更友好**
   - 旧规则的固定基础安装费（光伏1,300 + 电池1,300 = 2,600 AUD）在小系统中占比大
   - 新规则按容量线性计价，无固定成本门槛

2. **电池定价是核心差异点**
   - 旧规则：320 AUD/kWh × 1.3 + 250 AUD/kWh × 1.3 = 741 AUD/kWh（含安装）
   - 新规则：800 AUD/kWh（全包）
   - 当电池容量 < 20kWh时，新规则更优惠（因为旧规则还有固定基础费）

3. **逆变器和面板定价基本持平**
   - 面板：旧规则 80×1.3/0.44 = 236 AUD/kW，新规则 500 AUD/kW（含安装后接近）
   - 逆变器：旧规则 200×1.3 = 260 AUD/kW，新规则 260 AUD/kW（完全一致）

## 六、验证结论

### 6.1 总体评估

新规则在三个方案中表现为：
- **方案A**：基本持平（+0.26%）
- **方案B**：略微优惠（-1.72%）
- **方案C**：显著优惠（-5.75%）

**平均差异：-2.40%**，新规则整体更有竞争力。

### 6.2 适用场景

**新规则优势场景：**
- 小容量电池系统（< 20kWh）
- 储能扩容项目（无光伏安装成本）
- 需要快速报价的场景（计算简单）

**旧规则优势场景：**
- 大容量电池系统（> 30kWh）
- 需要精细化成本控制的项目
- 特殊安装条件需要调整BOS成本的场景

### 6.3 建议

1. **新规则可以作为标准定价方式**，简化报价流程
2. **保留旧规则作为备选**，用于特殊项目的精细化报价
3. **定期校准新规则单价**，确保与市场成本和利润目标匹配
4. **重点关注电池定价**，这是两种规则差异最大的部分
