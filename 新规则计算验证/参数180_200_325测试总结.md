## 🔍 负值原因分析

### 1. 新规则没有固定BOS成本

**旧规则**：
```
总价 = Key Products + BOS（固定安装费约$2,600）
即使产品成本低，BOS也能保证总价不会太低
```

**新规则**：
```
总价 = 面板容量×单价 + 逆变器功率×单价 + 电池容量×单价
没有固定成本保护！
```

### 2. 补贴占比过高

**50块面板系统的补贴结构**：

| 补贴类型 | NSW | VIC | 说明 |
|---------|-----|-----|------|
| PV STC | $6,403 | $6,403 | 光伏补贴 |
| Battery STC | $9,126 | $9,126 | 电池补贴（最大头）|
| NSW VPP | $924 | - | NSW电池补贴 |
| VIC补贴 | - | $2,800 | VIC额外补贴 |
| **总计** | **$16,453** | **$18,329** | |
| **占售价比** | **102.9%** | **114.6%** | ❌超过100% |

### 3. 电池STC是主要问题

**电池STC计算**：
```
Battery STC数量 = floor(可用容量 × 9.3)
                = floor(25.24 × 9.3)
                = 234个

Battery STC补贴 = 234 × $39 = $9,126
```

**问题**：电池补贴$9,126，但电池成本仅$9,113（28.04×$325），补贴几乎等于成本！
