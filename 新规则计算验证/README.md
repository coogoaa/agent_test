## 🔍 核心发现

### 1. 新参数合理性（迭代分析结论）⭐

✅ **新参数设置（500/260/800）较为合理**

**理由**：
- 平均税前差异仅+1.29%，基本持平
- 94.9%的样本在±5%范围内
- 小型系统更有竞争力（-4.85%）
- 大型系统差异可控（+3.46%）

**价格趋势**：
```
1-10块面板    → 新规则优惠 5-6%
11-30块面板   → 新规则优惠 1-4%
31-40块面板   → 基本持平 ±1%
41-100块面板  → 新规则略贵 1-5%

平衡点：约30块面板（13.2kW系统）
```

### 2. 为什么小系统优惠、大系统略贵？

**旧规则的固定成本效应**：
- 固定基础费：2,600 AUD（光伏1,300 + 电池1,300）
- 小系统：固定成本占比大（11.9%），拉高单位成本
- 大系统：固定成本摊薄（8.1%），降低单位成本

**新规则的线性定价**：
- 无固定成本，完全按容量计价
- 所有系统单位成本恒定
- 与旧规则在30块面板处交叉

### 3. 单价对比
- **面板**：旧规则 431 AUD/kW vs 新规则 500 AUD/kW（含安装）
- **逆变器**：旧规则 260 AUD/kW vs 新规则 260 AUD/kW（完全一致）✅
- **电池**：旧规则 651-691 AUD/kWh vs 新规则 800 AUD/kWh（考虑固定费后新规则更优）
