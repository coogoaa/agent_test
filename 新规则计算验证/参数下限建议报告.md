# 定价参数下限建议报告

## 🎯 分析目标

由于定价参数是开放给用户可调整的，需要设置合理的下限，防止：
1. **最终报价为负值**（补贴超过售价）
2. **最终报价过低**（< $5,000，不合理）

---

## 📊 问题分析

### 核心问题：补贴可能超过售价

**报价计算公式**：
```
最终报价 = (税前总价 × 1.1) - 总补贴
```

**补贴构成**：
1. **PV STC补贴**：光伏容量 × 1.382 × 6年 × $39
2. **电池STC补贴**：floor(可用电池容量 × 9.3) × $39
3. **NSW VPP补贴**：基于电池容量计算（2-28 kWh）
4. **VIC州补贴**：$1,400（Rebate）+ $1,400（无息贷款）

### 典型系统的补贴金额

| 系统规模 | 光伏容量 | 电池容量 | NSW补贴 | VIC补贴 | 最高补贴 |
|---------|---------|---------|---------|---------|---------|
| **小型（5块）** | 1.76kW | 22.44kWh | $8,601 | **$10,662** | $10,662 |
| **中小型（10块）** | 3.96kW | 22.44kWh | $9,313 | **$11,374** | $11,374 |
| **中型（30块）** | 11.88kW | 29.33kWh | $14,362 | **$16,197** | $16,197 |
| **大型（80块）** | 31.68kW | 50.32kWh | $26,664 | **$29,464** | $29,464 |

**关键发现**：
- VIC州补贴最高（额外$2,800）
- 小型系统补贴占比最高（补贴可能超过$10,000）
- 电池STC补贴占大头（约70-85%）

## 💡 参数下限设置建议

### 用户界面约束

```javascript
// 前端参数验证
const PARAM_LIMITS = {
    panel: {
        min: 420,      // AUD/kW
        max: 1000,     // AUD/kW
        default: 540,  // 当前推荐值
        step: 10
    },
    inverter: {
        min: 220,      // AUD/kW
        max: 500,      // AUD/kW
        default: 280,  // 当前推荐值
        step: 10
    },
    battery: {
        min: 660,      // AUD/kWh
        max: 1500,     // AUD/kWh
        default: 865,  // 当前推荐值
        step: 10
    }
};

// 验证函数
function validateParams(panel, inverter, battery) {
    if (panel < PARAM_LIMITS.panel.min) {
        return {
            valid: false,
            message: `面板单价不能低于 $${PARAM_LIMITS.panel.min}/kW`
        };
    }
    if (inverter < PARAM_LIMITS.inverter.min) {
        return {
            valid: false,
            message: `逆变器单价不能低于 $${PARAM_LIMITS.inverter.min}/kW`
        };
    }
    if (battery < PARAM_LIMITS.battery.min) {
        return {
            valid: false,
            message: `电池单价不能低于 $${PARAM_LIMITS.battery.min}/kWh`
        };
    }
    return { valid: true };
}
```

### 用户提示信息

当用户尝试设置过低的参数时，显示警告：

```
⚠️ 参数过低警告

您设置的参数可能导致最终报价过低或为负值。

建议最低参数：
• 面板：≥ $420/kW
• 逆变器：≥ $220/kW
• 电池：≥ $660/kWh

原因：
澳洲政府提供的补贴（STC、VIC Rebate等）可能超过系统售价，
导致最终报价为负值或不合理的低价。

推荐使用：
• 面板：$540/kW
• 逆变器：$280/kW
• 电池：$865/kWh
```

## 🔍 为什么需要这些下限？

### 1. 补贴结构导致的风险

**小型系统（5块面板）示例**：

```
系统配置：
- 光伏：1.76kW
- 逆变器：8kW
- 电池：22.44kWh

VIC州补贴：
- PV STC：$569
- 电池STC：$7,293
- VIC Rebate：$1,400
- VIC Loan：$1,400
- 总补贴：$10,662

如果参数过低（例如200/150/400）：
- 税前总价：约$9,500
- 含税总价：约$10,450
- 最终报价：$10,450 - $10,662 = -$212 ❌

使用推荐下限（420/220/660）：
- 税前总价：约$14,700
- 含税总价：约$16,170
- 最终报价：$16,170 - $10,662 = $5,508 ✅
```

### 2. 不同州的补贴差异

| 州 | 额外补贴 | 风险等级 |
|---|---------|---------|
| **VIC** | +$2,800 | ⚠️⚠️⚠️ 最高风险 |
| **NSW** | VPP补贴（变动） | ⚠️⚠️ 中等风险 |
| **QLD/SA/WA** | 仅STC | ⚠️ 低风险 |

**结论**：参数下限必须基于VIC州（最高补贴）场景设计。

### 3. 系统规模的影响

| 系统规模 | 补贴占比 | 风险 |
|---------|---------|------|
| **小型（<5kW）** | 50-70% | ⚠️⚠️⚠️ 最高 |
| **中型（5-15kW）** | 40-50% | ⚠️⚠️ 中等 |
| **大型（>15kW）** | 30-40% | ⚠️ 较低 |

**结论**：小型系统风险最高，参数下限必须基于小型系统设计。
