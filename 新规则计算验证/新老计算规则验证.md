## 成本计算

### 旧规则

A. 核心硬件成本 (calPanelBatteryInventorCost)
公式:
太阳能板报价 = 安装太阳能板数量 (panelCount) × 太阳能板单价 (panelPrice) × （1 + 面板利润率） 
逆变器报价 = 逆变器功率(kW) (invertorKw) × 逆变器每kW单价 (invertorPrice) ×（1 + 逆变器利润率） 
电池报价 = 电池额定容量(kWh) (batteryKw) × 电池每kWh单价 (batteryPrice)×（1 + 电池利润率） 
核心硬件报价 = 太阳能板报价 + 逆变器报价 + 电池报价
注意: 如果方案类型不是光伏（DesignType.PV），则太阳能板和逆变器的成本为0。

B. 系统平衡 (BOS) 成本 - 即安装及辅材费 (calBos)
公式:
// 光伏安装费部分
光伏安装费 = [基础安装费 × (1 + 基础安装利润率)] + [系统总功率(kW) × 每kW安装单价 × (1 + 每kW安装利润率)]

// 电池安装费部分
电池安装费 = [基础安装费 × (1 + 基础安装利润率)] + [电池额定容量(kWh) × 每kWh安装单价 × (1 + 每kWh安装利润率)]

BOS总成本 = 光伏安装费 + 电池安装费
注意: 光伏安装费同样仅在方案类型为光伏时计算。

C. 附加费用 (additionalCharges)
公式:
附加费总额 = Σ (该安装商所有附加项目的费用)
默认为 0

D. 含税系统总价 (systemTotal)
公式:
税前总成本 = 核心硬件总成本 + BOS总成本 + 附加费总额
最终系统总价 = 税前总成本 × (1 + 税率 (systemConfigDO.getTaxRate()))

### 新规则

直接使用一组数据，涵盖所有税前系统价格
panel_uint_price_per_kw	每 kW面板报价	500	AUD/kW
inverter_unit_price_per_kw	每 kW逆变器报价	260	AUD/kW
battery_unit_price_per_kwh	电池每kWh报价	800	AUD/kWh
系统税前报价 = panel_uint_price_per_kw * panelKw + inverter_unit_price_per_kw * invertorKw + battery_unit_price_per_kwh * batteryKw
系统含税报价 = 系统税前报价 * (1 + 税率)
