# 新老规则迭代分析报告

## 执行摘要

通过对1-100块面板的系统进行迭代分析，评估新参数设置的合理性。

### 核心结论

✅ **新参数设置较为合理，平均税前价格差异为 +1.29%**

- 94.9% 的样本税前价格差异在 ±5% 以内
- 32.3% 的样本税前价格差异在 ±3% 以内

## 一、分析方法

### 1.1 迭代范围

- **屋顶理论最大面板数量**：1-100块
- **容量系数**：0.9（默认值）
- **面板功率**：0.44 kW/块
- **电池方案**：GS功率映射表

### 1.2 对比维度

1. **税前费用**（重点关注）
2. **含税费用**（税前 × 1.1）
3. **补贴后费用**（含税 - 补贴）

### 1.3 新旧规则参数

**旧规则：**
- 面板：80 AUD/块 × 1.3
- 逆变器：200 AUD/kW × 1.3
- 电池：320 AUD/kWh × 1.3
- BOS：固定基础费 2,600 AUD + 按容量计费

**新规则：**
- 面板：500 AUD/kW
- 逆变器：260 AUD/kW
- 电池：800 AUD/kWh

## 二、关键发现

### 2.1 税前价格差异分布

| 指标 | 数值 |

| **平均差异率** | **+1.29%** |
| 最小差异率 | -5.80%（极小系统） |
| 最大差异率 | +4.98%（极大系统） |
| 标准差 | 3.29% |

**解读**：
- 新规则平均比旧规则高1.29%，基本持平
- 差异范围在-5.80%到+4.98%之间，波动较大
- 标准差3.29%，说明不同规模系统的表现差异明显

### 2.2 不同规模系统的表现

| 系统规模 | 样本数 | 平均税前差异率 | 表现 |
|---------|--------|---------------|------|
| **小型系统**（< 5kW） | 12 | **-4.85%** | 新规则更优惠 |
| **中型系统**（5-15kW） | 25 | **-1.15%** | 新规则略优 |
| **大型系统**（≥ 15kW） | 62 | **+3.46%** | 新规则略贵 |

**关键洞察**：

1. **小型系统（-4.85%）**
   - 新规则显著更优惠
   - 原因：旧规则固定基础费2,600 AUD在小系统中占比大
   - 示例：1块面板系统，旧规则21,497 AUD vs 新规则20,252 AUD

2. **中型系统（-1.15%）**
   - 新规则略微优惠
   - 过渡区间，两种规则接近平衡点
   - 示例：10块面板系统，旧规则23,206 AUD vs 新规则22,232 AUD

3. **大型系统（+3.46%）**
   - 新规则略贵
   - 原因：新规则单价设定略高于大系统的边际成本
   - 示例：82块面板系统，旧规则60,521 AUD vs 新规则63,366 AUD

## 三、价格差异趋势分析

### 3.1 税前价格差异曲线

从迭代数据可以看出明显的趋势：

```
面板数量    税前差异率
1-10块     -5.80% ~ -4.20%  （新规则显著优惠）
11-20块    -4.20% ~ -1.07%  （新规则优惠）
21-30块    -1.07% ~ -0.32%  （接近平衡）
31-40块    -0.32% ~ +0.52%  （基本持平）
41-50块    +0.52% ~ +3.27%  （新规则略贵）
51-100块   +3.27% ~ +4.98%  （新规则较贵）
```

**关键转折点**：
- **平衡点**：约30块面板（13.2kW系统）
- 小于30块：新规则更优惠
- 大于30块：新规则略贵

### 3.2 为什么会有这个趋势？

#### 旧规则的成本结构

```
旧规则总成本 = 固定成本 + 变动成本

固定成本 = 2,600 AUD（光伏基础1,300 + 电池基础1,300）
变动成本 = 面板成本 + 逆变器成本 + 电池成本 + 按容量BOS成本

单位成本 = 固定成本/容量 + 变动单位成本
```

**小系统**：固定成本占比大，单位成本高
**大系统**：固定成本摊薄，单位成本低

#### 新规则的成本结构

```
新规则总成本 = 变动成本（无固定成本）

变动成本 = 光伏kW × 500 + 逆变器kW × 260 + 电池kWh × 800

单位成本 = 恒定的变动单位成本
```

**所有系统**：单位成本恒定

#### 交叉点分析

```
当系统容量较小时：
  旧规则单位成本 = 固定成本/容量 + 变动单位成本 > 新规则单位成本
  → 新规则更优惠

当系统容量较大时：
  旧规则单位成本 = 固定成本/容量 + 变动单位成本 < 新规则单位成本
  → 旧规则更优惠

交叉点约在30块面板（13.2kW）
```

## 五、参数优化建议

### 5.1 如果希望税前价格完全持平

**方案1：统一调整所有单价**

```
调整幅度：-1.19%

调整后单价：
- 面板：500 × (1 - 0.0119) = 494 AUD/kW
- 逆变器：260 × (1 - 0.0119) = 257 AUD/kW
- 电池：800 × (1 - 0.0119) = 790 AUD/kWh
```

**效果**：平均差异从+1.29%降至约0%

**优点**：简单直接，所有系统同比例调整
**缺点**：仍然保留不同规模的差异趋势

---

**方案2：仅调整面板单价**

```
面板单价：500 → 494 AUD/kW
逆变器：260 AUD/kW（不变）
电池：800 AUD/kWh（不变）
```

**效果**：平均差异降低约1.2%

**优点**：调整最小，其他参数保持不变
**缺点**：面板单价可能偏低

---

**方案3：仅调整电池单价**

```
面板：500 AUD/kW（不变）
逆变器：260 AUD/kW（不变）
电池单价：800 → 790 AUD/kWh
```

**效果**：平均差异降低约0.8%

**优点**：电池是主要成本项，调整影响大
**缺点**：对小系统影响较小

---

### 5.2 如果希望保持小系统优势，改善大系统竞争力

**方案4：分档定价（推荐）**

```
面板单价：500 AUD/kW（不变）
逆变器单价：260 AUD/kW（不变）
电池单价分档：
  - 小系统（< 25kWh）：800 AUD/kWh
  - 中系统（25-40kWh）：780 AUD/kWh
  - 大系统（> 40kWh）：760 AUD/kWh
```

**效果**：
- 小系统保持优势（-4.85%）
- 大系统改善竞争力（+3.46% → +1.5%左右）

**优点**：
- 针对性强，不同规模都有竞争力
- 符合规模经济原理
- 灵活性高

**缺点**：
- 定价复杂度增加
- 需要系统支持分档计算

---

**方案5：引入容量折扣**

```
基础单价：
- 面板：500 AUD/kW
- 逆变器：260 AUD/kW
- 电池：800 AUD/kWh

容量折扣：
- 系统容量 > 20kW：总价打98折
- 系统容量 > 30kW：总价打96折
- 系统容量 > 40kW：总价打95折
```

**效果**：大系统自动享受折扣，改善竞争力

**优点**：
- 简单易懂，客户容易接受
- 鼓励客户选择大系统
- 灵活调整折扣比例

**缺点**：
- 可能影响利润率
- 需要明确折扣政策

---

## 八、风险与缓解

### 8.1 风险识别

| 风险 | 影响 | 概率 | 严重性 |
|------|------|------|--------|
| 大型系统竞争力下降 | 失去大客户 | 中 | 高 |
| 客户质疑价格变化 | 信任度下降 | 中 | 中 |
| 内部系统适应困难 | 效率降低 | 低 | 中 |
| 利润率波动 | 财务影响 | 中 | 中 |

### 8.2 缓解措施

**风险1：大型系统竞争力下降**
- 缓解：引入容量折扣或使用旧规则
- 监控：每周跟踪大型系统报价和成交率
- 应急：准备快速调整单价的机制

**风险2：客户质疑价格变化**
- 缓解：准备清晰的解释话术
- 强调：简化、透明、无隐藏费用
- 保护：给予老客户1个月价格保护期

**风险3：内部系统适应困难**
- 缓解：提供充分的培训
- 工具：更新报价系统和计算工具
- 支持：设立专门的咨询渠道

**风险4：利润率波动**
- 缓解：定期审查成本和利润
- 监控：每月分析不同规模系统的利润率
- 调整：根据实际情况灵活调整单价
